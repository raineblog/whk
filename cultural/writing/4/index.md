# 2017～2026 语文作文题目汇总分析

本文仅考虑大部分地区，收录大部分是全国卷的题，不收录北京、上海、天津是因为他们和全国差异太大，早期附上了山东、江苏、浙江的题目。

## 作文题目汇总

一下内容由人工智能整理，部分卷子名称，没有彻底核实，但是题目基本准确，附上了对应的来源，仅供参考。

### 2017 年

来源显示：2017 年共有全国Ⅰ、Ⅱ、Ⅲ卷，以及江苏、浙江、山东等自主命题卷；山东“回头已不是从前”为误传，实际为“24小时书店”材料题。[1](https://baike.baidu.com/item/2017%E5%B9%B4%E9%AB%98%E8%80%83%E4%BD%9C%E6%96%87/20837927) [2](https://gaokao.eol.cn/zuowen/jiqiao/201706/t20170607_1523663.shtml)

| 卷别/地区 | 作文题/材料核心                                                                                                                                                                                                                            |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 全国Ⅰ卷   | **“中国关键词”**：从“一带一路、大熊猫、广场舞、中华美食、长城、共享单车、京剧、空气污染、美丽乡村、食品安全、高铁、移动支付”等关键词中选两三个，写文章帮助外国青年读懂中国。                                                               |
| 全国Ⅱ卷   | **六句古诗文名句材料作文**：从“天行健，君子以自强不息”“露从今夜白，月是故乡明”“何须浅碧深红色，自是花中第一流”“受光于庭户见一堂，受光于天下照四方”“必须敢于正视，这才可望敢想，敢说，敢作，敢当”“数风流人物，还看今朝”等句中选两三句立意。 |
| 全国Ⅲ卷   | **“我看高考”/“我的高考”**：围绕恢复高考40周年，以“我看高考”或“我的高考”为副标题写作。                                                                                                                                                      |
| 山东卷    | **24小时书店/不打烊的书店**：某书店24小时营业，深夜接纳夜读者、自习学生、外来务工人员、流浪者、拾荒者，不驱赶任何人；据此写作。                                                                                                            |
| 江苏卷    | **“车”/车辆与时代变迁**：车来车往，见证时代发展，承载真情，折射观念变迁，蕴含人生哲理。                                                                                                                                                    |
| 浙江卷    | **“人生三本书”**：有字之书、无字之书、心灵之书，引发关于人生阅读与成长的思考。                                                                                                                                                             |

### 2018 年

2018 年全国Ⅰ、Ⅱ、Ⅲ卷以及江苏、浙江等卷题面由教育部/媒体汇总发布；山东使用全国Ⅰ卷。[2](https://www.guancha.cn/culture/2018_06_07_459315.shtml) [3](https://gaokao.eol.cn/zuowen/jiqiao/201806/t20180607_1606330.shtml)

| 卷别/地区 | 作文题/材料核心                                                                                                              |
| --------- | ---------------------------------------------------------------------------------------------------------------------------- |
| 全国Ⅰ卷   | **写给2035年18岁的一代人**：以“世纪宝宝”成长、中国新时代发展为材料，写文章装入“时光瓶”，留待2035年开启。                     |
| 全国Ⅱ卷   | **幸存者偏差/战机防护**：二战中统计幸存飞机弹痕，沃德指出应加强弹痕少的部位，因重创者无法返航。                              |
| 全国Ⅲ卷   | **三个时代标语**：1981深圳“时间就是金钱，效率就是生命”；2005浙江“绿水青山就是金山银山”；2017雄安“走好我们这一代人的长征路”。 |
| 江苏卷    | **语言**：花解语，鸟自鸣；音乐、雕塑、程序、基因等都是语言；语言丰富生活、演绎生命、传承文明。                               |
| 浙江卷    | **浙江精神/走在前列、勇立潮头**：浙江文化、浙江精神与浙江故事，引发作为浙江学子的体验与思考。                                |

### 2019 年

2019 年全国Ⅰ、Ⅱ、Ⅲ卷及江苏、浙江卷题目由人民日报客户端等汇总；山东使用全国Ⅰ卷。[2](https://www.guancha.cn/politics/2019_06_07_504738.shtml) [3](https://news.youth.cn/jsxw/201906/t20190607_11976323.htm)

| 卷别/地区    | 作文题/材料核心                                                                                                    |
| ------------ | ------------------------------------------------------------------------------------------------------------------ |
| 全国Ⅰ卷      | **“热爱劳动，从我做起”演讲稿**：围绕劳动价值、部分同学不愿劳动、不尊重劳动等现象，面向“复兴中学”同学写演讲稿。     |
| 全国Ⅱ卷      | **青春接棒，强国有我**：1919、1949、1979、2019、2049五个历史节点，任选任务写作，如演讲稿、书信、观后感、慰问信等。 |
| 全国Ⅲ卷      | **漫画作文：毕业前老师看学生**：漫画大意为老师对学生说“你们再看看书，我再看看你们”，围绕师生情、毕业、成长等立意。 |
| 全国汉语试卷 | **“奥运我最爱”主题班会**：围绕北京冬奥倒计时1000天、奥林匹克格言、马龙、“参与比胜利更重要”等材料写作。             |
| 江苏卷       | **五味调和，共存相生**：水至淡，盐得味；酸甜苦辣咸，五味调和，物如此，事犹是，人亦然。                             |
| 浙江卷       | **“作家、作品、读者”与生活**：若你是创造生活的“作家”，生活是“作品”，你将如何对待你的“读者”？                       |

### 2020 年

2020 年教育部考试中心命制全国Ⅰ、Ⅱ、Ⅲ、新高考Ⅰ、新高考Ⅱ五道作文题；山东使用新高考Ⅰ卷，江苏、浙江仍自主命题。[5](https://gaokao.eol.cn/zuowen/jiqiao/202007/t20200707_1736913.shtml) [2](https://edu.sina.com.cn/gaokao/2020-07-07/doc-iircuyvk2455042.shtml)

| 卷别/地区     | 作文题/材料核心                                                                                                                          |
| ------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| 全国Ⅰ卷       | **齐桓公、管仲、鲍叔**：班级读书会讨论三人，你对谁感触最深？写发言稿。                                                                   |
| 全国Ⅱ卷       | **“携手同一世界，青年共创未来”演讲稿**：结合全球抗疫、国际互助、人类命运共同体等材料，以中国青年代表身份在“世界青年与社会发展论坛”演讲。 |
| 全国Ⅲ卷       | **“如何为自己画好像”**：给即将入学的高一新生写信，谈自我认识、自画像、人生意义。                                                         |
| 全国新高考Ⅰ卷 | **“疫情中的距离与联系”**：疫情防控拉开空间距离，也密切了社会联系。                                                                       |
| 全国新高考Ⅱ卷 | \*\*“带你走近\_\_\_\_”主持词\*\*：读万卷书、行万里路，写一篇主持词，带人走近某地/某物/某文化等。                                         |
| 江苏卷        | **同声相应，同气相求/信息茧房与未来样子**：智能互联网时代，人被同类信息环绕、塑造；“你未来的样子”也许始于一次浏览、点赞、分享、感动。    |
| 浙江卷        | **人生坐标与现实变化**：个人的人生坐标、家庭预期、社会角色之间可能出现落差或错位，谈体验与思考。                                         |

### 2021 年

2021 年全国甲、乙、新高考Ⅰ、新高考Ⅱ由教育部考试中心命制；浙江仍自主命题，山东、江苏使用新高考Ⅰ卷。[1](https://m.thepaper.cn/newsDetail_forward_13029709) [2](https://gaokao.eol.cn/e_html/gk/mfzw/index.shtml)

| 卷别/地区 | 作文题/材料核心                                                                                                                                   |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| 全国甲卷  | **“可为与有为”**：结合建党百年、革命文化、社会主义先进文化、青年使命等，以“可为与有为”为主题写作。                                                |
| 全国乙卷  | **理想与自身发展**：围绕“修身以为弓，矫思以为矢，立义以为的”等关于理想追求、基础与目标的材料，结合当代青年自身发展写作。                          |
| 新高考Ⅰ卷 | **“体育之效”/强弱转化**：毛泽东《体育之研究》材料，体育强筋骨、增知识、调感情、强意志；“生而强者不必自喜，生而弱者不必自悲”。                     |
| 新高考Ⅱ卷 | **漫画“人”字/写人与做人**：漫画描红“人”字，含“逆锋起笔，藏而不露；中锋用笔，不偏不倚；停滞迂回，缓缓出头”等，谈认识、评价、取舍与新时代青年思考。 |
| 浙江卷    | **得与失**：有人把得与失看成终点，有人看成起点，有人看成过程；结合体验与思考写作。                                                                |

### 2022 年

2022 年全国甲、乙、新高考Ⅰ、新高考Ⅱ及浙江卷题面有公开汇总；山东、江苏使用新高考Ⅰ卷，浙江仍自主命题。[2](https://edu.sina.cn/gaokao/qsbk/2022-06-07/detail-imizirau6998777.d.html) [1](https://gaokao.eol.cn/zuowen/jiqiao/202303/t20230307_2315481.shtml)

| 卷别/地区 | 作文题/材料核心                                                                                                  |
| --------- | ---------------------------------------------------------------------------------------------------------------- |
| 全国甲卷  | **《红楼梦》“大观园试才题对额”**：众人给亭子题名，“翼然”“泻玉”“沁芳”等，涉及直接移用、借鉴化用、根据情境独创。   |
| 全国乙卷  | **“跨越，再跨越”**：北京“双奥之城”，2008奥运与2022冬奥见证中国体育和综合国力跨越，也见证考生成长。               |
| 新高考Ⅰ卷 | **本手、妙手、俗手**：围棋术语材料，本手是基础，妙手是创造，忽视本手易出俗手。                                   |
| 新高考Ⅱ卷 | **选择·创造·未来**：结合共青团成立100周年、青年选择与创造等材料写作。                                            |
| 浙江卷    | **青年有担当，青春正飞扬**：浙江实施人才强省、创新强省战略，新时代浙江青年在各领域开拓创新；谈对未来发展的启示。 |

### 2023 年

2023 年全国甲、乙、新课标Ⅰ、新课标Ⅱ四套全国命题卷；山东、江苏、浙江均使用新课标Ⅰ卷。[1](https://gaokao.eol.cn/zuowen/jiqiao/202306/t20230607_2431263.shtml) [4](https://m.bjnews.com.cn/detail/168611086614246.html)

| 卷别/地区 | 作文题/材料核心                                                                                                                                |
| --------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| 全国甲卷  | **人·技术·时间**：人们因技术发展得以更好掌控时间，但也有人因此成了时间的仆人。                                                                 |
| 全国乙卷  | **一花独放不是春**：两则材料：“吹灭别人的灯，并不会让自己更加光明；阻挡别人的路，也不会让自己行得更远。”以及“一花独放不是春，百花齐放春满园。” |
| 新课标Ⅰ卷 | **故事的力量**：好的故事有助于表达沟通、触动心灵、启迪智慧、改变命运、展现民族形象。                                                           |
| 新课标Ⅱ卷 | **青少年自己的空间**：从试卷阅读材料延伸，谈青少年在学习生活中有时希望拥有“自己的空间”的现象。                                                 |

### 2024 年

2024 年全国甲卷、新课标Ⅰ卷、新课标Ⅱ卷由教育部教育考试院命制；山东、江苏、浙江使用新课标Ⅰ卷。[1](https://www.xhby.net/content/s66627f23e4b0b88db5c49346.html) [5](https://c.m.163.com/news/a/J43EVB0500299EPB.html)

| 卷别/地区 | 作文题/材料核心                                                                                                       |
| --------- | --------------------------------------------------------------------------------------------------------------------- |
| 全国甲卷  | **真正的相遇/坦诚交流**：每个人都要学习与他人相处；有时为避免冲突不愿表达想法，其实坦诚交流才可能迎来真正的相遇。     |
| 新课标Ⅰ卷 | **答案与问题/人工智能时代的问题**：互联网普及、人工智能应用使越来越多问题很快得到答案，那么我们的问题是否会越来越少？ |
| 新课标Ⅱ卷 | **抵达未知之境**：现代文阅读Ⅰ提到月背探索、深空探测；如人类太空之旅，每个人也在不断抵达未知之境。                     |

### 2025 年

2025 年教育部教育考试院命制全国一卷、全国二卷两道作文题；公开信息显示江苏、浙江、山东使用全国一卷。[2](http://www.xinhuanet.com/edu/20250607/a3ccbb7424eb472bb05a5429f5128880/c.html) [3](https://www.zxxk.com/gaokao/2025shiti/)

| 卷别/地区 | 作文题/材料核心                                                                                                                                                                                                                         |
| --------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 全国一卷  | **民族魂/以嘶哑喉咙歌唱**：材料包括老舍《鼓书艺人》“他想要给孩子们唱上一段，可是心里直翻腾，开不了口”；艾青《我爱这土地》“假如我是一只鸟，我也应该用嘶哑的喉咙歌唱”；穆旦《赞美》“我要以带血的手和你们一一拥抱，因为一个民族已经起来”。 |
| 全国二卷  | **梦的赠予**：“昨夜闲潭梦落花”“我欲因之梦吴越”“铁马冰河入梦来”……梦呈现感受和期冀，也可讲述、记录、实现；“如果有一天，我们能够将梦赠予他人……”                                                                                            |

### 2026 年

2026 年教育部教育考试院命制全国Ⅰ卷、全国Ⅱ卷两道作文题；江苏、浙江、山东继续属于全国Ⅰ卷使用地区范围。[5](https://education.news.cn/20260607/bb187509af0e46139a7d5e7dd1ce4fab/c.html) [1](http://www.huaue.com/gkao2026/202667114055.htm)

| 卷别/地区 | 作文题/材料核心                                                                                                                                                                  |
| --------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 全国Ⅰ卷   | **词语理解的变化**：词语是表达思想情感的载体，也是展现社会生活变化的窗口；青年是常为新的，在成长过程中，你对哪一个词语的理解发生了变化？这种变化有你的成长印记、对你有特殊意义。 |
| 全国Ⅱ卷   | **本体与源头/困顿中复明复通**：材料引用“日月不失其体，故蔽而复明；江汉不失其源，故穷而复通。”谈个人成长、社会发展、文明演进中的困顿、挫折与根基。                                |
