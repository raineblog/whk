    2026济南一模物理18题

    2026济南一模物理18题解析：三体多过程弹性碰撞与局部摩擦耗能压轴题。含暴力演绎、状态代替、v-t图像几何及柯尼希正交分解解法，解锁等质量碰撞速度交换与机械能损失递推公式，助力高考物理压轴突破。

    这道题是一道非常经典的“三体多过程弹性碰撞 + 局部摩擦耗能”综合压轴题。很多同学做第（3）问时觉得思维链太长、算着算着就乱了，核心原因在于：三个物体的速度都在变，且交替碰撞的对象（挡板 C 与物块 A）不断切换，还要同时判断是否发生“未共速先相撞”的情况。

    下面我们先用极简的篇幅把第（1）、（2）问的物理基础铺好（第（3）问直接依赖它们的结果），然后重点用 4 种不同思维层次的做法，一步步拆解第（3）问。

    预备基础：第（1）、（2）问求解与物理图像建立

    记长木板为 C，取水平向右为正方向。已知 m_A = m_B = m_C = m = 1\text{ kg}，L = 5.5\text{ m}。

    1. 第（1）问：爆炸瞬间

      爆炸时间极短，内力远大于外力（A 与 C 间的摩擦力冲量忽略），A、B 系统水平动量守恒，且化学能的 50\%（即 E_{\text{初}} = 0.5 \times 8\text{ J} = 4\text{ J}）转化为 A、B 的动能：

      m v_{A0} + m v_{B0} = 0 \implies v_{A0} = -v_{B0}

      代入动能式：

      \frac{1}{2}m(-v_{B0})^2 + \frac{1}{2}m v_{B0}^2 = 4 \implies m v_{B0}^2 = 4

      由 m = 1\text{ kg} 且 B 向右运动，解得爆炸后瞬间：

      v_{B0} = 2\text{ m/s}，\quad v_{A0} = -2\text{ m/s}，\quad v_{C0} = 0

    2. 第（2）问：第一次碰撞（B 与挡板 C）前

      爆炸后，B 与 C 无摩擦，始终以 v_{B0} = 2\text{ m/s} 匀速向右运动。

      A 相对 C 向左滑动，滑动摩擦力大小为 f = \mu m g = 0.1 \times 1 \times 10 = 1\text{ N}。

      • 对 A：C 对 A 的摩擦力向右，a_A = +\frac{f}{m} = +1\text{ m/s}^2；

      • 对 C：A 对 C 的摩擦力向左，a_C = -\frac{f}{m} = -1\text{ m/s}^2。

      设经过时间 t_0，A 与 C 达到共同速度 u_0，则由 v_A(t_0) = v_C(t_0)：

      -2 + 1 \cdot t_0 = 0 - 1 \cdot t_0 \implies 2t_0 = 2 \implies t_0 = 1\text{ s}

      此时共同速度 u_0 = -1\text{ m/s}。检验此时 B 是否已经撞上挡板：

      • B 的位移：x_B = 2 \times 1 = 2\text{ m}；

      • C 的位移：x_C = -\frac{1}{2}(1)(1)^2 = -0.5\text{ m}；

      • B 相对 C 向右移动了 x_B - x_C = 2 - (-0.5) = 2.5\text{ m} < L = 5.5\text{ m}，说明 在 B 撞上挡板前，A 与 C 已经共速！

      在 t_0 = 1\text{ s} 时，同时算出两个重要物理量留作第（3）问使用：

      • A 的位移 x_A = -2(1) + \frac{1}{2}(1)(1)^2 = -1.5\text{ m}，A 相对 C 向左滑动的距离 |\Delta x_{AC,0}| = |-1.5 - (-0.5)| = 1\text{ m}，因此 A 距离挡板 C 的距离增大为 d_0 = 5.5 + 1 = 6.5\text{ m}，第 1 次碰撞前摩擦生热 \Delta Q_0 = f|\Delta x_{AC,0}| = 1\text{ J}。

      • 此后 A、C 一起以 u_0 = -1\text{ m/s} 匀速向左运动，B 相对挡板的速度为 2 - (-1) = 3\text{ m/s}，走完剩余 5.5 - 2.5 = 3.0\text{ m} 所需时间为 \Delta t = \frac{3.0}{3} = 1\text{ s}。故第 1 次相碰的时间为 t_1 = 1 + 1 = 2\text{ s}。

    第（3）问的审题关键说明（先扫清两个常见疑惑）

    在开始推导前，先明确题目第（3）问字面背后的两个物理细节：

    1. 关于“碰撞总次数 n”的理解：在本题理想条件下（B 与木板完全无摩擦、全部弹性碰撞、木板左侧足够长不滑落），后续每次过程速率减半但不会在有限步内严格归零，碰撞理论上可以持续下去；题目此处指代的是截至第 n 次碰撞发生前（累计经历了 n-1 次碰撞后的第 n 次碰撞临近时刻），E 表示从爆炸后（初始机械能 E_{\text{初}} = 4\text{ J}）到第 n 次碰撞前系统损失的机械能（注：爆炸时未转化为动能的那 4\text{ J} 化学能不是系统的机械能，不计入机械能损失）。

    2. 关于为什么题目写“当 n > 2 时”：第 1 次碰撞前损失的机械能 \Delta Q_0 = 1\text{ J} 并不在后续的等比数列里，从第 1 次碰撞后开始，各阶段的能量损失才构成公比为 \frac{1}{4} 的等比数列（即 n=3 起才能在过程累加中出现至少两项等比数列项），这正是题目限定 n>2 的原因（虽然最终化简出来的封闭公式对 n=1,2 也巧合成立）。

    另外，我们先用 3 行推一个全题共用的等质量弹性碰撞核心引理（避免后文重复推导）：

    碰撞时间极短，摩擦力冲量为零，未参与碰撞的第三者速度不变。两质量均为 m 的物体发生弹性碰撞，设碰前速度为 v_1, v_2，碰后为 v_1', v_2'：

    由动量守恒 m v_1 + m v_2 = m v_1' + m v_2' 得：v_1 - v_1' = v_2' - v_2 \quad \text{①}

    由动能守恒 \frac{1}{2}m v_1^2 + \frac{1}{2}m v_2^2 = \frac{1}{2}m v_1'^2 + \frac{1}{2}m v_2'^2，因式分解得：(v_1 - v_1')(v_1 + v_1') = (v_2' - v_2)(v_2' + v_2) \quad \text{②}

    将②式除以①式（碰撞发生则 v_1 \ne v_1'），得：v_1 + v_1' = v_2' + v_2 \quad \text{③}

    ①式与③式相加，直接消去 v_1' 和 v_2，得 2v_1 = 2v_2' \implies v_2' = v_1；代回①式得 v_1' = v_2。

    结论：等质量弹性碰撞的本质就是“直接交换速度”。

    做法一：暴力过程演绎 + 数列推演法（纯高中常规通法）

    思维路标：脚踏实地算完第 1 次碰撞后 \to 第 2 次碰撞前、第 2 次碰撞后 \to 第 3 次碰撞前，验证“每次都是先共速再下一次碰撞”，然后把第 k 阶段推到第 k+1 阶段写出严格递推式，最后用等比数列求和算出累计损失 E = \Delta Q_0 + \sum_{k=1}^{n-1} \Delta Q_k。

    第一步：计算第 1 次碰撞后到第 2 次碰撞前（第 1 阶段）

    第 1 次碰撞（B 撞挡板 C）前瞬间：

    v_A = -1\text{ m/s}，\quad v_C = -1\text{ m/s}，\quad v_B = +2\text{ m/s}

    B 与 C 交换速度，A 速度不变，故第 1 次碰撞后瞬间：

    v_A^{(1)} = -1\text{ m/s}，\quad v_B^{(1)} = -1\text{ m/s}，\quad v_C^{(1)} = +2\text{ m/s}

    此时 v_A^{(1)} < v_C^{(1)}，A 相对 C 向左滑，因此 a_A = +1\text{ m/s}^2，a_C = -1\text{ m/s}^2，B 匀速运动。

    设从第 1 次碰后经过时间 \tau_1，A、C 达到共速 u_1：

    -1 + 1 \cdot \tau_1 = 2 - 1 \cdot \tau_1 \implies 2\tau_1 = 3 \implies \tau_1 = 1.5\text{ s}

    代入得共速速度：u_1 = -1 + 1.5 = +0.5\text{ m/s}。

    检验在 \tau_1 内 B 是否提前撞上 A 或 C：

    • 在 \tau_1 = 1.5\text{ s} 内，三者位移分别为：

      \Delta x_A = -1(1.5) + \frac{1}{2}(1)(1.5)^2 = -0.375\text{ m}

      \Delta x_C = 2(1.5) - \frac{1}{2}(1)(1.5)^2 = +1.875\text{ m}

      \Delta x_B = -1(1.5) = -1.5\text{ m}

    • 碰后瞬间 B 在挡板处，距离 A 为 d_0 = 6.5\text{ m}。在 [0, \tau_1] 内 v_A(\tau) - v_B = (-1+\tau) - (-1) = \tau \ge 0，B 单调靠近 A，靠近量为 |\Delta x_B - \Delta x_A| = |-1.5 - (-0.375)| = 1.125\text{ m} < 6.5\text{ m}，故 B 未撞上 A；同时 v_C(\tau) - v_B = (2-\tau) - (-1) = 3-\tau > 0，B 单调远离挡板。

    • 共速后 A、C 一起以 +0.5\text{ m/s} 向右，B 以 -1\text{ m/s} 向左，因此之后必定发生第 2 次碰撞（B 撞 A）。

    第 1 阶段摩擦生热：

    A 相对 C 向左滑行距离：|\Delta x_{AC,1}| = \Delta x_C - \Delta x_A = 1.875 - (-0.375) = 2.25\text{ m} = \frac{9}{4}\text{ m}。

    此时 A 与挡板间距增大为：d_1 = d_0 + 2.25 = 8.75\text{ m}。

    第 1 阶段损失机械能：\Delta Q_1 = f|\Delta x_{AC,1}| = 1 \times \frac{9}{4} = \frac{9}{4}\text{ J}。

    第二步：计算第 2 次碰撞后到第 3 次碰撞前（第 2 阶段）

    第 2 次碰撞（B 撞 A）前瞬间：

    v_A = +0.5\text{ m/s}，\quad v_C = +0.5\text{ m/s}，\quad v_B = -1\text{ m/s}

    B 与 A 交换速度，C 速度不变，故第 2 次碰撞后瞬间：

    v_A^{(2)} = -1\text{ m/s}，\quad v_B^{(2)} = +0.5\text{ m/s}，\quad v_C^{(2)} = +0.5\text{ m/s}

    注意：仍然是 v_A^{(2)} < v_C^{(2)}！A 依然相对 C 向左滑，故加速度依然是 a_A = +1\text{ m/s}^2，a_C = -1\text{ m/s}^2。

    设经过时间 \tau_2 达到共速 u_2：

    -1 + \tau_2 = 0.5 - \tau_2 \implies 2\tau_2 = 1.5 \implies \tau_2 = 0.75\text{ s}

    代入得共速速度：u_2 = -1 + 0.75 = -0.25\text{ m/s}。

    检验在 \tau_2 内是否提前碰撞：

    • 三者位移：

      \Delta x_A = -1(0.75) + \frac{1}{2}(0.75)^2 = -\frac{15}{32}\text{ m}

      \Delta x_C = 0.5(0.75) - \frac{1}{2}(0.75)^2 = +\frac{3}{32}\text{ m}

      \Delta x_B = 0.5(0.75) = +\frac{12}{32}\text{ m}

    • 碰后瞬间 B 在 A 处，距离挡板 d_1 = 8.75\text{ m}。在 [0, \tau_2] 内 B 单调靠近挡板，靠近量为 \Delta x_B - \Delta x_C = \frac{9}{32}\text{ m} \approx 0.28\text{ m} < 8.75\text{ m}，且远离 A。故直到共速前都不发生碰撞！共速后 B（+0.5）追上 C（-0.25），发生第 3 次碰撞（B 撞挡板）。

    第 2 阶段摩擦生热：

    A 相对 C 向左滑行距离：|\Delta x_{AC,2}| = \frac{3}{32} - \left(-\frac{15}{32}\right) = \frac{18}{32} = \frac{9}{16}\text{ m}。

    此时 A 与挡板间距增大为：d_2 = 8.75 + \frac{9}{16} = 9.3125\text{ m}。

    第 2 阶段损失机械能：\Delta Q_2 = 1 \times \frac{9}{16} = \frac{9}{16}\text{ J}。

    第三步：建立一般第 k 阶段（k \ge 1）的严格代数递推

    记第 k 次碰撞前，三者速度已满足：

    v_A = v_C = u_{k-1}，\quad v_B = -2u_{k-1}

    （验证 k=1 时 u_0=-1, v_B=2=-2u_0；k=2 时 u_1=0.5, v_B=-1=-2u_1，均成立），且 u_{k-1} 符号随 k 交替变化（k 为奇时 u_{k-1}<0，B 向右撞挡板 C；k 为偶时 u_{k-1}>0，B 向左撞 A），板间距 d_{k-1} \ge 6.5\text{ m}。

    现在把第 k 阶段推进到第 k+1 次碰撞前：

    1. 碰后速度：无论 k 为奇（B 与 C 换速）还是为偶（B 与 A 换速），未碰撞那一方和 B 的速度都保持为 u_{k-1}，而被碰撞那一方获得 -2u_{k-1}。

      • 当 k 为奇时，u_{k-1} < 0，v_C' = -2u_{k-1} > 0 > v_A' = u_{k-1}；

      • 当 k 为偶时，u_{k-1} > 0，v_C' = u_{k-1} > 0 > v_A' = -2u_{k-1}。

      可见无论奇偶，碰后恒有 v_C' - v_A' = 3|u_{k-1}| > 0，即 A 永远相对 C 向左滑，a_A = +1\text{ m/s}^2，a_C = -1\text{ m/s}^2！

    2. 共速时间与新共速：

      由 v_A' + \tau_k = v_C' - \tau_k 得：

      \tau_k = \frac{v_C' - v_A'}{2} = \frac{3|u_{k-1}|}{2}

      新的共速为两端初速的平均值（因加速度等大反向）：

      u_k = \frac{v_A' + v_C'}{2} = \frac{u_{k-1} + (-2u_{k-1})}{2} = -\frac{1}{2}u_{k-1}

      由于碰后 v_B' = u_{k-1}，立即得到 v_B' = -2u_k，且 u_k 符号刚好反转，这就严格证明了速度关系向下一阶段闭合递推！

    3. 不提前碰撞的严格证明：

      在 [0, \tau_k] 内，B 与未碰撞方初速相同（均为 u_{k-1}），未碰撞方以大小为 1\text{ m/s}^2 的加速度朝 B 的目标方向加速，故 B 接近目标的距离为 \frac{1}{2} \cdot 1 \cdot \tau_k^2 = \frac{9}{8}u_{k-1}^2。由于 |u_{k-1}| = 2^{-(k-1)} \le 1，该距离不超过 \frac{9}{8} = 1.125\text{ m}，而此时 A 相对 C 继续左滑使间距 d_k > d_{k-1} \ge 6.5\text{ m}，因此永远不会在共速前相撞。

    4. 第 k 阶段耗能 \Delta Q_k：

      在 \tau_k 时间内，A、C 相对速度从 3|u_{k-1}| 均匀减为 0，用平均相对速度算相对位移：

      |\Delta x_{AC,k}| = \frac{3|u_{k-1}| + 0}{2} \cdot \tau_k = \frac{3|u_{k-1}|}{2} \cdot \frac{3|u_{k-1}|}{2} = \frac{9}{4}u_{k-1}^2

      由 u_k = -\frac{1}{2}u_{k-1} 和 u_0 = -1，得 u_{k-1} = (-1)\left(-\frac{1}{2}\right)^{k-1}，于是 u_{k-1}^2 = \frac{1}{4^{k-1}}。从而：

      \Delta Q_k = f|\Delta x_{AC,k}| = \frac{9}{4} \cdot \left(\frac{1}{4}\right)^{k-1}\text{ J} \quad (k = 1, 2, 3, \dots)

    第四步：等比数列求和得出 E 与 n 的关系

    第 n 次碰撞前（n > 2），系统经历了第 0 阶段（第 1 次碰撞前）以及第 1, 2, \dots, n-1 阶段。总损失机械能为：

    E = \Delta Q_0 + \sum_{k=1}^{n-1} \Delta Q_k = 1 + \sum_{k=1}^{n-1} \frac{9}{4}\left(\frac{1}{4}\right)^{k-1}

    后面是首项 a_1 = \frac{9}{4}、公比 q = \frac{1}{4}、共 (n-1) 项的等比数列，直接套用求和公式 S = \frac{a_1(1 - q^{n-1})}{1 - q}：

    E = 1 + \frac{\frac{9}{4}\left[1 - \left(\frac{1}{4}\right)^{n-1}\right]}{1 - \frac{1}{4}} = 1 + 3\left(1 - \frac{1}{4^{n-1}}\right) = 4 - \frac{3}{4^{n-1}}\text{ (J)}

    做法二：以状态代替过程 + 系统动量锁定法（经典物理思想转化）

    思维路标：做法一之所以计算量大，是因为题目问“损失了多少机械能”，我们却老老实实去算每一段的“加速度、时间、位移、摩擦生热”再求和。转换视角：求损失的机械能 E，等于求“初始机械能 E_{\text{初}} 减去 第 n 次碰撞前瞬间的剩余总动能 E_{k,n^-}”！只要用动量守恒把“共速状态”的速度递推出来，完全不用算位移、也不用做数列求和！

    第一步：用全局动量守恒锁定“共速状态”的唯一自由度

    系统（A+B+C）放置在光滑水平地面上，水平方向不受外力，因此全过程任意时刻总动量恒为零：

    m v_A + m v_B + m v_C = 0 \implies v_A + v_B + v_C = 0

    因此，在任何一次 A 与 C 达到共同速度 u 的状态（v_A = v_C = u），B 的速度被唯一锁定为：

    u + v_B + u = 0 \implies v_B = -2u

    此时整个系统的总动能可以仅用单变量 u 表示出来：

    E_k(u) = \frac{1}{2}m u^2 + \frac{1}{2}m u^2 + \frac{1}{2}m (-2u)^2 = 3m u^2

    第二步：一步验证“共速必先于下次碰撞”

    （逻辑严谨不可跳过的节点，用能量/运动学不等式一句话写透）：

    假设第 k 次碰撞前处于共速状态 (u_{k-1}, u_{k-1}, -2u_{k-1})（第 1 次碰撞前已知成立，且 d_0 = 6.5\text{ m}，u_0=-1\text{ m/s}）。

    碰撞瞬间 B 与 C（或 A）交换速度后，未碰撞者与 B 具有相同初速度 u_{k-1}，而被碰撞者获得 -2u_{k-1}。因 u_{k-1} 与 -2u_{k-1} 异号，A 与 C 必经历相对滑动直到再次共速 u_k。

    在此期间（设耗时 \tau_k），以 B 为参考系，未碰撞者初速为 0、加速度大小恒为 1\text{ m/s}^2，且 \tau_k = \frac{|-2u_{k-1} - u_{k-1}|}{2} = \frac{3}{2}|u_{k-1}|，所以 B 接近目标的最大位移为 \frac{1}{2}\cdot 1 \cdot \tau_k^2 = \frac{9}{8}u_{k-1}^2。只要 |u_{k-1}| \le 1（马上可见 |u_k| 每次减半），接近量 \le 1.125\text{ m}，且无论奇偶碰撞，碰后总是 v_A < v_C（u_0<0 时偶次碰后 v_A = -2u_{k-1}<0<u_{k-1}；奇次碰后 v_A = u_{k-1}<0<-2u_{k-1}），故 A 总是左滑使间距 d_k 单调增大（d_k > 6.5\text{ m}）。因此，每次碰撞前，A、C 必定已经完成共速！

    第三步：两行推出共速递推式与剩余动能

    从第 k 次碰撞后瞬间到第 k+1 次碰撞前共速的这段时间内，B 没有任何受力，因此只看 (A+C) 这两个物体构成的局部系统，水平外力之和为零，(A+C) 局部系统动量守恒！

    碰后瞬间 A 和 C 的速度一个为 u_{k-1}，一个为 -2u_{k-1}，共速后均为 u_k，于是：

    m u_{k-1} + m(-2u_{k-1}) = (m + m) u_k \implies -u_{k-1} = 2u_k \implies u_k = -\frac{1}{2}u_{k-1}

    将其代回第一步的总动能表达式 E_k(u) = 3m u^2，立即得到相邻两次碰撞前瞬间系统总动能的比值：

    \frac{E_{k,(k+1)^-}}{E_{k,k^-}} = \frac{3m u_k^2}{3m u_{k-1}^2} = \left(-\frac{1}{2}\right)^2 = \frac{1}{4}

    第四步：直接写出第 n 次碰撞前的机械能损失

    第 1 次碰撞前，由第（2）问已知 u_0 = -1\text{ m/s}，此时系统总动能为：

    E_{k,1^-} = 3m u_0^2 = 3 \times 1 \times (-1)^2 = 3\text{ J}

    每经历一次碰撞和共速，剩余动能乘以 \frac{1}{4}，从第 1 次碰撞前到第 n 次碰撞前共经历了 (n-1) 个周期，因此第 n 次碰撞前的剩余动能为：

    E_{k,n^-} = 3 \times \left(\frac{1}{4}\right)^{n-1}\text{ J}

    系统初始机械能为 E_{\text{初}} = 4\text{ J}，故第 n 次碰撞前系统损失的机械能为：

    E = E_{\text{初}} - E_{k,n^-} = 4 - \frac{3}{4^{n-1}}\text{ (J)}

    思考提炼：做法二只用了一次整体动量守恒 + 一次局部动量守恒，完全绕开了牛顿第二定律、运动学公式和等比数列求和，计算量直降 80%！

    做法三：v-t 图像相似三角形法（思维可视化 + 几何面积法）

    思维路标：A 和 C 相对滑动时，加速度永远是 a_A = +1\text{ m/s}^2 和 a_C = -1\text{ m/s}^2，它们在 v-t 图上画出来就是一个个斜率对称（\pm 1）的水平等腰三角形！三角形的高（横轴）是时间，底边（纵轴）是速度差，三角形的面积就是 A 相对 C 的滑行距离，直接等于该阶段损失的机械能！

    第一步：画出几何规则（把动力学变成平面几何）

    在 v-t 坐标系中：

    1. 每当 A 与 C 发生相对滑动（v_A < v_C），v_C(t) 以斜率 -1 下降，v_A(t) 以斜率 +1 上升，直到相交于共速点 u_k。这三条线段围成一个底边竖直、顶点向右的等腰三角形。

    2. 设竖直底边长度（初速度差）为 \Delta v = v_C' - v_A'。由于两条腰的斜率分别是 +1 和 -1，这个等腰三角形的水平高（共速时间 \tau）必然等于底边的一半，即 \tau = \frac{\Delta v}{2}。

    3. 由 v-t 图线所围面积代表相对位移，该等腰三角形的面积 S 就是 A 相对 C 的滑行距离，再乘以 f = 1\text{ N} 就是摩擦生热：

      \Delta Q = f \cdot S = 1 \cdot \left(\frac{1}{2} \cdot \Delta v \cdot \frac{\Delta v}{2}\right) = \frac{1}{4}(\Delta v)^2

    第二步：在 v-t 图上读出各阶段三角形的相似关系

    1. 第 0 阶段（第 1 次碰撞前）：

      初态 v_{C0}=0, v_{A0}=-2，底边 \Delta v_0 = 0 - (-2) = 2。

      直接算出第 0 个三角形面积：

      S_0 = \frac{1}{4}(2)^2 = 1\text{ m} \implies \Delta Q_0 = 1\text{ J}

      右顶点（共速）纵坐标为底边中点：u_0 = \frac{0 + (-2)}{2} = -1。

    2. 第 1 阶段（第 1 次碰撞后）：

      因总动量 v_A+v_B+v_C=0，共速时 v_B = -2u_0 = +2。第 1 次碰撞 B 与 C 交换速度，C 的图线瞬间竖直跳变到 +2，而 A 和 B 都停留在 -1。

      于是第 1 个三角形的竖直底边为：\Delta v_1 = 2 - (-1) = 3。

      面积为：S_1 = \frac{1}{4}(3)^2 = \frac{9}{4}\text{ m} \implies \Delta Q_1 = \frac{9}{4}\text{ J}。

      新顶点（底边中点）纵坐标：u_1 = \frac{2 + (-1)}{2} = +0.5。

    3. 几何相似性锁定（从第 k 个三角形到第 k+1 个三角形）：

      对于任意第 k 个三角形（k \ge 1），设其右顶点纵坐标为 u_k。此时 v_B 在碰后停留在上一个顶点 u_{k-1} = -2u_k 处（因为总动量为零，v_A+v_C+v_B=0 \implies 2u_k + v_B = 0 \implies v_B = -2u_k）。

      在第 k+1 次碰撞瞬间，其中一个物体（A 或 C）通过换速跳到 v_B = -2u_k，另一个仍留在 u_k。因此，第 k+1 个三角形的竖直底边长度为：

      \Delta v_{k+1} = |-2u_k - u_k| = 3|u_k|

      而对比第 k 个三角形：它的顶点 u_k 是底边 u_{k-1} 和 -2u_{k-1} 的中点，即 u_k = -\frac{1}{2}u_{k-1}，而第 k 个三角形的底边是 \Delta v_k = 3|u_{k-1}|。

      两式一除，相邻两个三角形的底边比（相似比）严格等于 \frac{1}{2}：

      \frac{\Delta v_{k+1}}{\Delta v_k} = \frac{3|u_k|}{3|u_{k-1}|} = \frac{1}{2}

      同时在图上还能一眼看穿“为什么不会提前碰撞”：B（水平线 u_{k-1}）与未碰撞物体（从 u_{k-1} 斜向 u_k 的斜线）之间夹着一个直角三角形，底为 \tau_k、高为 |u_k - u_{k-1}| = \frac{1}{2}\Delta v_k，其面积恰好是对应等腰三角形面积的一半（\frac{1}{2}S_k \le \frac{1}{2}S_1 = 1.125\text{ m} < d_0 = 6.5\text{ m}）！

    第三步：用相似三角形面积比（相似比的平方 = \frac{1}{4}）直接求和

    从第 1 个三角形开始，各三角形全部相似，相似比为 \frac{1}{2}，故面积比为 \left(\frac{1}{2}\right)^2 = \frac{1}{4}，即 S_{k+1} = \frac{1}{4}S_k（k \ge 1），首项 S_1 = \frac{9}{4}。

    当 n > 2 时，第 n 次碰撞前经历了三角形 0, 1, 2, \dots, n-1，总面积（总损失机械能）为：

    E = S_0 + \sum_{k=1}^{n-1} S_k = 1 + \frac{\frac{9}{4}\left[1 - \left(\frac{1}{4}\right)^{n-1}\right]}{1 - \frac{1}{4}} = 4 - \frac{3}{4^{n-1}}\text{ (J)}

    做法四：进阶二级结论法——柯尼希定理正交能量分解（“双能量桶”模型）

    思维路标：这是竞赛和强基中非常优雅的视角（核心只用到一个两体动能分解公式 / 柯尼希定理）。它把三体系统总动能正交拆成两个互不干扰的“能量桶”——一个装“B 与 (A+C) 整体的动能”，另一个装“A 与 C 内部相对动能”。瞬间看清每次碰撞和摩擦到底在干什么！

    第一步：2 行证明本题所需的二级结论（三等质量零动量系统的动能正交分解）

    对任意总动量为零的三个等质量物体（v_A + v_B + v_C = 0）：

    记 (A, C) 的相对速度为 v_{\text{rel}} = v_A - v_C。由于 v_A + v_C = -v_B，把两式相加、相减，解得：

    v_A = \frac{-v_B + v_{\text{rel}}}{2}，\quad v_C = \frac{-v_B - v_{\text{rel}}}{2}

    直接代入三体总动能 E_{\text{总}} = \frac{1}{2}m(v_A^2 + v_C^2 + v_B^2)（利用 (a+b)^2 + (a-b)^2 = 2(a^2+b^2)）：

    v_A^2 + v_C^2 = \frac{2(v_B^2 + v_{\text{rel}}^2)}{4} = \frac{v_B^2 + v_{\text{rel}}^2}{2}

    于是系统总动能瞬间分解为两个完全独立的平方项：

    E_{\text{总}} = \frac{1}{2}m\left(v_B^2 + \frac{v_B^2 + v_{\text{rel}}^2}{2}\right) = \underbrace{\frac{3}{4}m v_B^2}_{E_{\text{外}}} + \underbrace{\frac{1}{4}m(v_A - v_C)^2}_{E_{\text{内}}}

    _(注：从柯尼希定理看，E_{\text{外}} 就是 B 与 (A+C) 质心间的相对动能，约化质量 \mu_{B,AC} = \frac{m\cdot 2m}{3m} = \frac{2}{3}m，相对速度 v_B - v_{AC} = \frac{3}{2}v_B，故 \frac{1}{2}\mu_{B,AC}(\frac{3}{2}v_B)^2 = \frac{3}{4}m v_B^2；而 E_{\text{内}} 是 (A, C) 系统的内能，约化质量 \mu_{AC} = \frac{m}{2}，故 \frac{1}{2}\mu_{AC} v_{\text{rel}}^2 = \frac{1}{4}m(v_A - v_C)^2。)_

    第二步：微元/积分验证“摩擦只烧 E_{\text{内}}，不动 E_{\text{外}}”

    （利用这一物理结构，甚至可以直接看到摩擦生热微元的去向）：

    在 A 与 C 滑动的微元时间 dt 内：

    • B 不受任何力，dv_B = 0 \implies dE_{\text{外}} = 0，外桶能量严格守恒！

    • 对 E_{\text{内}} = \frac{1}{4}m v_{\text{rel}}^2 求微分：dE_{\text{内}} = \frac{1}{2}m v_{\text{rel}} \, d v_{\text{rel}}。因 A 左滑时 v_{\text{rel}} = v_A - v_C < 0，且 a_A = \frac{f}{m}, a_C = -\frac{f}{m} \implies d v_{\text{rel}} = (a_A - a_C)dt = \frac{2f}{m}dt。代入得：

      dE_{\text{内}} = \frac{1}{2}m v_{\text{rel}} \cdot \frac{2f}{m}dt = f v_{\text{rel}} dt = -f |dx_{\text{rel}}|

      积分到共速（v_{\text{rel}} = 0，如做法二已证明共速必在下次碰撞前完成），内桶能量 E_{\text{内}} 被摩擦力 100\% 消耗归零，全部转化为摩擦内能！

    第三步：两句话算完所有碰撞（能量在两个桶之间的分配法则）

    现在看整个物理过程，简直就像看水流一样清晰：

    1. 爆炸后瞬间（初态）：v_B = 2，v_A = -2，v_C = 0 \implies v_{\text{rel}} = -2。

      • E_{\text{外},0} = \frac{3}{4}(1)(2)^2 = 3\text{ J}

      • E_{\text{内},0} = \frac{1}{4}(1)(-2)^2 = 1\text{ J}

      第 1 次碰撞前，内桶的 1\text{ J} 被烧光，只剩下外桶的 E_{\text{总},1^-} = 3\text{ J}。

    2. 任意第 k 次弹性碰撞（k \ge 1）：

      • 碰撞前瞬间，A、C 已共速，故 E_{\text{内}} = 0，全部总能量都在外桶里：E_{\text{总},k^-} = E_{\text{外},k^-} = \frac{3}{4}m v_{B,k^-}^2，且被撞对象（C 或 A）的速度等于 u = -\frac{1}{2}v_{B,k^-}。

      • 碰撞瞬间（弹性碰撞总能量守恒！），B 与对方交换速度，使得 v_{B,k^+} = -\frac{1}{2}v_{B,k^-}。因此碰后瞬间，外桶剩下的能量立刻缩水为：

        E_{\text{外},k^+} = \frac{3}{4}m\left(-\frac{1}{2}v_{B,k^-}\right)^2 = \frac{1}{4}E_{\text{总},k^-}

      • 由总能量在碰撞瞬间守恒，外桶少掉的 \frac{3}{4}E_{\text{总},k^-} 必然全部挤进了内桶（E_{\text{内},k^+} = \frac{3}{4}E_{\text{总},k^-}），随后在下次碰撞前被摩擦力彻底烧光！

    也就是说：第 1 次碰撞前剩 3\text{ J}；此后每碰撞一次，只有 \frac{1}{4} 的机械能留在外桶带入下一次碰撞，另外 \frac{3}{4} 全部转入内桶并在碰前耗散掉！

    因此，第 n 次碰撞前系统剩余机械能为 3 \times \left(\frac{1}{4}\right)^{n-1}\text{ J}，损失的机械能为：

    E = 4 - \frac{3}{4^{n-1}}\text{ (J)}

    四种做法横向对比与总结（帮你以后快速选路）

    做法核心物理思想 / 工具计算量思维难度适用场景与考场建议
    做法一：过程暴力演绎运动学公式 + 逐段摩擦生热 + 等比数列求和较大低（最直觉）最稳妥的“保底法”，也能解释清楚为什么题干专门写 n>2。
    做法二：状态代替过程\Delta E_{\text{损}} = E_{\text{初}} - E_{\text{末}} + 局部/全局动量守恒极小中考场最推荐的规范解答！ 完全用纯高中课内知识，避开了位移和求和，步骤极短不易算错。
    做法三：v-t 图像几何法速度图线斜率对称 + 相似三角形面积比极小中图像直觉极强时首选，能把“不提前碰撞检验”和“面积等比”直观地画在纸上。
    做法四：双能量桶正交分解柯尼希定理 + 约化质量内能分解 + 微元微分最小略高（需二级结论）强基/竞赛/高水平玩家大杀器，直接透视出多体系统的能量分配本质（\frac{1}{4} 留存，\frac{3}{4} 耗散）。

    你可以重点消化做法二的思维转折点（“不累加每次的热量，改用局部动量守恒递推共速，只算末状态动能”），今后遇到多体多次碰撞或往复滑动的耗能压轴题，把过程量转化为首末状态量，思维链和计算量都会瞬间砍掉一大半。
