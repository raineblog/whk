    2022济宁一模物理18题

    本文详解2022年济宁一模物理18题，剖析多体多过程、摩擦突变与弹性碰撞的高中物理压轴题。运用分段法、隔离法及v-t图像验算，拆解四问求解步骤，助考生掌握受力分析与状态转折判断技巧，提升压轴题解题能力。

    这是一道非常经典的多体、多过程、含摩擦突变与连续弹性碰撞的高中物理压轴计算题。解决此类问题的核心在于理清每个物理阶段的受力与相对运动方向，精准捕捉状态转折点。

    一、 核心思想方法与破题关键

    在动笔列式前，先运用《高中物理思想方法导引》中的核心思维拆解本题的物理内核：

    1. 隐藏的“黄金条件”（摩擦力临界数值）：

      已知 \theta = 30^\circ，\mu = \frac{\sqrt{3}}{3} = \tan 30^\circ，且 M = m = 0.5\,\text{kg}。

      一旦物块 B 与凹槽 A 发生相对滑动，两者间的滑动摩擦力大小为：

      f = \mu mg\cos\theta = \frac{\sqrt{3}}{3} \times mg \cdot \frac{\sqrt{3}}{2} = \frac{1}{2}mg = mg\sin 30^\circ = 2.5\,\text{N}

      而 A、B 各自的重力沿斜面向下的分力也恰为：

      G_{Ax} = Mg\sin 30^\circ = 2.5\,\text{N}, \quad G_{Bx} = mg\sin 30^\circ = 2.5\,\text{N}

      结论：只要两者发生相对滑动，必有一方所受摩擦力方向沿斜面向上，从而受力平衡（加速度为 0，做匀速运动）；另一方所受摩擦力方向沿斜面向下，合力加倍（加速度为 2g\sin 30^\circ = 10\,\text{m/s}^2，沿斜面向下）！这极大简化了计算。

    2. 本题调动的核心方法：

      • 分段法（方法2） 与 隔离法（方法11）：以每次碰撞为界划分阶段，对 A、B 隔离受力分析；

      • 摩擦力突变分析法（方法4）：每次碰撞后 A、B 相对速度方向反转，导致滑动摩擦力方向发生“动—动突变”；

      • 共速对称法 / 弹性碰撞规律（方法36）：m=M 发生一维弹性碰撞时，两者交换速度；

      • 追及相遇模型（方法3） 与 运动学图像应用法 / 思维可视化法（方法1、68）：利用相对运动方程和 v-t 图像面积差验证各阶段位移与碰撞时刻。

    二、 分阶段详细求解

    为方便描述，统一规定沿斜面向下为正方向（或者在具体阶段标明方向，以下列式均严格指明矢量方向）。

    第 (1) 问：凹槽与挡板发生第一次碰撞前瞬间物块的速度大小

    • 物理过程（阶段一：0 \sim t_1）：

      t=0 时撤去外力，假设 A、B 一起沿斜面向下自由下滑。

      对 A、B 整体，由牛顿第二定律（斜面光滑）：

      (M+m)g\sin\theta = (M+m)a_0 \implies a_0 = g\sin 30^\circ = 10 \times 0.5 = 5\,\text{m/s}^2

      隔离物块 B 分析：若 B 具有 a_0 = g\sin\theta 的加速度，重力分力 mg\sin\theta 恰好全部用来提供加速度，故 A、B 间既无弹力也无摩擦力，两者完全无相对运动，一起做初速度为 0、加速度为 5\,\text{m/s}^2 的匀加速直线运动。

    • 运动学计算：

      凹槽 A 下滑距离 x_0 = 2.5\,\text{m} 与挡板 P 发生第一次碰撞。设碰撞前瞬间速度为 v_0，所用时间为 t_1：

      x_0 = \frac{1}{2}a_0 t_1^2 \implies 2.5 = \frac{1}{2} \times 5 \times t_1^2 \implies t_1 = 1\,\text{s}

      v_0 = a_0 t_1 = 5 \times 1 = 5\,\text{m/s}

      （或直接用 v_0^2 = 2a_0 x_0 算得 v_0 = \sqrt{2 \times 5 \times 2.5} = 5\,\text{m/s}）。

    第 (1) 问答案：凹槽与挡板发生第一次碰撞前瞬间物块的速度大小为 5\,\text{m/s}。

    第 (2) 问：凹槽的长度 L

    • 碰撞分析（t_1 = 1\,\text{s} 时刻）：

      A 与固定挡板 P 发生弹性碰撞且时间极短。碰撞后瞬间：

      • 凹槽 A 原速反弹，速度 v_{A1} = 5\,\text{m/s}（沿斜面向上）；

      • 物块 B 处于凹槽上端（内侧），未与凹槽端壁发生碰撞，速度保持 v_{B1} = 5\,\text{m/s}（沿斜面向下）。

    • 物理过程（阶段二：t_1 = 1\,\text{s} \sim t_2 = 1.5\,\text{s}）：

      碰撞后，A 向上运动、B 向下运动，因此 B 相对 A 沿斜面向下滑动。由隔离法分别分析受力：

      • 对物块 B：受沿斜面向下的重力分力 mg\sin 30^\circ = 2.5\,\text{N}，以及沿斜面向上的滑动摩擦力 f = \mu mg\cos 30^\circ = 2.5\,\text{N}。

        a_B = \frac{mg\sin 30^\circ - f}{m} = 0

        故 B 沿斜面向下做匀速直线运动，速度恒为 v_B = 5\,\text{m/s}。

      • 对凹槽 A：受沿斜面向下的重力分力 Mg\sin 30^\circ = 2.5\,\text{N}，以及 B 对 A 沿斜面向下的反作用摩擦力 f' = f = 2.5\,\text{N}。

        a_A = \frac{Mg\sin 30^\circ + f'}{M} = \frac{2.5 + 2.5}{0.5} = 10\,\text{m/s}^2 \quad (\text{方向沿斜面向下})

        故 A 先沿斜面向上做初速度为 5\,\text{m/s}、加速度大小为 10\,\text{m/s}^2 的匀减速直线运动。

    • 运动状态判定与位移计算：

      由题意，t_2 = 1.5\,\text{s} 时 B 与 A 发生第一次碰撞（即 B 滑到凹槽 A 下端挡板处），此过程历经时间：

      \Delta t_1 = t_2 - t_1 = 1.5 - 1.0 = 0.5\,\text{s}

      先检验 A 在此 \Delta t_1 = 0.5\,\text{s} 内的速度变化：

      v_{A2} = v_{A1} - a_A \Delta t_1 = 5 - 10 \times 0.5 = 0

      巧合检验：在 t_2 = 1.5\,\text{s} 时，凹槽 A 恰好向上减速到最高点（速度刚好为 0），整个 \Delta t_1 过程中 A 始终向上运动，B 始终向下运动，两者相对运动方向从未改变，摩擦力方向保持不变！

      分别计算这段时间内 A 向上的位移 x_{A1} 和 B 向下的位移 x_{B1}：

      x_{A1} = v_{A1}\Delta t_1 - \frac{1}{2}a_A \Delta t_1^2 = 5 \times 0.5 - \frac{1}{2} \times 10 \times 0.5^2 = 1.25\,\text{m}

      x_{B1} = v_{B1}\Delta t_1 = 5 \times 0.5 = 2.5\,\text{m}

      因为 t_1 时刻 B 在 A 的上端，t_2 时刻 B 撞击到 A 的下端（两端挡板厚度不计），所以两者相向运动的路程之和即为凹槽长度 L：

      L = x_{A1} + x_{B1} = 1.25 + 2.5 = 3.75\,\text{m}

    第 (2) 问答案：凹槽的长度为 3.75\,\text{m}。

    第 (3) 问：凹槽与挡板发生第二次碰撞时，物块到挡板 P 的距离

    • 碰撞分析（t_2 = 1.5\,\text{s} 时刻，B 与 A 第一次碰撞）：

      碰前瞬间：B 的速度 v_{B2} = 5\,\text{m/s}（向下），A 的速度 v_{A2} = 0。

      由于是时间极短的弹性碰撞，且摩擦力和重力冲量可忽略，沿斜面方向系统动量守恒、机械能守恒：

      mv_{B2} = mv_{B2}' + Mv_{A2}'

      \frac{1}{2}mv_{B2}^2 = \frac{1}{2}mv_{B2}'^2 + \frac{1}{2}Mv_{A2}'^2

      利用共速对称法（或等质量弹性碰撞结论 m=M 交换速度）：

      v_{\text{共}} = \frac{mv_{B2}}{M+m} = 2.5\,\text{m/s} \implies v_{B2}' = 2v_{\text{共}} - v_{B2} = 0, \quad v_{A2}' = 2v_{\text{共}} - 0 = 5\,\text{m/s}

      即碰后瞬间：B 静止（v_{B2}' = 0），A 获得 v_{A2}' = 5\,\text{m/s} 的速度沿斜面向下运动。

    • 物理过程（阶段三：t_2 = 1.5\,\text{s} \sim t_3）：

      碰后瞬间，A 向下运动而 B 速度为 0，因此 B 相对 A 沿斜面向上滑动（摩擦力发生方向突变！）。

      • 对凹槽 A：受沿斜面向下的重力分力 Mg\sin 30^\circ = 2.5\,\text{N}，以及 B 对 A 沿斜面向上的摩擦力 f' = 2.5\,\text{N}。

        a_A' = \frac{Mg\sin 30^\circ - f'}{M} = 0

        故 A 以 v_{A2}' = 5\,\text{m/s} 沿斜面向下做匀速直线运动。

      • 对物块 B：受沿斜面向下的重力分力 mg\sin 30^\circ = 2.5\,\text{N}，以及 A 对 B 沿斜面向下的滑动摩擦力 f = 2.5\,\text{N}。

        a_B' = \frac{mg\sin 30^\circ + f}{m} = \frac{2.5 + 2.5}{0.5} = 10\,\text{m/s}^2 \quad (\text{方向沿斜面向下})

        故 B 从静止开始以 10\,\text{m/s}^2 沿斜面向下做匀加速直线运动。

    • 追及碰撞计算：

      t_2 时刻，A 下端距离挡板 P 的距离为 x_{A1} = 1.25\,\text{m}。

      A 匀速下滑到挡板 P（发生第二次 A-P 碰撞）所需的时间 \Delta t_2 为：

      \Delta t_2 = \frac{x_{A1}}{v_{A2}'} = \frac{1.25}{5} = 0.25\,\text{s}

      状态检验：在 \Delta t_2 = 0.25\,\text{s} 末（即 t_3 = 1.5 + 0.25 = 1.75\,\text{s} 时），B 的速度为：

      v_{B3} = a_B' \Delta t_2 = 10 \times 0.25 = 2.5\,\text{m/s} < 5\,\text{m/s}

      且这段时间内 B 相对 A 向上滑动的距离为 1.25 - \frac{1}{2} \times 10 \times 0.25^2 = 0.9375\,\text{m} < L = 3.75\,\text{m}。说明在 A 撞击挡板 P 前，B 既没有追上 A 的速度，也没有撞到 A 的上端壁，受力一直不变！

      此时 B 沿斜面向下移动的距离为：

      x_{B2} = \frac{1}{2}a_B' \Delta t_2^2 = \frac{1}{2} \times 10 \times 0.25^2 = 0.3125\,\text{m} \left(\text{即 }\frac{5}{16}\,\text{m}\right)

      A 下端刚好接触挡板 P，故此时物块 B 到挡板 P 的距离 d 为：

      d = x_{A1} - x_{B2} = 1.25 - 0.3125 = 0.9375\,\text{m} \left(\text{即 }\frac{15}{16}\,\text{m}\right)

    第 (3) 问答案：凹槽与挡板发生第二次碰撞时，物块到挡板 P 的距离为 0.9375\,\text{m}（或 \frac{15}{16}\,\text{m}）。

    第 (4) 问：从 t=0 到物块与凹槽发生第二次碰撞时所用的时间

    • 碰撞分析（t_3 = 1.75\,\text{s} 时刻，A 与挡板 P 第二次碰撞）：

      A 以 5\,\text{m/s} 撞击固定挡板 P 后原速反弹：

      • A 的速度变为 v_{A3}' = 5\,\text{m/s}（沿斜面向上）；

      • B 的速度保持 v_{B3} = 2.5\,\text{m/s}（沿斜面向下）；

      • 此时 B 在 A 下端上方距离 d = \frac{15}{16}\,\text{m} 处。

    • 物理过程（阶段四：t_3 = 1.75\,\text{s} \sim t_4）：

      与阶段二完全同理，A 向上运动、B 向下运动，B 相对 A 向下滑动（摩擦力再次突变）：

      • 物块 B 受力平衡（a_B'' = 0），以 v_{B3} = 2.5\,\text{m/s} 沿斜面向下做匀速直线运动；

      • 凹槽 A 沿斜面向上做初速度 v_{A3}' = 5\,\text{m/s}、沿斜面向下加速度 a_A'' = 10\,\text{m/s}^2 的匀减速直线运动。

    • 建立追及相遇方程：

      设从 t_3 时刻起，再经过时间 \Delta t_3 后 B 与 A 发生第二次碰撞（相向相遇）。

      以 P 为原点、沿斜面向上为正方向，两者位移坐标相等时发生碰撞（或直接用两者相向位移之和等于间距 d）：

      x_{A3} + x_{B3} = d

      即：

      \left(v_{A3}' \Delta t_3 - \frac{1}{2}a_A'' \Delta t_3^2\right) + v_{B3}\Delta t_3 = d

      代入数据 v_{A3}' = 5\,\text{m/s}，a_A'' = 10\,\text{m/s}^2，v_{B3} = 2.5\,\text{m/s}，d = \frac{15}{16}\,\text{m}：

      5\Delta t_3 - 5\Delta t_3^2 + 2.5\Delta t_3 = \frac{15}{16}

      整理得：

      7.5\Delta t_3 - 5\Delta t_3^2 = \frac{15}{16}

      两边同乘以 16 并化简（同除以 5）：

      16\Delta t_3^2 - 24\Delta t_3 + 3 = 0

      由求根公式解得：

      \Delta t_3 = \frac{24 \pm \sqrt{24^2 - 4 \times 16 \times 3}}{32} = \frac{24 \pm \sqrt{384}}{32} = \frac{24 \pm 8\sqrt{6}}{32} = \frac{3 \pm \sqrt{6}}{4}\,\text{s}

    • 舍根检验（物理意义判定）：

      若取较大根 \Delta t_3' = \frac{3+\sqrt{6}}{4} \approx 1.35\,\text{s}，在此之前两者早已在较小的正根时刻发生了碰撞，碰撞后运动规律发生改变，且若不碰撞 B 也早已穿过挡板 P，故舍去较大根，只取：

      \Delta t_3 = \frac{3 - \sqrt{6}}{4}\,\text{s}

      检验较小根的物理有效性：代入 \sqrt{6} = 2.4，得：

      \Delta t_3 = \frac{3 - 2.4}{4} = 0.15\,\text{s}

      • 此时凹槽 A 的速度为 v_A = 5 - 10 \times 0.15 = 3.5\,\text{m/s} > 0，仍处于向上减速过程中，未到最高点；

      • 此时 B 向下移动了 2.5 \times 0.15 = 0.375\,\text{m} < d = 0.9375\,\text{m}，说明碰撞发生在挡板 P 上方，未到达 P。

      因此全部前提假设均严格成立！

    • 计算总时间：

      t_{\text{总}} = t_1 + \Delta t_1 + \Delta t_2 + \Delta t_3 = 1 + 0.5 + 0.25 + \frac{3 - \sqrt{6}}{4} = \frac{10 - \sqrt{6}}{4}\,\text{s}

      代入 \sqrt{6} = 2.4：

      t_{\text{总}} = 1.75 + 0.15 = 1.9\,\text{s}

    第 (4) 问答案：从开始自由下滑到物块与凹槽发生第二次碰撞所用的时间为 1.9\,\text{s}（精确解析式为 \frac{10-\sqrt{6}}{4}\,\text{s}）。

    三、 思维可视化复盘：v-t 图像验算（方法1、68）

    在考场上，对于这种多阶段往返问题，可以用“以沿斜面向下为正方向的 v-t 图像”快速核对每一问，避免符号出错：

    时间段凹槽 A 的速度变化与图线特征物块 B 的速度变化与图线特征图像面积差含义与数值验证
    0 \sim 1.0\,\text{s}0 \to +5\,\text{m/s}（斜率 +5）与 A 重合各自面积 \frac{1}{2}\times 1\times 5 = 2.5\,\text{m} = x_0
    t = 1.0\,\text{s}A 撞 P 突变：+5 \to -5\,\text{m/s}保持 +5\,\text{m/s}—
    1.0 \sim 1.5\,\text{s}-5 \to 0\,\text{m/s}（斜率 +10）水平线 +5\,\text{m/s}B 面积 2.5，A 面积 -1.25；面积差 2.5 - (-1.25) = 3.75\,\text{m} = L
    t = 1.5\,\text{s}A、B 弹性碰撞互换速度：A 跳至 +5B 跳至 0—
    1.5 \sim 1.75\,\text{s}水平线 +5\,\text{m/s}0 \to +2.5\,\text{m/s}（斜率 +10）A 下移面积 +1.25\,\text{m} 回到 P；B 下移面积 \frac{1}{2}\times 0.25\times 2.5 = 0.3125\,\text{m}；间距 d = 1.25 - 0.3125 = 0.9375\,\text{m}
    t = 1.75\,\text{s}A 撞 P 突变：+5 \to -5\,\text{m/s}保持 +2.5\,\text{m/s}—
    1.75 \sim 1.9\,\text{s}-5 \to (-5 + 10\Delta t_3)水平线 +2.5\,\text{m/s}面积差 \int_0^{\Delta t_3} [2.5 - (-5+10t)]\,dt = 7.5\Delta t_3 - 5\Delta t_3^2 = \frac{15}{16} \implies \Delta t_3 = 0.15\,\text{s}

    通过“受力隔离 \to 阶段拆分 \to v-t 图像面积校核”的组合拳，即可确保 16 分大题每一步都稳妥无误。
