要彻底吃透第 (2)(ii) 问，我们先花一分钟把物理舞台和核心参数锚定好（这部分是所有解法的共同基础）。

### 前置锚点：建系、参数与碰撞规则

建立固定于地面的直角坐标系：取圆柱初位置 O 为原点，初速度 v_2=2\\text{ m/s} 的方向（木板中轴线向上）为 +y 轴，木板短边向右为 +x 轴。

1. **动力学基础参数**：

   - 滑动摩擦力大小：f = \\mu mg = 0.2 \\times 1 \\times 10 = 2\\text{ N}。
   - 圆柱加速度大小：a_m = \\frac{f}{m} = \\mu g = 2\\text{ m/s}^2；木板加速度大小：a_M = \\frac{f}{M} = \\frac{2}{4} = 0.5\\text{ m/s}^2。
   - 相对加速度大小（当两物体加速度反向时）：a\_{\\text{相}} = a_m + a_M = 2.5\\text{ m/s}^2。
   - 系统初动能：E\_{k0} = \\frac{1}{2}m v_2^2 = \\frac{1}{2}\\times 1 \\times 2^2 = 2\\text{ J}。

1. **碰撞瞬间的速度变化（用正交分解推导，不靠猜）**：

   图乙中挡板与 +x 轴（木板短边）夹角为 45^\\circ（左上—右下走向）。取平行挡板斜向右下方向为切向单位矢量 \\hat{t}\_0 = \\frac{1}{\\sqrt{2}}(1, -1)，垂直挡板指向左下方向为法向单位矢量 \\hat{n}\_0 = \\frac{1}{\\sqrt{2}}(-1, -1)。

   设碰撞前瞬间圆柱的速度为 \\vec{v}\_{m1} = (0, v_1)（其中 v_1 > 0）。将其沿切向和法向分解：

   \\vec{v}\_{m1} = -\\frac{v_1}{\\sqrt{2}}\\hat{t}\_0 - \\frac{v_1}{\\sqrt{2}}\\hat{n}\_0

   由于与固定光滑竖直挡板发生**弹性碰撞**，切向速度分量保持不变，法向速度分量等大反向，因此碰撞后瞬间圆柱的速度为：

   \\vec{v}\_{m1}' = -\\frac{v_1}{\\sqrt{2}}\\hat{t}\_0 + \\frac{v_1}{\\sqrt{2}}\\hat{n}\_0 = \\left(-\\frac{v_1}{2}-\\frac{v_1}{2},\\ \\frac{v_1}{2}-\\frac{v_1}{2}\\right) = (-v_1, 0)

   即：**弹性碰撞把圆柱的速度大小维持为 v_1，方向从 +y（向上）精确偏转为 -x（水平向左）**。而挡板不与木板接触，木板在碰撞瞬间的速度保持 \\vec{v}_{M1} = (0, v_{M1}) 不变。

1. **几何红线（d=1\\text{ m} 的约束）**：

   圆柱初始在中轴线上，木板只平动不旋转，故碰撞后圆柱相对木板向左（-x 方向）移动的最大安全距离为 \\frac{d}{2} = 0.5\\text{ m}。一旦相对位移 |\\Delta x\_{\\text{相}}| > 0.5\\text{ m}，圆柱就会在共速前从木板左侧掉落，摩擦力归零，停止生热。

### 解法一：高中物理常规“暴力”通法（分段动力学 + 相对路程硬算 + 极值讨论）

**核心策略**：严格按照时间先后拆分运动过程，利用相对位移算出第一段生热 Q_1 与第二段生热 Q_2，再通过分类讨论排除干扰情形。为了防止中间出现一堆带根号的 L，我们**先选定碰前瞬间的圆柱速度 v_1 作为“黄金中间变量”**，算出最优 v_1 后再反推 L。

#### 第一步：分析碰撞前阶段（一维滑块-木板模型）

圆柱以初速度 v_2=2\\text{ m/s} 沿 +y 做匀减速运动，木板从静止开始沿 +y 做匀加速运动。

1. **先找“碰前是否共速”的临界点**：

   假设圆柱在撞到挡板前就已经和木板达到共速 v\_{\\text{共}0}。

   共速所需时间 t_0 满足：

   v_2 - a_m t_0 = a_M t_0 \\implies 2 - 2t_0 = 0.5t_0 \\implies t_0 = 0.8\\text{ s}

   此时共同速度 v\_{\\text{共}0} = a_M t_0 = 0.5 \\times 0.8 = 0.4\\text{ m/s}，圆柱对地走过的距离为：

   L_0 = \\frac{v_2 + v\_{\\text{共}0}}{2} t_0 = \\frac{2 + 0.4}{2} \\times 0.8 = 0.96\\text{ m}

   因此，必须按 L < 0.96\\text{ m} 与 L \\ge 0.96\\text{ m} 分两类讨论。

1. **先算情形 A：0 < L < 0.96\\text{ m}（碰前未共速）**：

   由运动学公式 v_1^2 - v_2^2 = -2a_m L，代入 v_2=2,\\ a_m=2：

   v_1^2 = 4 - 4L \\implies L = 1 - \\frac{v_1^2}{4} \\quad \\text{其中 } v_1 \\in (0.4,\\ 2)\\text{ m/s}

   碰前运动时间 t_1 = \\frac{v_2 - v_1}{a_m} = \\frac{2 - v_1}{2}。

   碰前瞬间木板速度：

   v\_{M1} = a_M t_1 = 0.5 \\times \\frac{2 - v_1}{2} = \\frac{2 - v_1}{4}

   碰前木板对地位移：

   y\_{M1} = \\frac{0 + v\_{M1}}{2} t_1 = \\frac{1}{2} \\cdot \\frac{2 - v_1}{4} \\cdot \\frac{2 - v_1}{2} = \\frac{(2 - v_1)^2}{16}

   于是碰前圆柱相对木板滑动的距离 \\Delta y_1 = L - y\_{M1}：

   \\Delta y_1 = \\left(1 - \\frac{v_1^2}{4}\\right) - \\frac{4 - 4v_1 + v_1^2}{16} = \\frac{16 - 4v_1^2 - 4 + 4v_1 - v_1^2}{16} = \\frac{12 + 4v_1 - 5v_1^2}{16}

   所以第一阶段产生的摩擦热为：

   Q_1 = f \\Delta y_1 = 2 \\times \\frac{12 + 4v_1 - 5v_1^2}{16} = \\frac{12 + 4v_1 - 5v_1^2}{8}

#### 第二步：分析碰撞后阶段（二维相对运动与“共线减速度”论证）

碰撞后瞬间，圆柱速度 \\vec{v}_{m1}' = (-v_1, 0)，木板速度 \\vec{v}_{M1}' = (0, v\_{M1})，则圆柱相对于木板的初速度为：

\\vec{v}_{\\text{相}1}' = \\vec{v}_{m1}' - \\vec{v}_{M1}' = (-v_1,\\ -v_{M1})

- **为什么碰撞后摩擦力方向保持不变？**

  在碰撞后的任意时刻，只要尚未共速或掉落，滑动摩擦力 \\vec{f} 始终与瞬时相对速度 \\vec{v}_{\\text{相}} 反向。设 \\vec{v}_{\\text{相}} 方向的单位矢量为 \\hat{e}，则圆柱加速度 \\vec{a}\_m = -\\frac{f}{m}\\hat{e}，木板加速度 \\vec{a}\_M = +\\frac{f}{M}\\hat{e}，故相对加速度为：

  \\vec{a}\_{\\text{相}} = \\vec{a}\_m - \\vec{a}\_M = -\\left(\\frac{f}{m} + \\frac{f}{M}\\right)\\hat{e} = -2.5\\hat{e}

  可见 \\vec{a}_{\\text{相}} 始终与 \\vec{v}_{\\text{相}} 反向共线，垂直于 \\vec{v}_{\\text{相}} 方向没有任何加速度分量，因此\*\*整个碰撞后的滑动过程中，\\vec{v}_{\\text{相}} 的方向永远不变\*\*，相对运动就是一个“方向不变的匀减速直线运动”，相对加速度大小恒为 a\_{\\text{相}} = 2.5\\text{ m/s}^2！

设 \\vec{v}\_{\\text{相}1}' 与 -x 轴夹角为 \\alpha，则：

v\_{\\text{相}1}' = \\sqrt{v_1^2 + v\_{M1}^2}, \\qquad \\cos\\alpha = \\frac{v_1}{\\sqrt{v_1^2 + v\_{M1}^2}}

假设木板足够宽（先不考虑掉落），圆柱与木板一直相对滑动至相对速度为零，其总相对路程为：

\\Delta s_2 = \\frac{(v\_{\\text{相}1}')^2}{2a\_{\\text{相}}} = \\frac{v_1^2 + v\_{M1}^2}{5}

该过程向左（-x 方向）的相对位移大小为：

|\\Delta x_2| = \\Delta s_2 \\cos\\alpha = \\frac{v_1^2 + v\_{M1}^2}{5} \\cdot \\frac{v_1}{\\sqrt{v_1^2 + v\_{M1}^2}} = \\frac{v_1 \\sqrt{v_1^2 + v\_{M1}^2}}{5}

#### 第三步：分“不掉落”与“掉落”求解并合并极值

1. **子分支 A1：若不掉落（|\\Delta x_2| \\le 0.5\\text{ m}）**：

   第二阶段生热为：

   Q_2 = f \\Delta s_2 = 2 \\times \\frac{v_1^2 + v\_{M1}^2}{5}

   把 v\_{M1} = \\frac{2 - v_1}{4} 代入并通分：

   Q_2 = \\frac{2}{5} \\left[ v_1^2 + \\frac{(2 - v_1)^2}{16} \\right] = \\frac{16v_1^2 + 4 - 4v_1 + v_1^2}{40} = \\frac{17v_1^2 - 4v_1 + 4}{40}

   将 Q_1（分子分母同乘 5 化为同分母 40）与 Q_2 相加，得总摩擦热：

   Q = Q_1 + Q_2 = \\frac{60 + 20v_1 - 25v_1^2}{40} + \\frac{17v_1^2 - 4v_1 + 4}{40} = \\frac{-8v_1^2 + 16v_1 + 64}{40}

   分子分母同除以 8 并配方：

   Q = \\frac{-v_1^2 + 2v_1 + 8}{5} = \\frac{9 - (v_1 - 1)^2}{5} = 1.8 - \\frac{(v_1 - 1)^2}{5}

   抛物线开口向下，对称轴 v_1 = 1\\text{ m/s} 恰好在 (0.4,\\ 2) 内。此时校核“不掉落条件”：

   - 当 v_1 = 1\\text{ m/s} 时，v\_{M1} = \\frac{2 - 1}{4} = 0.25\\text{ m/s}。
   - |\\Delta x_2| = \\frac{1 \\times \\sqrt{1^2 + 0.25^2}}{5} = \\frac{\\sqrt{1.0625}}{5} < \\frac{\\sqrt{2.25}}{5} = 0.3\\text{ m} < 0.5\\text{ m}，安全留在木板上！
   - 对应 L = 1 - \\frac{1^2}{4} = 0.75\\text{ m}，总摩擦热 Q\_{\\max} = 1.8\\text{ J}。

1. **子分支 A2：若发生掉落（|\\Delta x_2| > 0.5\\text{ m}），能否超过 1.8\\text{ J}？**

   完全不需要去解四次方程求掉落临界点！看物理逻辑：

   - 发生掉落意味着相对位移在 -x 方向刚达到 0.5\\text{ m} 时就脱离了木板，而此时尚未共速（若能一直不掉落，它会沿同方向继续滑动至 |\\Delta x_2| > 0.5\\text{ m} 才停止），故掉落前的实际相对路程 \\Delta s_2' < \\Delta s_2，实际生热 Q_2' = f\\Delta s_2' < Q_2。

   - 又因为 v_1 = 1 时不掉落（0.206 < 0.5），所以任何能导致掉落的 v_1 必满足 v_1 \\neq 1。从而：

     Q\_{\\text{掉}} = Q_1 + Q_2' < Q_1 + Q_2 = 1.8 - \\frac{(v_1 - 1)^2}{5} < 1.8\\text{ J}

   严格排除了掉落情形！

1. **再看情形 B：L \\ge 0.96\\text{ m}（碰前已共速）**：

   一旦 L \\ge 0.96\\text{ m}，圆柱在 0.96\\text{ m} 处就已与木板共速（v\_{\\text{共}0}=0.4\\text{ m/s}），之后匀速滑至 P 点碰撞，不再生热。整个过程的生热与情形 A 的端点 v_1 = 0.4\\text{ m/s} 完全一致（此时 |\\Delta x_2| = \\frac{0.4\\sqrt{0.32}}{5} \\approx 0.045 < 0.5\\text{ m}，不会掉落）：

   Q = 1.8 - \\frac{(0.4 - 1)^2}{5} = 1.8 - 0.072 = 1.728\\text{ J} < 1.8\\text{ J}

**结论**：综上，当 L = 0.75\\text{ m} 时，摩擦热最大，最大值为 1.8\\text{ J}。

### 解法二：经典思想转化法（“以状态代替过程” + 坐标变换分解法）

解法一虽然稳健，但又是算位移又是通分，计算链条很长。现在我们运用\*\*“以状态代替过程”**和**“坐标变换分解法”\*\*，跳过所有中间的加速度、时间、相对位移，直击始末状态。

#### 第一步：问题转化（用“末动能最小”代替“算两段路程生热”）

全过程中，固定挡板对圆柱做弹性碰撞（弹力不做功），木板与地面间光滑，唯一耗散机械能的只有木板与圆柱间的滑动摩擦力。因此，假设圆柱最终未掉出木板且与木板达到共同速度 \\vec{v}\_{\\text{终}}，由功能关系（总能量守恒），全部摩擦热必等于系统初、末总动能之差：

Q = E\_{k0} - E\_{k\\text{终}} = 2 - \\frac{1}{2}(m+M)v\_{\\text{终}}^2 = 2 - 2.5, v\_{\\text{终}}^2

于是，“求摩擦热 Q 最大”转化为“**求末态共速速度大小 v\_{\\text{终}} 最小**”。

#### 第二步：坐标变换分解（捕捉全过程唯一不变的守恒量）

不要用正南正北的 (x, y) 坐标系，而是建立**与挡板对齐的斜交正交坐标系**：

- 取平行于挡板向左上为 +t 轴（切向）；
- 取垂直于挡板向右上为 +n 轴（法向）。

检查全过程中“圆柱 + 木板”系统在这两个方向上受到的外力冲量：

1. 碰前与碰后：地面光滑，摩擦力是系统内力，系统在 t、n 两个方向合外力均为零；
1. 碰撞瞬间：光滑竖直挡板对圆柱的弹力**严格沿着 n 轴方向**，在**平行于挡板的 t 轴方向没有任何外力作用**！

这意味着：**从最开始到最终共速，系统在 t 方向的总动量 P_t 严格守恒！**

初速度 \\vec{v}\_2 沿 +y 轴，与 +t 轴和 +n 轴均成 45^\\circ 夹角，故系统 t 方向总动量恒为：

P_t = m v_2 \\cos 45^\\circ = 1 \\times 2 \\times \\frac{\\sqrt{2}}{2} = \\sqrt{2}\\text{ kg}\\cdot\\text{m/s}

因此无论 L 取何值，只要最终共速，末速度在 t 方向的分量就被死死锁定为：

v\_{\\text{终}, t} = \\frac{P_t}{m + M} = \\frac{\\sqrt{2}}{1 + 4} = \\frac{\\sqrt{2}}{5}\\text{ m/s}

#### 第三步：直接锁定热上限与取等条件

末速度平方满足 v\_{\\text{终}}^2 = v\_{\\text{终}, t}^2 + v\_{\\text{终}, n}^2 \\ge v\_{\\text{终}, t}^2 = \\frac{2}{25}。

代入总热公式，立得理论上限：

Q \\le 2 - 2.5 \\times \\frac{2}{25} = 2 - 0.2 = 1.8\\text{ J}

- **顺手秒杀掉落情形**：如果圆柱中途从边缘掉落，那么在脱离瞬间它与木板仍有相对速度，系统动能可分解为“质心平动动能（含 t 方向动能 0.2\\text{ J} 和 n 方向动能）+ 不为零的内部相对动能”，故脱离瞬间系统总动能必定**严格大于** 0.2\\text{ J}，即掉落时摩擦热一定严格小于 1.8\\text{ J}。

因此，要达到 1.8\\text{ J} 的最高极限，必须满足两个条件：**① 不掉落且共速；② 末态在垂直挡板方向的速度 v\_{\\text{终}, n} = 0（即碰撞后系统在 n 方向总动量 P_n' = 0）**。

接下来只需反解何时能让 P_n' = 0：

- 碰前瞬间，由系统在 y 方向动量守恒：m v_1 + M v\_{M1} = m v_2 \\implies v_1 + 4v\_{M1} = 2。

- 碰撞后瞬间，圆柱速度变为 (-v_1, 0)，木板速度仍为 (0, v\_{M1})，故碰撞后系统总动量矢量为：

  \\vec{P}' = m(-v_1, 0) + M(0, v\_{M1}) = (-v_1,\\ 4v\_{M1}) = (-v_1,\\ 2 - v_1)

- 而 n 方向沿 (1, 1) 单位矢量，要使 P_n' = \\vec{P}' \\cdot \\frac{(1, 1)}{\\sqrt{2}} = 0，只需两分量之和为零：

  (-v_1) + (2 - v_1) = 0 \\implies v_1 = 1\\text{ m/s}

#### 第四步：快速校核可行性与反解 L

1. **碰前能否达到 v_1 = 1\\text{ m/s}？**

   碰前共速速度为 v\_{\\text{共}0} = \\frac{m v_2}{m+M} = 0.4\\text{ m/s} < 1\\text{ m/s}，说明圆柱在到达 P 点前一直以 a_m = 2\\text{ m/s}^2 匀减速，故所需初始距离：

   L = \\frac{v_2^2 - v_1^2}{2 a_m} = \\frac{2^2 - 1^2}{2 \\times 2} = 0.75\\text{ m}

1. **碰后会不会掉出木板？**

   此时 v\_{M1} = \\frac{2 - 1}{4} = 0.25\\text{ m/s}。两物体相对运动时 a\_{\\text{相}} = 2.5\\text{ m/s}^2 且相对速度方向不变，向左相对位移大小：

   |\\Delta x_2| = \\frac{v_1 \\sqrt{v_1^2 + v\_{M1}^2}}{2a\_{\\text{相}}} = \\frac{1 \\times \\sqrt{1.0625}}{5} \\approx 0.206\\text{ m} < 0.5\\text{ m}

   不会掉出木板，完美取到全局最大值 1.8\\text{ J}！

### 解法三：新奇可视化方法——“动量空间垂线段最短法”

如果觉得斜交坐标系投影还不够直观，我们可以把这个问题**直接拍到平面几何里**，变成一道初中几何题：“求直线段上到原点距离最近的点”。

1. **写出碰撞后的系统总动量矢量**：

   - 系统初始总动量为定点 \\vec{P}\_0 = (0, 2)。

   - 在碰撞前，无论经过多少内力摩擦，总动量始终停留在 \\vec{P}\_0 = (0, 2)。

   - 碰撞瞬间，圆柱动量由 (0, v_1) 变为 (-v_1, 0)（因 m=1\\text{ kg}），木板动量不变。因此挡板给予整个系统的外力冲量矢量为：

     \\vec{I} = (-v_1, 0) - (0, v_1) = (-v_1,\\ -v_1)

     注意到随着 L 从 0 增大到 0.96\\text{ m}（及更大），v_1 的取值范围是 [0.4,\\ 2]。

   - 碰撞后不再受外力，如果未掉落直至共速，末状态总动量即为：

     \\vec{P}\_{\\text{终}} = \\vec{P}\_0 + \\vec{I} = (0, 2) + (-v_1,\\ -v_1) = (-v_1,\\ 2 - v_1)

1. **在动量平面 (P_x,\\ P_y) 中作图（几何秒杀）**：

   消去参数 v_1：令 P_x = -v_1,\\ P_y = 2 - v_1，立即发现末总动量矢量的终点 (P_x, P_y) 落在直线：

   P_y - P_x = 2

   的线段上——起点为 A(-2, 0)（对应 v_1=2），终点为 B(-0.4, 1.6)（对应 v_1=0.4）。

   因为末态动能 E\_{k\\text{终}} = \\frac{|\\vec{P}\_{\\text{终}}|^2}{2(m+M)} = \\frac{P_x^2 + P_y^2}{10}，所以**生热最大 \\iff 原点 O(0,0) 到线段 AB 上动点的距离平方 (P_x^2 + P_y^2) 最小**！

1. **垂线段最短**：

   直线 P_y - P_x = 2 与两坐标轴交于 (-2, 0) 和 (0, 2)，正好构成一个等腰直角三角形！

   从原点 O(0,0) 向斜边 y = x + 2 作垂线，**垂足 H 恰好就是斜边的中点**：

   H\\left(-1,\\ 1\\right)

   - 检验 H(-1, 1) 是否在线段 AB 上：-1 \\in [-2, -0.4]，就在线段上！
   - 对比坐标 (-v_1,\\ 2 - v_1) = (-1, 1)，一眼读出：v_1 = 1\\text{ m/s}！
   - 最短距离平方 |OH|^2 = (-1)^2 + 1^2 = 2，故最小末动能为 \\frac{2}{10} = 0.2\\text{ J}，最大摩擦热 Q\_{\\max} = 2 - 0.2 = 1.8\\text{ J}！

   （随后用解法二完全相同的两行验证 L=0.75\\text{ m} 且不掉落即可。）

### 解法四（进阶加餐）：微元法导出“约化质量与相对动能损耗定理”

如果我们不用质心总动量，而是直接用**双体相对运动与微元法**（很多竞赛和强基题会用到的“折合质量”二级结论），不仅能把计算压到 3 行，还能看清一个非常有趣的物理本质：**为什么没有挡板时最多只能生热 1.6\\text{ J}，放了块静止不动的挡板反而能多磨出 0.2\\text{ J} 的热？**

#### 第一步：用微元法 3 行推导“内耗生热公式”（让你不用死记二级结论）

对任意两个只有内力（此处为滑动摩擦力 \\vec{f}\_m = -\\vec{f}\_M = \\vec{f}）相互作用的物体，在微元时间 dt 内，内力做的总功（即摩擦生热的负值 -dQ）为：

-dQ = \\vec{f} \\cdot d\\vec{r}\_m + (-\\vec{f}) \\cdot d\\vec{r}\_M = \\vec{f} \\cdot (d\\vec{r}\_m - d\\vec{r}_M) = \\vec{f} \\cdot d\\vec{r}_{\\text{相}}

同时，牛顿第二定律给出两者的相对加速度：

\\vec{a}_{\\text{相}} = \\frac{d\\vec{v}_{\\text{相}}}{dt} = \\frac{\\vec{f}}{m} - \\frac{-\\vec{f}}{M} = \\left(\\frac{1}{m} + \\frac{1}{M}\\right)\\vec{f}

令**约化（折合）质量** \\mu\_{\\text{折}} = \\frac{mM}{m+M} = \\frac{1 \\times 4}{1 + 4} = 0.8\\text{ kg}，就有 \\vec{f} = \\mu\_{\\text{折}} \\frac{d\\vec{v}_{\\text{相}}}{dt}。代入上式（利用 \\frac{d\\vec{r}_{\\text{相}}}{dt} = \\vec{v}\_{\\text{相}}）：

-dQ = \\mu\_{\\text{折}} \\frac{d\\vec{v}_{\\text{相}}}{dt} \\cdot \\vec{v}_{\\text{相}}, dt = \\mu\_{\\text{折}} \\vec{v}_{\\text{相}} \\cdot d\\vec{v}_{\\text{相}} = d\\left(\\frac{1}{2}\\mu\_{\\text{折}} v\_{\\text{相}}^2\\right)

积分得任意无外力阶段的通用生热公式：

Q = -\\Delta\\left(\\frac{1}{2}\\mu\_{\\text{折}} v\_{\\text{相}}^2\\right) = \\frac{1}{2}\\mu\_{\\text{折}}\\left(v\_{\\text{相,初}}^2 - v\_{\\text{相,末}}^2\\right)

#### 第二步：利用约化相对动能直接计算 Q(v_1)

全程跳过 a_m,\\ a_M,\\ t_1,\\ t_2,\\ \\Delta y_1,\\ \\Delta s_2，直接写出两段相对动能变化（\\frac{1}{2}\\mu\_{\\text{折}} = 0.4\\text{ kg}）：

1. **碰前阶段**：相对速度大小从 v\_{\\text{相}0} = 2 降至 v\_{\\text{相}1} = v_1 - v\_{M1}。由碰前动量守恒 v\_{M1} = \\frac{2 - v_1}{4}，得：

   v\_{\\text{相}1} = v_1 - \\frac{2 - v_1}{4} = \\frac{5v_1 - 2}{4} \\implies Q_1 = 0.4 \\left[ 4 - \\frac{(5v_1 - 2)^2}{16} \\right]

1. **碰后阶段**（至相对静止 v\_{\\text{相,末}} = 0）：碰后相对初速度 \\vec{v}_{\\text{相}1}' = (-v_1,\\ -v_{M1})，故：

   Q_2 = 0.4 \\left[ v_1^2 + \\frac{(2 - v_1)^2}{16} \\right]

1. **两式相加，利用平方差 a^2 - b^2 = (a-b)(a+b) 一步化简**：

   Q = 0.4 \\left[ 4 + v_1^2 + \\frac{(2 - v_1)^2 - (5v_1 - 2)^2}{16} \\right]

   注意分式分子：(2 - v_1 - 5v_1 + 2)(2 - v_1 + 5v_1 - 2) = (4 - 6v_1)(4v_1) = 8v_1(2 - 3v_1)。

   于是：

   Q = 0.4 \\left[ 4 + v_1^2 + \\frac{v_1(2 - 3v_1)}{2} \\right] = 0.4 \\left( 4 + v_1 - \\frac{1}{2}v_1^2 \\right) = 1.6 + 0.4v_1 - 0.2v_1^2 = 1.8 - 0.2(v_1 - 1)^2

   同样在 v_1 = 1\\text{ m/s}（即 L = 0.75\\text{ m}）时取得极大值 1.8\\text{ J}！（不掉落校核与掉落排除同前）

> **物理本质透视**：最初相对动能只有 \\frac{1}{2}\\mu\_{\\text{折}}v_2^2 = 0.4 \\times 4 = 1.6\\text{ J}（另外 0.4\\text{ J} 锁死在质心平动动能里）。如果不碰挡板，摩擦最多只能把这 1.6\\text{ J} 烧完。而固定挡板虽不做总功，却通过把圆柱速度偏转 90^\\circ“给质心刹车”，把质心动能转换成了相对动能——在 v_1 = 1\\text{ m/s} 时转换量达到峰值 0.2\\text{ J}，于是最高总生热突破到了 1.6 + 0.2 = 1.8\\text{ J}！

### 高阶物理严谨性彩蛋：当 L > 0.75\\text{ m} 时，会不会再次撞上挡板？

因为你的物理思维较为深入，这里非常有必要点破一个考场常规解答不会提、但从纯物理推演上必然会碰到的边界问题：

看前面解法二中的总动量 \\vec{P}' = (-v_1,\\ 2 - v_1)。

- 当 L = 0.75\\text{ m} (v_1 = 1) 时，二次共速速度 \\vec{v}\_{\\text{共}2} = (-0.2,\\ 0.2) **恰好平行于挡板**，此后两者永远平行于挡板滑走，绝不再撞。

- 当 L > 0.75\\text{ m} (v_1 < 1) 时，二次共速速度在垂直挡板向上的 n 方向分量为 v\_{\\text{共}2, n} = \\frac{2 - 2v_1}{5\\sqrt{2}} > 0——也就是说，达到二次共速后，圆柱和木板是一起**斜向挡板所在直线运动**的！

  - **若挡板只在 P 点附近有较短一段**（或按通常压轴题默许的“只在 P 点发生一次弹性碰撞”），则没有二次碰撞，**L = 0.75\\text{ m} 是唯一的最大值点**。
  - **若挡板沿左上方延伸得足够长**（比如全覆盖木板左侧区域），我们来算一算：比如当 L \\ge 0.96\\text{ m}（v_1 = 0.4）时，第一次共速后向右上方直线滑行仅约 0.06\\text{ m} 就会在 P 点左上方再次撞上挡板！由于每次碰撞仍保持 P_t = \\sqrt{2} 不变，且每次碰撞都会让法向速度按比例 \\frac{M-m}{M+m} = \\frac{3}{5} 衰减（经计算，哪怕碰撞无限次，总耗时也收敛于有限值 \\approx 0.75\\text{ s}，且横向总相对位移 < 0.24\\text{ m} < 0.5\\text{ m} 不会掉落！），最终 v_n \\to 0，**系统依然会在反复微幅弹跳滑行后收敛到 Q = 1.8\\text{ J} 的热上限**。

结合原题提问方式“**求 L 为多大时**……摩擦热最大”（指定单一数值），以及图乙中挡板画在 P 点附近的有限长度，考题预设的标准模型是**只发生一次在 P 点的弹性碰撞**，因此标准答案为 **L = 0.75\\text{ m}**（此时恰好凭**单次碰撞**就榨干了 1.8\\text{ J} 的理论极限）。
