高中数学：西尔维斯特序列

深度解析西尔维斯特序列核心性质与高中数学压轴题破解模板，涵盖裂项相消、互素性证明、倒数求和放缩及参数化离散最值搜索的完整解题矩阵。

零、认知激活

我们先以一道高中数学题引入：若数列 \{a_n\} 满足 a_{n+1}=a_n^2-5a_n+9，a_1=4，证明 \dfrac{1}{a_1-2}+\dfrac{1}{a_2-2}+\dots+\dfrac{1}{a_n-2}<1。

面对递推关系 a_{n+1} = a_n^2 - 5a_n + 9 与前 n 项和的不等式，我们首先代入特殊值计算前几项，观察前 n 项和 S_n = \sum_{k=1}^n \dfrac{1}{a_k - 2} 的数值变化规律：

  • 当 n=1 时，a_1 = 4，则 S_1 = \dfrac{1}{4-2} = \dfrac{1}{2}；
  • 当 n=2 时，a_2 = 4^2 - 5 \times 4 + 9 = 5，则 S_2 = \dfrac{1}{2} + \dfrac{1}{5-2} = \dfrac{1}{2} + \dfrac{1}{3} = \dfrac{5}{6}；
  • 当 n=3 时，a_3 = 5^2 - 5 \times 5 + 9 = 9，则 S_3 = \dfrac{5}{6} + \dfrac{1}{9-2} = \dfrac{5}{6} + \dfrac{1}{7} = \dfrac{41}{42}；
  • 当 n=4 时，a_4 = 9^2 - 5 \times 9 + 9 = 45，则 S_4 = \dfrac{41}{42} + \dfrac{1}{45-2} = \dfrac{41}{42} + \dfrac{1}{43} = \dfrac{1764}{1806} = \dfrac{42}{43}。

观察上述和式结果：

S_1 = 1 - \frac{1}{2} = 1 - \frac{1}{a_2 - 3}

S_2 = 1 - \frac{1}{6} = 1 - \frac{1}{a_3 - 3}

S_3 = 1 - \frac{1}{42} = 1 - \frac{1}{a_4 - 3}

强烈的积极信号表明：前 n 项和具有极佳的结构守恒性，即：

S_n = \sum_{k=1}^n \frac{1}{a_k - 2} = 1 - \frac{1}{a_{n+1} - 3}

这也暗示了本题的核心破解钥匙在于对通项进行裂项变形。

步骤 1：构造裂项恒等式

分析递推式 a_{k+1} = a_k^2 - 5a_k + 9 的等号右侧，对其进行常数偏移与因式分解：

a_{k+1} - 3 = a_k^2 - 5a_k + 6 = (a_k - 2)(a_k - 3)

关注待求和式中的通项 \dfrac{1}{a_k - 2}，利用上述因式分解形式进行代数裂项：

\frac{1}{a_k - 3} - \frac{1}{a_{k+1} - 3} = \frac{1}{a_k - 3} - \frac{1}{(a_k - 2)(a_k - 3)}

通分化简右边：

\frac{(a_k - 2) - 1}{(a_k - 2)(a_k - 3)} = \frac{a_k - 3}{(a_k - 2)(a_k - 3)} = \frac{1}{a_k - 2}

由此，我们精准导出了关键代数恒等式：

\frac{1}{a_k - 2} = \frac{1}{a_k - 3} - \frac{1}{a_{k+1} - 3} \quad (k \ge 1)

步骤 2：求和与累加抵消（裂项相消法）

利用导出的恒等式对原式进行裂项相消展开累加：

\begin{aligned} \sum_{k=1}^n \frac{1}{a_k - 2} &= \left( \frac{1}{a_1 - 3} - \frac{1}{a_2 - 3} \right) + \left( \frac{1}{a_2 - 3} - \frac{1}{a_3 - 3} \right) + \dots + \left( \frac{1}{a_n - 3} - \frac{1}{a_{n+1} - 3} \right) \\ &= \frac{1}{a_1 - 3} - \frac{1}{a_{n+1} - 3} \end{aligned}

代入已知首项 a_1 = 4：

\frac{1}{a_1 - 3} = \frac{1}{4 - 3} = 1

因此，前 n 项和表达式为：

\sum_{k=1}^n \frac{1}{a_k - 2} = 1 - \frac{1}{a_{n+1} - 3}

步骤 3：单调性与下界验证（数学归纳法）

下面只需证明对任意 n \ge 1，均有 a_{n+1} > 3。

此处可以直观感受，用类似下面的方式可以很容易得到，但是更严谨的做法和步骤是采用数学归纳法：

  1. 当 n=1 时，a_1 = 4 > 3，结论成立。

  2. 假设当 n=k (k \ge 1) 时，a_k > 3 成立。则当 n=k+1 时：

    a_{k+1} - 3 = (a_k - 2)(a_k - 3)

    由于 a_k > 3，故 a_k - 2 > 1 > 0 且 a_k - 3 > 0。两个正数相乘必为正数，因此 a_{k+1} - 3 > 0，即 a_{k+1} > 3 成立。

综上所述，对任意 n \in \mathbb{N}^*，都有 a_{n+1} - 3 > 0，从而：

\frac{1}{a_{n+1} - 3} > 0

结合求和公式最终得到：

\sum_{k=1}^n \frac{1}{a_k - 2} = 1 - \frac{1}{a_{n+1} - 3} < 1

原命题得证。

本题在高等数学与数论中有着非常深厚的背景。若令 b_n = a_n - 3，代入原递推关系可得：

b_{n+1} + 3 = (b_n + 3)^2 - 5(b_n + 3) + 9 \implies b_{n+1} = b_n^2 + b_n = b_n(b_n + 1)

这正是经典的西尔维斯特序列（Sylvester’s Sequence）的形式，其通项的倒数和满足：

\sum_{k=1}^n \frac{1}{b_k + 1} = 1 - \frac{1}{b_{n+1}}

当 n \to \infty 时，其极限恰好收敛于 1。

总结与反思：

  1. 破局点：对于非线性二次递推关系 a_{n+1} = P(a_n) 与倒数求和相结合的问题，直接求解通项公式往往不可行。寻求“递推式的因式分解”与“倒数裂项”之间的内在对偶性是通用的解题模板。
  2. 易错点：仅推导出 \sum_{k=1}^n \dfrac{1}{a_k-2} = 1 - \dfrac{1}{a_{n+1}-3} 是不够的，必须严格验证 a_{n+1} - 3 > 0，否则无法保证不等号方向严格成立。这种“代数等式变形 + 边界取值证明”的双轨逻辑是高考压轴与竞赛题的常见考查方式。

二、西尔维斯特序列

西尔维斯特序列（Sylvester’s Sequence）是数论与代数递推中极具美感且结构极其特殊的经典序列。其原始定义为：

E_1 = 2, \quad E_{n+1} = E_n^2 - E_n + 1 \quad (n \ge 1)

其前几项依次为：2, 3, 7, 43, 1807, 3263443, \dots

该序列虽然形式简单，却蕴含着三条震撼人心的核心代数与数论结构，是解决高考压轴题与高中数学联赛大题的“超级母型”。

核心性质 1：乘积移位恒等式（积转化为线性）

对递推式两边同时减 1：

E_{n+1} - 1 = E_n^2 - E_n = E_n(E_n - 1)

对其不断进行代换下降，可得：

E_{n+1} - 1 = E_n E_{n-1} \dots E_1 (E_1 - 1)

由于 E_1 - 1 = 2 - 1 = 1，得到重要乘积恒等式：

E_{n+1} - 1 = \prod_{i=1}^n E_i \quad \iff \quad E_n = 1 + \prod_{i=1}^{n-1} E_i

这一性质揭示了该序列“下一项减 1 等于前面所有项之积”的奇妙结构。

核心性质 2：全局两两互素性（欧几里得定理的代数构造）

对于任意 1 \le i < j，由于：

E_j - 1 = E_1 E_2 \dots E_i \dots E_{j-1} \implies E_j - (E_1 E_2 \dots E_i \dots E_{j-1}) = 1

若 d = \gcd(E_i, E_j)，则 d \mid E_i \implies d \mid (E_1 E_2 \dots E_{j-1})，又 d \mid E_j，故 d \mid 1 \implies d = 1。

结论：西尔维斯特序列中任意两项均互素（\gcd(E_i, E_j) = 1）。这是构造性证明“素数有无穷多个”的最优雅代数模型之一。

核心性质 3：倒数裂项相消与埃及分数贪心收敛

对恒等式 E_{k+1} - 1 = E_k(E_k - 1) 两边取倒数变形：

\frac{1}{E_k} = \frac{1}{E_k - 1} - \frac{1}{E_{k+1} - 1}

对前 n 项求和即可实现无损无缝裂项相消：

\sum_{k=1}^n \frac{1}{E_k} = \sum_{k=1}^n \left( \frac{1}{E_k - 1} - \frac{1}{E_{k+1} - 1} \right) = \frac{1}{E_1 - 1} - \frac{1}{E_{n+1} - 1} = 1 - \frac{1}{E_{n+1} - 1}

当 n \to \infty 时，由于 E_n 呈现双指数级爆炸增长，E_{n+1} \to \infty，故：

\sum_{k=1}^\infty \frac{1}{E_k} = 1

这构成了将 1 拆分为分子为 1 的单位分数（埃及分数）的最快贪心展开收敛级数。

高中数学中的参数化平移（母题变式模板）

在压轴题中，考官通常会通过平移参数将西尔维斯特序列包装隐藏起来。一般形式为：

a_{n+1} = a_n^2 - (c+1)a_n + c(c+1) \quad \implies \quad a_{n+1} - c = (a_n - 1)(a_n - c)

此时对通项变形为 \dfrac{1}{a_k - 1} = \dfrac{1}{a_k - c} - \dfrac{1}{a_{k+1} - c}，从而破解复杂的求和与放缩问题。

三、典题突破与深度对撞

例题 1：递推结构放缩与界限估计

已知数列 \{a_n\} 满足 a_1 = 3，a_{n+1} = a_n^2 - 3a_n + 4 (n \in \mathbb{N}^*)。

（1）求证：\sum_{k=1}^n \dfrac{1}{a_k - 1} = 1 - \dfrac{1}{a_{n+1} - 2}；

（2）记 b_n = \dfrac{1}{a_n - 1}，证明：对任意 n \ge 2，均有 \sum_{k=1}^n b_k^2 < \dfrac{5}{12}。

步骤 1：第一问的精准裂项与递推破译

对递推关系 a_{k+1} = a_k^2 - 3a_k + 4 进行常数偏移构造：

a_{k+1} - 2 = a_k^2 - 3a_k + 2 = (a_k - 1)(a_k - 2)

这说明数列属于平移参数 c = 2 的西尔维斯特型序列。调用构造法与裂项法：

\frac{1}{a_k - 1} = \frac{(a_k - 1) - (a_k - 2)}{(a_k - 1)(a_k - 2)} = \frac{1}{a_k - 2} - \frac{1}{(a_k - 1)(a_k - 2)} = \frac{1}{a_k - 2} - \frac{1}{a_{k+1} - 2}

将上式累加得到：

\sum_{k=1}^n \frac{1}{a_k - 1} = \sum_{k=1}^n \left( \frac{1}{a_k - 2} - \frac{1}{a_{k+1} - 2} \right) = \frac{1}{a_1 - 2} - \frac{1}{a_{n+1} - 2}

代入 a_1 = 3，得 \dfrac{1}{a_1 - 2} = 1，故：

\sum_{k=1}^n \frac{1}{a_k - 1} = 1 - \frac{1}{a_{n+1} - 2}

第一问得证。

步骤 2：第二问的精细局部放缩（以退为进与分段隔离）

我们要证明 \sum_{k=1}^n b_k^2 < \dfrac{5}{12}。首先算数列前几项：

  • a_1 = 3 \implies b_1 = \dfrac{1}{2}；
  • a_2 = 3^2 - 3 \times 3 + 4 = 4 \implies b_2 = \dfrac{1}{3}，此时 a_2 - 2 = 2；
  • a_3 = 4^2 - 3 \times 4 + 4 = 8 \implies b_3 = \dfrac{1}{7}，此时 a_3 - 2 = 6；
  • a_4 = 8^2 - 3 \times 8 + 4 = 44 \implies b_4 = \dfrac{1}{43}，此时 a_4 - 2 = 42。

直接计算前三项平方和：

b_1^2 + b_2^2 + b_3^2 = \frac{1}{4} + \frac{1}{9} + \frac{1}{49} = \frac{13}{36} + \frac{1}{49}

对于 k \ge 4 的尾项，适度放缩法。注意到对于 k \ge 4，有 b_k = \dfrac{1}{a_k - 1} < \dfrac{1}{a_k - 2}，且 b_k < 1，故：

b_k^2 < b_k = \frac{1}{a_k - 2} - \frac{1}{a_{k+1} - 2}

从而尾项和满足：

\sum_{k=4}^n b_k^2 < \sum_{k=4}^n \left( \frac{1}{a_k - 2} - \frac{1}{a_{k+1} - 2} \right) = \frac{1}{a_4 - 2} - \frac{1}{a_{n+1} - 2} < \frac{1}{a_4 - 2} = \frac{1}{42}

因此，对任意 n \ge 4（当 n=2,3 时前几项直接计算显然满足）：

\sum_{k=1}^n b_k^2 < b_1^2 + b_2^2 + b_3^2 + \frac{1}{42} = \frac{13}{36} + \frac{1}{49} + \frac{1}{42}

通分计算右侧：

\frac{1}{49} + \frac{1}{42} = \frac{6 + 7}{294} = \frac{13}{294}

\sum_{k=1}^n b_k^2 < \frac{13}{36} + \frac{13}{294} = \frac{13 \times 49 + 13 \times 6}{1764} = \frac{13 \times 55}{1764} = \frac{715}{1764}

而目标上界：

\frac{5}{12} = \frac{5 \times 147}{1764} = \frac{735}{1764}

因为 715 < 735，所以：

\sum_{k=1}^n b_k^2 < \frac{715}{1764} < \frac{735}{1764} = \frac{5}{12}

命题得证。

总结与反思：处理“西尔维斯特型”倒数平方和 \sum b_k^2 时，由于 b_k 呈双指数衰减，项数越大下降越剧烈。前几项精密保留（计算），后半部分通过一次项 \dfrac{1}{a_k-2} 整体裂项放缩，是破解此类压轴不等式的黄金法则。

例题 2：数论结构与代数性质的深层对偶

已知数列 \{x_n\} 满足 x_1 = 2，x_{n+1} = x_n^2 - x_n + 1 (n \in \mathbb{N}^*)。

（1）求证：当 i \neq j 时，\gcd(x_i, x_j) = 1；

（2）证明：对任意正整数 n，前 n 项倒数和 S_n = \sum_{k=1}^n \dfrac{1}{x_k} 永远不是整数。

步骤 1：第一问的互素性证明

设 1 \le i < j。由西尔维斯特序列的标准乘积恒等式：

x_j - 1 = x_1 x_2 \dots x_i \dots x_{j-1} \implies x_j - \left(\prod_{k=1}^{j-1} x_k\right) = 1

假设 d = \gcd(x_i, x_j) > 1，且 d 为整除 x_i 与 x_j 的公因数，则：

d \mid x_i \implies d \mid \prod_{k=1}^{j-1} x_k

又因为 d \mid x_j，根据整除的线性性质：

d \mid \left( x_j - \prod_{k=1}^{j-1} x_k \right) \implies d \mid 1

这导致 d = 1，与 d > 1 矛盾。

因此，对任意 i \neq j，均有 \gcd(x_i, x_j) = 1。

步骤 2：第二问的不整性（非整数）证明

调用西尔维斯特序列的求和公式：

S_n = \sum_{k=1}^n \frac{1}{x_k} = 1 - \frac{1}{x_{n+1} - 1} = \frac{x_{n+1} - 2}{x_{n+1} - 1}

  • 当 n = 1 时，S_1 = \dfrac{1}{x_1} = \dfrac{1}{2}，显然不是整数。
  • 当 n \ge 2 时，由于 x_{n+1} - 1 与 x_{n+1} - 2 是两个连续的正整数，而任意两个连续正整数互素，即：

\gcd(x_{n+1} - 2, \, x_{n+1} - 1) = 1

同时，因为 x_1 = 2, x_2 = 3，所以对任意 n \ge 2：

x_{n+1} - 1 = x_1 x_2 \dots x_n \ge 2 \times 3 = 6 > 1

这表明分母 x_{n+1} - 1 是一个严格大于 1 的整数，且分式的分子分母已是最简既约分数。

因此，S_n = \dfrac{x_{n+1} - 2}{x_{n+1} - 1} 永远是一个真分数，绝不可能为整数。

总结与反思：本题完美展现了代数结构与数论性质的融合。利用递推式化出的相差为 1 的连续整数模型（即 A 与 A-1），既能导出互素性，又能秒杀非整数性质，充分体现了命题转换思想。

例题 3：参数化控制与离散最值搜索

已知函数 f(x) = x^2 - 3x + 4，定义数列 \{a_n\} 满足 a_1 = 4，a_{n+1} = f(a_n) (n \in \mathbb{N}^*)。记 T_n = \sum_{k=1}^n \dfrac{1}{a_k - 1}。

若对任意 n \in \mathbb{N}^*，不等式：

T_n < \lambda \left(1 - \frac{1}{2^{2^n}}\right)

恒成立，求实数 \lambda 的最小值。

第一阶段：理解题目与目标拆解

  • 未知量：使得不等式对一切 n \ge 1 恒成立的实数 \lambda 的下界（即最小值）。
  • 已知条件：递推式 a_{n+1} = a_n^2 - 3a_n + 4，首项 a_1 = 4。
  • 策略：首先求出 T_n 的封闭表达形式，然后将问题转化为参数分离：求离散数列 g(n) = \dfrac{T_n}{1 - 2^{-2^n}} 的全局最大值。

第二阶段：拟订方案与代数求和

注意到 a_{n+1} - 2 = a_n^2 - 3a_n + 2 = (a_n - 1)(a_n - 2)。

利用西尔维斯特裂项，通项为：

\frac{1}{a_k - 1} = \frac{1}{a_k - 2} - \frac{1}{a_{k+1} - 2}

前 n 项和为：

T_n = \frac{1}{a_1 - 2} - \frac{1}{a_{n+1} - 2} = \frac{1}{4 - 2} - \frac{1}{a_{n+1} - 2} = \frac{1}{2} - \frac{1}{a_{n+1} - 2}

原恒成立不等式等价于：

\lambda > \frac{T_n}{1 - 2^{-2^n}} = \frac{\dfrac{1}{2} - \dfrac{1}{a_{n+1} - 2}}{1 - 2^{-2^n}} \quad (\forall n \in \mathbb{N}^*)

记离散函数 g(n) = \dfrac{T_n}{1 - 2^{-2^n}}，只需求 \lambda \ge \max_{n \in \mathbb{N}^*} \{g(n)\}。

第三阶段：执行方案与精密计算

采用估算法计算 g(n) 的前几项：

先算出 a_n 的具体数值：

  • a_1 = 4；
  • a_2 = 4^2 - 3 \times 4 + 4 = 8 \implies a_2 - 2 = 6；
  • a_3 = 8^2 - 3 \times 8 + 4 = 44 \implies a_3 - 2 = 42；
  • a_4 = 44^2 - 3 \times 44 + 4 = 1810 \implies a_4 - 2 = 1806。

对应计算 T_n 与 g(n)：

  1. 当 n = 1 时：

    T_1 = \frac{1}{a_1 - 1} = \frac{1}{3}

    g(1) = \frac{\frac{1}{3}}{1 - 2^{-2}} = \frac{\frac{1}{3}}{\frac{3}{4}} = \frac{4}{9} \approx 0.4444

  2. 当 n = 2 时：

    T_2 = \frac{1}{3} + \frac{1}{7} = \frac{10}{21}

    g(2) = \frac{\frac{10}{21}}{1 - 2^{-4}} = \frac{\frac{10}{21}}{\frac{15}{16}} = \frac{10 \times 16}{21 \times 15} = \frac{32}{63} \approx 0.507936

  3. 当 n = 3 时：

    T_3 = \frac{1}{2} - \frac{1}{a_4 - 2} = \frac{1}{2} - \frac{1}{1806} = \frac{902}{1806} = \frac{451}{903}

    g(3) = \frac{\frac{451}{903}}{1 - 2^{-8}} = \frac{\frac{451}{903}}{\frac{255}{256}} = \frac{451 \times 256}{903 \times 255} = \frac{115456}{230265} \approx 0.501404

我们发现 g(2) > g(3) > g(1)！下面用严格不等式证明对于所有 n \ge 3，都有 g(n) < g(2)：

当 n \ge 3 时，因为 T_n < \dfrac{1}{2}，所以：

g(n) = \frac{T_n}{1 - 2^{-2^n}} < \frac{\frac{1}{2}}{1 - 2^{-2^n}} = \frac{2^{2^n - 1}}{2^{2^n} - 1}

对函数 h(x) = \dfrac{x}{2x - 1}（在 x \ge 8 上单调递减，其中 x = 2^{2^n - 1}），当 n \ge 3 时，2^{2^n - 1} \ge 2^7 = 128，因此：

g(n) < \frac{128}{256 - 1} = \frac{128}{255} \approx 0.50196

对比 g(2) = \dfrac{32}{63} \approx 0.507936，因为：

\frac{32}{63} - \frac{128}{255} = \frac{32 \times 255 - 128 \times 63}{63 \times 255} = \frac{8160 - 8064}{16065} = \frac{96}{16065} > 0

所以对任意 n \ge 3，都有 g(n) < \dfrac{128}{255} < \dfrac{32}{63} = g(2)。

综上所述，离散序列 g(n) 的最大值在 n = 2 处取得，最大值为 \dfrac{32}{63}。

实数 \lambda 的最小值为 \dfrac{32}{63}。

回顾与反思

  1. 认知陷阱陷阱：很多同学受思维定势影响，误以为当 n \to \infty 时 T_n \to \dfrac{1}{2}，而 1 - 2^{-2^n} \to 1，从而盲目猜测极值在极限处取得，得出 \lambda \ge \dfrac{1}{2} 的错误结论。
  2. 本质剖析：本题本质是一个“非单调离散数列寻找峰值”的问题。由于分母 1 - 2^{-2^n} 在 n=1,2 时增长极快，导致 g(n) 在 n=2 处产生“超调（Overshoot）”，形成局部的最高峰（\frac{32}{63} > \frac{1}{2}）。通过精准局部计算 + 尾部放缩控界，能够严密锁定离散极值点。

四、元认知总结

遇到带有二次平方递推（如 a_{n+1} = a_n^2 + p a_n + q）且涉及倒数求和的压轴题时，请直接调取以下三步矩阵思维：

  1. 识别特征：a_{n+1} = a_n^2 + p a_n + q

  2. 寻找到隐藏的平移西尔维斯特母体，配对偏移常数 c：使 a_{n+1} - c = (a_n - 1)(a_n - c)

  3. 构造裂项恒等式：\dfrac{1}{a_k - 1} = \dfrac{1}{a_k - c} - \dfrac{1}{a_{k+1} - c}

    无损累加相消导出 S_n = \dfrac{1}{a_1 - c} - \dfrac{1}{a_{n+1} - c}

  4. 策略抉择（双轨应用）：

    • 若证不等式：保留前 k 项，尾项用一次项放缩（b_k^2 < b_k）
    • 若求参/极值：警惕离散超调点，精细比较前几项与极限边界
