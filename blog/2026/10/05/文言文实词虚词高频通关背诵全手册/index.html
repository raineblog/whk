文言文实词·虚词·高频通关背诵全手册

本手册系统梳理高考必考18个文言虚词精研与150个核心实词考点，附高频拓展词库及文化常识，提供本义引申义、考点点拨和例句，三维一体结构助力高效通关背诵与复习。

研读与背诵指南

  1. 三维一体结构：本书册由第一部分：18个高考必考文言虚词通关精研、第二部分：150个高考核心文言实词终极考点精解、第三部分：高频拓展实词、难词与文化常识词库构成。
  2. 符号与体例说明：
    • 【本义】、【引申义】、【假借/通假】：标明词义演变脉络，便于逻辑记忆而非死记硬背。
    • 【考点点拨】：收录古汉语文化常识、高考命题高频陷阱及快速推断技巧。
    • [多音标注]：对一词多音、多义分项列出，严防读音与意义混淆。

第一部分：高考必考 18 个核心文言虚词深度通关手册

1. 而

  • 表示并列关系（一般不译，有时可译为“又”“并”）
    • 剑阁峥嵘而崔嵬，一夫当关，万夫莫开。（《蜀道难》）
    • 蟹六跪而二螯，非蛇鳝之穴无可寄托者。（《劝学》）
  • 表示递进关系（可译为“并且”“而且”）
    • 君子博学而日参省乎己，则知明而行无过矣。（《劝学》）
    • 楚怀王贪而信张仪，遂绝齐。（《屈原列传》）
  • 表示承接关系（可译为“就”“接着”，或不译）
    • 故舍汝而旅食京师，以求斗斛之禄。（《祭十二郎文》）
    • 人非生而知之者，孰能无惑？（《师说》）
    • 拔剑切而食之。（《鸿门宴》）
  • 表示转折关系（可译为“但是”“却”）
    • 青，取之于蓝，而青于蓝。（《劝学》）
    • 有如此之势，而为秦人积威之所劫。（《六国论》）
    • 信而见疑，忠而被谤。（《屈原列传》）
  • 表示假设关系（可译为“如果”“假如”）
    • 诸君而有意，瞻予马首可也。（《冯婉贞》）
    • 死而有知，其几何离。（《祭十二郎文》）
  • 表示修饰关系（连接状语与中心词，可不译，或译为“地”）
    • 吾尝跂而望矣，不如登高之博见也。（《劝学》）
    • 项王按剑而跽曰：“客何为者？”（《鸿门宴》）
  • 表示因果关系（可译为“因而”“以致”）
    • 余亦悔其随之而不得极夫游之乐也。（《游褒禅山记》）
  • 第二人称代词（译为“你”“你的”）
    • 必欲烹而翁，则幸分我一杯羹。（《项羽本纪》）
    • 而母立于兹。（《项脊轩志》）
  • 【固定搭配】
    • 【而言】：表示语气舒缓，如“一夫作难而阕落，身死人手，为天下笑者，何也？”
    • 【而后】：才，方才。如“三月而后成。”
    • 【而况】：何况，更加。如“技历数者，而况于人事乎？”
    • 【既而】：不久，一会儿。如“既而得其尸于井。”

2. 何

  • 单独作谓语（常带语气词“哉”“也”，译为“为什么”“什么原因”）
    • 齐人未尝赂秦，终继五国迁灭，何哉？（《六国论》）
  • 作动词或介词宾语（疑问代词前置，译为“哪里”“什么”）
    • 大王来何操？（《鸿门宴》）
    • 沛公安在？/ 子何恃而往？（《为学》）
    • 一旦山陵崩，长安君何以自托于赵？（《触龙说赵太后》——“何以”即“以何”）
  • 作定语（译为“什么”“哪”）
    • 其间旦暮闻何物，杜鹃啼血猿哀鸣。（《琵琶行》）
    • 然则何时而乐耶？（《岳阳楼记》）
  • 作状语，表反问（译为“为什么”“怎么”）
    • 何不按兵束甲，北面而事之？（《赤壁之战》）
    • 徐公何能及君也？（《邹忌讽齐王纳谏》）
  • 副词，用在形容词前，表程度深（译为“多么”“怎么这样”）
    • 至于誓天断发，泣下沾襟，何其衰也！（《伶官传序》）
    • 水何澹澹，山岛竦峙。（《观沧海》）
  • 动词，通“呵”或“荷”
    • 良将劲弩守要害之处，信臣精卒陈利兵而谁何。（通“呵”，喝问、盘查，《过秦论》）
    • 何蓑何笠。（读 hè，通“荷”，扛、背，《诗经·无衣》）
  • 【固定搭配】
    • 【何如】/【奈何】：怎么样，怎么办。
    • 【何乃】：怎能，怎么这样。如“阿母谓府吏：何乃太区区！”（《孔雀东南飞》）
    • 【何其】：多么。如“何其衰也！”

3. 乎

  • 句末语气词，表疑问（译为“吗”“呢”）
    • 儿寒乎？欲食乎？（《项脊轩志》）
  • 句末语气词，表反问（译为“难道……吗”）
    • 吾师道也，夫庸知其年之先后生于吾乎？（《师说》）
    • 日夜望将军至，岂敢反乎？（《鸿门宴》）
  • 句末语气词，表测度或商量（译为“吧”）
    • 圣人之所以为圣，愚人之所以为愚，其皆出于此乎？（《师说》）
    • 王之好乐甚，则齐国其庶几乎！（《庄暴见孟子》）
  • 句末语气词，表感叹（译为“啊”“呀”）
    • 悔相道之不察兮，延伫乎吾将反。（《离骚》）
    • 呜呼！孰知赋敛之毒有甚是蛇者乎！（《捕蛇者说》）
  • 句中语气词，表停顿舒缓（不译）
    • 胡为乎遑遑欲何之？（《归去来兮辞》）
  • 介词，相当于“于”（引出地点、时间、对象或比较）
    • 醉翁之意不在酒，在乎山水之间也。（《醉翁亭记》，在）
    • 生乎吾前，其闻道也固先乎吾。（《师说》，前：在；后：比）
    • 吾尝疑乎是。（《捕蛇者说》，对于）
  • 形容词/副词词尾（译为“……的样子”“……地”，同“然”）
    • 飘飘乎如遗世独立，羽化而登仙。（《赤壁赋》）
    • 郁郁乎文哉！（《论语》）

4. 乃

  • 副词，表顺承或时间紧接（译为“才”“这才”“就”）
    • 悉使羸兵负草填之，骑乃得过。（《赤壁之战》）
    • 度我至军中，公乃入。（《鸿门宴》）
    • 刿曰：“未可。”齐人三鼓。刿曰：“可矣。”齐师败绩。公将驰之。刿曰：“未可。”下视其辙，登轼而望之，曰：“可矣。”乃逐之。（《曹刿论战》）
  • 副词，表出乎意料（译为“却”“竟然”“反而”）
    • 今其智乃反不能及，其可怪也欤！（《师说》）
    • 问今是何世，乃不知有汉，无论魏晋。（《桃花源记》）
    • 而陋者乃以斧斤考击而求之。（《石钟山记》）
  • 副词，表判断（译为“是”“本是”“原来是”）
    • 若事之不济，此乃天也。（《赤壁之战》）
    • 当立者乃公子扶苏。（《陈涉世家》）
  • 副词，表限制（译为“只”“仅”）
    • 项王乃复引兵而东，至东城，乃有二十八骑。（《项羽本纪》）
  • 代词，第二人称（译为“你”“你们”“你的”）
    • 王师北定中原日，家祭无忘告乃翁。（《示儿》）
    • 尔其无忘乃父之志！（《伶官传序》）
  • 连词，表转折（译为“却”“反而”）
    • 老臣今者殊不欲食，乃自强步。（《触龙说赵太后》）
  • 【固定搭配】
    • 【无乃……与（乎）】：恐怕……吧？（表委婉推测）。如“无乃尔是过与？”（《季氏将伐颛臾》）

5. 其

  • 人称代词，第三人称（译为“他/她/它”“他的/她的/它的/他们的”）
    • 秦王恐其破璧。（《廉颇蔺相如列传》）
    • 其闻道也固先乎吾。（《师说》）
  • 人称代词，第一/第二人称（活用为“我（自己）”或“你”）
    • 而余亦悔其随之而不得极夫游之乐也。（《游褒禅山记》，我、自己）
    • 老臣病足，曾不能疾走，不得见久矣，窃自恕，而恐太后玉体之有所郄也，故愿望见太后。太后曰：“老妇恃辇而行。”曰：“日食饮得无衰乎？”曰：“恃鬻耳。”曰：“老臣今者殊不欲食，乃自强步，日三四里，少益耆食，和于身也。”太后曰：“老妇不能。”太后之色少解。
    • 尔其无忘乃父之志。（《伶官传序》，指示副词，表祈使，你/一定）
  • 指示代词，远指与近指（译为“那”“那个”“这”“这个”）
    • 不嫁义郎体，其往欲何云？（《孔雀东南飞》，那）
    • 今存其本不忍废。（《指南录后序》，这）
  • 指示代词，表群体中的部分（译为“其中的”）
    • 于乱石间择其一二扣之。（《石钟山记》）
  • 语气副词，表推测、揣度（译为“大概”“或许”“恐怕”）
    • 圣人之所以为圣，愚人之所以为愚，其皆出于此乎？（《师说》）
  • 语气副词，表祈使、商量或催促（译为“还是”“一定”）
    • 攻之不克，围之不继，吾其还也。（《烛之武退秦师》，还是）
    • 与尔三矢，尔其无忘乃父之志！（《伶官传序》，一定）
  • 语气副词，表反诘（译为“难道”）
    • 其孰能讥之乎？（《游褒禅山记》）
    • 尽吾志也而不能至者，可以无悔矣，其孰能讥之乎？
  • 连词，表选择（译为“是……还是……”）
    • 其真无马邪？其真不知马也！（《马说》）
    • 其信然邪？其梦邪？其传之非其真邪？（《祭十二郎文》）
  • 连词，表假设（译为“如果”“假如”）
    • 其业有不精，德有不成者，非天质之卑，则心不若余之专耳。（《送东阳马生序》）
  • 助词，调节音节（不译）
    • 路曼曼其修远兮，吾将上下而求索。（《离骚》）

6. 且

  • 连词，表递进（译为“而且”“并且”“况且”“再说”）
    • 彼所将中国人不过十五六万，且已久疲。（《赤壁之战》）
    • 且燕赵处秦革灭殆尽之际。（《六国论》）
    • 且立石于其墓之门。（《五人墓碑记》）
  • 连词，表让步（译为“尚且”“还”）
    • 臣死且不避，卮酒安足辞！（《鸿门宴》）
    • 古之圣人，其出人也远矣，犹且从师而问焉。（《师说》）
  • 连词，表并列（译为“又……又……”“一边……一边……”）
    • 命如南山石，四体康且直。（《孔雀东南飞》）
    • 磐石方且厚，可以卒千年。（《孔雀东南飞》）
  • 副词，表动作将要发生（译为“将”“将要”）
    • 若属皆且为所虏！（《鸿门宴》）
    • 不出，火且尽。（《游褒禅山记》）
  • 副词，表姑且、暂且（译为“姑且”“暂且”）
    • 誓不相隔卿，且暂还家去。（《孔雀东南飞》）
    • 存者且偷生，死者长已矣。（《石壕吏》）
  • 【固定搭配】
    • 【且夫】：发语词，用于句首引起下文议论，“况且”“再说”。
    • 【且如】：就像，好比。

7. 若

  • 第二人称代词（译为“你”“你们”“你的”）
    • 若入前为寿，寿毕，请以剑舞。（《鸿门宴》）
    • 更若役，复若赋。（《捕蛇者说》）
  • 指示代词（译为“这”“这样”“如此”）
    • 以若所为求若所欲，犹缘木而求鱼也。（《齐桓晋文之事》）
  • 连词，表假设（译为“如果”“假设”）
    • 若事之不济，此乃天也。（《赤壁之战》）
    • 国危矣，若使烛之武见秦君，师必退。（《烛之武退秦师》）
  • 连词，表选择（译为“或”“或者”）
    • 以万人若一郡降者，封万户。（《汉书·高帝纪》）
  • 动词（译为“像”“好像”或“比得上”）
    • 视之，形若土狗。（《促织》）
    • 徐公不若君之美也。（《邹忌讽齐王纳谏》）
  • 介词（译为“至于”）
    • 若民，则无恒产，因无恒心。（《齐桓晋文之事》）
  • 形容词词尾（译为“……的样子”，同“然”）
    • 桑之未落，其叶沃若。（《诗经·氓》）
  • 【固定搭配】
    • 【若夫】/【至若】：句首发语词，转移话题，译为“要说那……”“至于……”。如“若夫霪雨霏霏，连月不开。”（《岳阳楼记》）
    • 【孰若】/【若何】：哪如，怎么，怎么样。

8. 所

  • 名词，处所、地方
    • 某所，而母立于兹。（《项脊轩志》）
    • 成反复自念，得无教我猎虫所耶？（《促织》）
  • 助词，与动词组成“所字结构”（表示“所……的人/事/地方/情况”）
    • 师者，所以传道受业解惑也。（《师说》）
    • 道之所存，师之所存也。（《师说》）
    • 过蒙拔擢，宠命优渥，岂敢盘桓，有所希冀。（《陈情表》）
  • 助词，与“为”呼应，表被动（“为……所……”句式）
    • 仆以口语遇遭此祸，重为乡党所笑。（《报任安书》）
    • 赢闻晋鄙之兵符常在王卧内，而如姬最幸，力能窃之。尝为公子言曰：“公子岂能为妾报仇乎？”
    • 若属皆且为所虏！（《鸿门宴》）
  • 【固定搭配】
    • 【所以】：
      1. 表凭借、工具、方法：“用来……的”“靠它来……的”。如“师者，所以传道受业解惑也。”“此非所以跨海内、制诸侯之术也。”
      2. 表原因：“……的原因”。如“强秦所以不敢加兵于赵者，徒以吾两人在也。”（《廉颇蔺相如列传》）
    • 【所从】：……的来源，从……的地方。如“问所从来。”（《桃花源记》）

9. 为

一、介词（读 wèi）
  • 表对象，向、对
    • 如姬为公子泣。（《信陵君窃符救赵》）
    • 不足为外人道也。（《桃花源记》）
  • 表替代，替、给
    • 公为我献之。（《鸿门宴》）
    • 愿为市鞍马，从此替爷征。（《木兰诗》）
  • 表原因/目的，因为、为了
    • 慎勿为妇死，贵贱情何薄。（《孔雀东南飞》）
    • 盘庚不为怨谤之故，改其度。（《答司马谏议书》）
  • 表时间，当、等到
    • 为其来也，臣请缚一人过王而行。（《晏子使楚》）
二、介词（读 wéi）
  • 表被动，译为“被”
    • 身死人手，为天下笑者，何也？（《过秦论》）
    • 恐为操所先。（《赤壁之战》）
三、动词（读 wéi）
  • 含义极其广泛：做、干、充当、作为、成为、算作
    • 斩木为兵，揭竿为旗。（《过秦论》）
    • 冰，水为之，而寒于水。（《劝学》）
    • 南取百越之地，以为桂林、象郡。（《过秦论》）
    • 然赢欲就公子之名，故久立公子车骑市中；客凡三千人，皆自以为豪杰。
四、句末语气助词（读 wéi）
  • 表疑问或反诘，译为“呢”
    • 如今人方为刀俎，我为鱼肉，何辞为？（《鸿门宴》）
    • 何故怀瑾握瑜而自令见放为？（《屈原列传》）
    • 是社稷之臣也，何以伐为？（《季氏将伐颛臾》）

10. 焉

  • 兼词（于之 / 于此 / 于彼）（译为“在这里”“从这里”“在这上面”）
    • 三人行，必有我师焉。（《论语》，在其中）
    • 积土成山，风雨兴焉。（《劝学》，从这里）
