# 第一题（题 2）详解

### 1. 题目审读与已知条件

- 匀强磁场：B = 0.4\\text{ T}，垂直导轨平面向下（\\otimes）。
- 导轨间距：d = 0.5\\text{ m}，光滑水平，电阻不计。
- 导体棒 MN：质量 m = 0.2\\text{ kg}，电阻不计，初速度水平向右。
- 电感线圈：L = 5\\text{ H}，接在导轨右端，直流电阻不计。
- 回路电流表达式：i = \\sin(\\omega t)\\text{ (A)}（峰值电流 I\_{\\text{m}} = 1\\text{ A}）。
- 自感电动势：E_L = L \\frac{\\Delta I}{\\Delta t}。
- **求解**：导体棒向右运动的最大位移 x\_{\\text{m}}。

### 2. 物理过程分析与模型构建

1. **运动与感应过程**：
   - 导体棒向右以速度 v 运动时，切割磁感线产生动生电动势：E\_{\\text{动}} = B d v。根据右手定则，感应电动势方向为 M \\to N（N 端为高电势）。
   - 整个回路电阻为零，由回路电压平衡（基尔霍夫电压定律）可知，动生电动势与电感线圈的自感电动势时刻平衡： E\_{\\text{动}} = E_L \\implies B d v = L \\frac{\\mathrm{d}i}{\\mathrm{d}t}
1. **受力与动力学过程**：
   - 回路中产生电流 i，流经导体棒的方向为从 M 到 N。
   - 根据左手定则，导体棒受到的安培力向左：F\_{\\text{安}} = B i d。
   - 安培力为阻力，阻碍导体棒向右运动，故满足动力学方程： m \\frac{\\mathrm{d}v}{\\mathrm{d}t} = - B i d
   - 该系统构成一个典型的**简谐振动系统**（电感与质量块的机电振荡耦合）。

### 3. 详细解题方法

#### 【解法一：微积分累积法 / 状态守恒法（最直接、最简捷）】

回路中无电阻，动生电动势等于自感电动势： B d v = L \\frac{\\mathrm{d}i}{\\mathrm{d}t} 两边同乘以 \\mathrm{d}t： B d (v \\mathrm{d}t) = L \\mathrm{d}i \\implies B d \\cdot \\mathrm{d}x = L \\cdot \\mathrm{d}i 对上式从初始状态（t=0，x=0，i=0）到任意时刻积分： B d x = L i \\implies x(t) = \\frac{L}{B d} i(t) 已知回路中的电流表达式为 i(t) = \\sin(\\omega t)\\text{ (A)}，其最大值为 I\_{\\text{m}} = 1\\text{ A}。

当电流达到峰值 I\_{\\text{m}} 时，位移达到最大值 x\_{\\text{m}}： x\_{\\text{m}} = \\frac{L I\_{\\text{m}}}{B d} 代入数据： x\_{\\text{m}} = \\frac{5 \\times 1}{0.4 \\times 0.5}\\text{ m} = \\frac{5}{0.2}\\text{ m} = \\mathbf{25\\text{ m}}

#### 【解法二：简谐振动与能量守恒法（加深物理机制理解）】

1. **求系统的角频率 \\omega**：由动力学方程 \\frac{\\mathrm{d}v}{\\mathrm{d}t} = -\\frac{B d}{m} i，对自感方程两边求导： L \\frac{\\mathrm{d}^2 i}{\\mathrm{d}t^2} = B d \\frac{\\mathrm{d}v}{\\mathrm{d}t} = -\\frac{B^2 d^2}{m} i 整理得： \\frac{\\mathrm{d}^2 i}{\\mathrm{d}t^2} + \\frac{B^2 d^2}{m L} i = 0 对比简谐振动标准方程 \\ddot{i} + \\omega^2 i = 0，得固有角频率： \\omega = \\sqrt{\\frac{B^2 d^2}{m L}} = \\sqrt{\\frac{0.4^2 \\times 0.5^2}{0.2 \\times 5}} = \\sqrt{\\frac{0.04}{1}} = 0.2\\text{ rad/s}
1. **能量守恒求初速度 v_0**：系统只有动能与磁场能相互转化，机械能与电磁能守恒： \\frac{1}{2} m v_0^2 = \\frac{1}{2} L I\_{\\text{m}}^2 \\implies v_0 = \\sqrt{\\frac{L}{m}} I\_{\\text{m}} = \\sqrt{\\frac{5}{0.2}} \\times 1 = 5\\text{ m/s}
1. **求最大位移 x\_{\\text{m}}**：导体棒做简谐运动，速度与位移的关系为：v(t) = v_0 \\cos(\\omega t)，位移为： x(t) = \\int_0^t v_0 \\cos(\\omega t) \\mathrm{d}t = \\frac{v_0}{\\omega} \\sin(\\omega t) 所以向右的最大位移为： x\_{\\text{m}} = \\frac{v_0}{\\omega} = \\frac{5}{0.2}\\text{ m} = \\mathbf{25\\text{ m}}

# 第二题（例 4）详解

alt text

### 1. 题目审读与已知条件

- 导轨间距：l = 0.4\\text{ m}，矩形框 ac 边、bd 边垂直于导轨，长度为 l = 0.4\\text{ m}。
- 磁场参数：匀强磁场 B_1 = B_2 = B = 1\\text{ T}，方向相反（垂直纸面向外与向里相间排列）。
- 磁场运动速度：v = 5\\text{ m/s}（水平向右）。
- 线框参数：总电阻 R = 2\\ \\Omega，受恒定阻力 F\_{\\text{f}} = 1\\text{ N}。
- **求解**：金属框相对地面的最大速度 v\_{\\text{m}}。

### 2. 物理模型与受力分析

1. **相对运动与动生电动势**：
   - 设金属框最终相对地面向右的最大速度为 v\_{\\text{m}}（显然 v\_{\\text{m}} < v）。
   - 选取**金属框为参考系**，磁场相对金属框向右以速度 v\_{\\text{相}} = v - v\_{\\text{m}} 运动；
   - 等效于：磁场静止，金属框以相对速度 v\_{\\text{相}} = v - v\_{\\text{m}} **向左**切割磁感线。
   - ac 边位于向里的磁场 B_2 中，由右手定则，ac 产生感应电动势由 a \\to c： E_1 = B_2 l (v - v\_{\\text{m}}) = B l (v - v\_{\\text{m}})
   - bd 边位于向外的磁场 B_1 中，由右手定则，bd 产生感应电动势由 d \\to b： E_2 = B_1 l (v - v\_{\\text{m}}) = B l (v - v\_{\\text{m}})
   - 两个电动势在闭合回路中顺时针串联相加，回路总感应电动势为： E = E_1 + E_2 = 2 B l (v - v\_{\\text{m}})
1. **回路电流与安培力**：
   - 回路感应电流为： I = \\frac{E}{R} = \\frac{2 B l (v - v\_{\\text{m}})}{R}
   - 对 ac 边（电流 a \\to c，磁场向里）：由左手定则，安培力水平**向右**（牵引力方向）： F_1 = B I l
   - 对 bd 边（电流 d \\to b，磁场向外）：由左手定则，安培力同样水平**向右**： F_2 = B I l
   - 金属框受到的总安培推力为： F\_{\\text{安}} = F_1 + F_2 = 2 B I l = \\frac{4 B^2 l^2 (v - v\_{\\text{m}})}{R}
1. **最大速度的平衡条件**：金属框加速度逐渐减小，当推力等于阻力时，速度达到最大，做匀速直线运动： F\_{\\text{安}} = F\_{\\text{f}}

### 3. 计算与求解

代入平衡条件方程： \\frac{4 B^2 l^2 (v - v\_{\\text{m}})}{R} = F\_{\\text{f}} 变形得： v - v\_{\\text{m}} = \\frac{F\_{\\text{f}} R}{4 B^2 l^2} 代入已知数值： v - v\_{\\text{m}} = \\frac{1 \\times 2}{4 \\times 1^2 \\times 0.4^2} = \\frac{2}{4 \\times 0.16} = \\frac{2}{0.64} = 3.125\\text{ m/s} 因此，金属框的最大速度为： v\_{\\text{m}} = v - 3.125 = 5 - 3.125 = \\mathbf{1.875\\text{ m/s}}\\quad \\left(\\text{即 } \\frac{15}{8}\\text{ m/s}\\right)

# 第三题（题 3）详解

alt text

### 1. 题目审读与已知条件

- 导轨间距为 b，竖直放置；磁场区域等间距分布，长均为 a，磁感应强度大小均为 B，方向垂直平面相间交替。
- 导线框 MNPQ：固定在轿厢上，宽为 b（横向）、长为 a（竖向），总电阻为 R。
- 状态 1：磁场向上平动速度为 v_1 时，轿厢悬停（静止）。
- 状态 2：磁场向上平动速度为 v_2 时，轿厢最终向上以速度 v\_{\\text{上}} 做匀速运动。
- **求解**：轿厢匀速上升的速度 v\_{\\text{上}}。

### 2. 关键几何对称性与电磁分析

1. **几何特征剖析**：
   - 磁场每个区域的高为 a，导线框的纵向长度也恰好为 a。
   - 因此，无论线框相对磁场运动到何种位置，MN 边和 QP 边必定**时刻处于方向相反的两个匀强磁场区域中**（或同时穿过分界线）。
   - 纵向边 MQ 和 NP 平行于磁场的运动方向，不切割磁感线。
1. **感应电动势与安培力规律**：
   - 设磁场向上平动的速度为 v\_{\\text{磁}}，轿厢向上运动速度为 v\_{\\text{轿}}。
   - 磁场相对轿厢（线框）的向上相对速度为： v\_{\\text{相}} = v\_{\\text{磁}} - v\_{\\text{轿}}
   - 此时 MN 和 QP 两边同时切割磁感线，由于两处的磁场方向始终相反，它们产生的感应电动势在闭合回路中**顺时针/逆时针方向一致相加**： E = B b v\_{\\text{相}} + B b v\_{\\text{相}} = 2 B b v\_{\\text{相}}
   - 回路感应电流为： I = \\frac{E}{R} = \\frac{2 B b v\_{\\text{相}}}{R}
   - 两条横边所受安培力的方向均向上（“来拒去留”，阻碍相对运动，等效为被向上移动的磁场“拖拽”），合安培力为： F\_{\\text{安}} = 2 \\times (B I b) = \\frac{4 B^2 b^2 v\_{\\text{相}}}{R}
   - **核心结论**：总安培力大小完全由**相对速度 v\_{\\text{相}}** 唯一定义，且成严格正比关系：F\_{\\text{安}} \\propto v\_{\\text{相}}。

### 3. 列式与求解

设轿厢与线框的总质量为 M。

1. **状态 1（悬停静止，v\_{\\text{轿}} = 0）**：相对速度为 v\_{\\text{相1}} = v_1 - 0 = v_1。轿厢处于二力平衡状态（安培力等于重力）： F\_{\\text{安1}} = M g \\implies \\frac{4 B^2 b^2 v_1}{R} = M g \\quad \\text{—— ①}
1. **状态 2（匀速上升，v\_{\\text{轿}} = v\_{\\text{上}}）**：相对速度为 v\_{\\text{相2}} = v_2 - v\_{\\text{上}}。轿厢向上做匀速运动，合外力依然为零（安培力依然等于重力）： F\_{\\text{安2}} = M g \\implies \\frac{4 B^2 b^2 (v_2 - v\_{\\text{上}})}{R} = M g \\quad \\text{—— ②}
1. **联立求解**：对比式 ① 与式 ②，重力 Mg 保持不变，安培力必须相等，因此相对速度必然相等： v_1 = v_2 - v\_{\\text{上}} 直接解得： v\_{\\text{上}} = \\mathbf{v_2 - v_1}

# 题型模型、物理思想与解题方法深度总结

这三道题目代表了高考及各类物理竞赛中**电磁感应与现代科技结合**的两大高频经典模型：

### 模型一：电感与导轨构成的“机电振荡模型”（题 2）

#### 1. 物理本质

- 在纯电阻回路中，金属棒切割磁感线会产生焦耳热，能量持续耗散，运动为**阻尼运动**。
- 在含纯电感的闭合导轨回路中，系统**无电阻消耗能量**，机械能与线圈磁场能相互转化： \\frac{1}{2}mv^2 + \\frac{1}{2}Li^2 = \\text{恒量}
- 系统的运动规律在数学上与**弹簧振子（简谐运动）完全同构**。

#### 2. 机电类比关系表

| 机械振动物理量 | 符号 / 对应                    | 电感回路物理量 | 符号 / 对应                              |
| -------------- | ------------------------------ | -------------- | ---------------------------------------- |
| 位移           | x                              | 电流           | i                                        |
| 速度           | v = \\dot{x}                   | 电流变化率     | \\frac{\\mathrm{d}i}{\\mathrm{d}t}       |
| 质量           | m                              | 电感           | L                                        |

#### 3. 核心秒杀思想：微积分的一阶积分守恒

由于 E\_{\\text{动}} = E_L，即 B d \\frac{\\mathrm{d}x}{\\mathrm{d}t} = L \\frac{\\mathrm{d}i}{\\mathrm{d}t}，两端积分必有： B d x(t) = L i(t) **该积分关系独立于外界具体的外力形式**，只要初始 x=0, i=0，位移始终与瞬时电流严格成正比。

### 模型二：行波磁场与磁悬浮驱动模型（例 4、题 3）

#### 1. 物理本质——“行波磁场”与异步感应电机原理

- 磁悬浮列车或电梯的驱动原理本质上是**直线感应电动机（Linear Induction Motor, LIM）**。
- 磁场的移动相当于电机的“旋转定子磁场”，金属框相当于电机的“转子闭合鼠笼绕组”。
- 根据楞次定律的推广结论：**“感应电流的效果总是阻碍相对运动”**。当磁场向前运动时，线框为了“追赶”磁场以减小穿过自身磁通量的剧烈变化，必然受到磁场对它的向前推力（电磁拖拽力）。

#### 2. “双边切割、双倍增强”效应

- 为什么两题均将线框长设为磁场区域的宽度？
  - 巧妙的几何设计使得线框的两条有效切割边，**恒处于相反极性的磁场中**。
  - 根据反向磁场的对称性： E\_{\\text{总}} = E_1 + E_2 = 2 B l v\_{\\text{相}}
  - 安培力不仅两边同向，且叠加发力： F\_{\\text{安}} = 2 \\times (B I l) = \\frac{4 B^2 l^2 v\_{\\text{相}}}{R}
  - 这不仅消除了脉动波动（使得安培力在匀速相对运动时成为恒力），还将推力放大为单棒切割的 **4 倍**。

#### 3. 解决此类问题的一般通法与思想步骤

1. **参考系转换（相对运动法）**：
   - 永远将复杂的双动问题简化为相对运动：v\_{\\text{相}} = v\_{\\text{磁}} - v\_{\\text{物}}。
1. **等效电路建模**：
   - 明确有效切割长度、回路总电阻，写出与相对速度 v\_{\\text{相}} 相关的电动势及电流。
1. **动力学稳态分析（收尾速度模型）**：
   - 当加速度为零时，安培力等于外部负载（阻力 F\_{\\text{f}} 或重力 Mg）。
   - 若负载保持恒定，**维持平衡所需的相对速度 v\_{\\text{相}} 必然是唯一固定的常量**（如题 3 直接利用 v\_{\\text{相1}} = v\_{\\text{相2}} 实现秒杀）。
