离散数学（集合论、数理逻辑、图论、组合计数）目录结构及核心内容概要

本文系统梳理离散数学四大核心模块的目录结构与内容概要，涵盖集合论中的集合运算、二元关系、闭包、等价与偏序，数理逻辑中的命题与谓词逻辑，图论中的图的基本性质、欧拉与哈密顿图、树和平面图，以及组合计数中的递推关系与生成函数。

第一部分：集合论 (Set Theory)

集合论 1：集合基本运算与幂集

  • 1.1 集合的幂集 (Power Set)
    • 定义与编码：幂集 \mathcal{P}(A) 或 2^A 的概念；利用二元选择（01 序列/二进制数）与子集建立一一对应编码；
    • 基数定理：若 |A|=n，则 |\mathcal{P}(A)|=2^n（提供二项式定理展开与组合选取两种证明）。
  • 1.2 集合运算律复习
    • 并（\cup）、交（\cap）、补（\overline{A}）的交换律、结合律、幂等律、分配律与广义分配律；吸收律与对偶律。
    • 德·摩根律 (De Morgan’s Laws)：代数恒等式证明技巧与多集合形式推广。
  • 1.3 集合的差运算与对称差运算
    • 相对差 (A - B)：核心转化公式 A - B = A \cap \overline{B}；文氏图表示；不满足交换律和结合律。
    • 对称差 (A \oplus B)：本质定义为“不交并” (A-B)\cup(B-A) 与“包含差” (A\cup B)-(A\cap B)；
    • 对称差代数性质：交换律、结合律、单位元 \emptyset、逆元自反性 A \oplus A = \emptyset 及消去律 (A \oplus B = A \oplus C \Rightarrow B = C)。

集合论 2：对称差结合律与集合恒等式证明

  • 2.1 运算性质深度证明
    • 严谨证明对称差结合律 (A \oplus B) \oplus C = A \oplus (B \oplus C)，建立中间引理 \overline{X \oplus Y} = (X \cap Y) \cup (\overline{X} \cap \overline{Y})。
  • 2.2 集合恒等式的三大证明方法
    • 演算法：利用熟知布尔运算律及特征化公式等值化简；
    • 包含法 (双向包含法)：证明 X \subseteq Y 且 Y \subseteq X；
    • 对称差法：利用 X = Y \iff X \oplus Y = \emptyset 进行代数抵消证明。
  • 2.3 典型例题与恒等变形
    • 交对差/对称差的分配律；三集合容斥包含区域的并集化简。

集合论 3：二元关系基础

  • 3.1 关系的概念引入与笛卡尔积
    • 笛卡尔积 A \times B = \{(x,y) \mid x \in A, y \in B\}；基数公式 |A \times B| = mn。
    • 二元关系的数学定义：R \subseteq A \times B；n 元集上的关系总数为 2^{n^2}。
  • 3.2 关系的基本概念与表示
    • 关系的域系统：定义域 \text{dom}\,R、值域 \text{ran}\,R、域 \text{fld}\,R = \text{dom}\,R \cup \text{ran}\,R；
    • 特殊关系：空关系 \emptyset、全域关系 E_A、恒等关系 I_A；
    • 三大表示法：集合列举法、布尔关系矩阵 M_R、有向关系图。
  • 3.3 两大重要数论关系
    • 模 n 同余关系与整除关系的定义、列举、矩阵与有向图。

集合论 4：关系的逆、复合与幂运算

  • 4.1 关系的逆运算 (R^{-1})
    • 定义与性质：互逆性 (R^{-1})^{-1}=R、单调性、对并/交的保持分配性。
  • 4.2 关系的乘法（复合 R_1 \circ R_2）
    • 复合的序对乘法定义；满足结合律、以 I_A 为单位元、逆运算穿脱律 (S \circ T)^{-1} = T^{-1} \circ S^{-1}；
    • 对并的完全分配律与对交的弱分配律（包含反例）。
  • 4.3 关系的幂运算与矩阵乘法的一致性
    • R^n 的幂律性质；有限集上关系的周期性定理（必存在 R^s = R^t）；
    • 布尔矩阵乘法：证明关系复合对应于关系矩阵的布尔积（逻辑加法 1+1=1）。

集合论 5：关系的五大性质及其判定与计数

  • 5.1 五大核心性质定义与判定准则
    • 自反性：\forall x (xRx) \iff I_A \subseteq R（图有全自环，矩阵对角全 1）；
    • 反自反性：\forall x (\neg xRx) \iff I_A \cap R = \emptyset（图无自环，矩阵对角全 0）；
    • 对称性：xRy \Rightarrow yRx \iff R^{-1} = R（图无单向边，矩阵对称）；
    • 反对称性：xRy \land yRx \Rightarrow x=y \iff R \cap R^{-1} \subseteq I_A（图无双向边）；
    • 传递性：xRy \land yRz \Rightarrow xRz \iff R^2 \subseteq R。
  • 5.2 n 元集上特殊关系的组合计数
    • 自反/反自反关系数：2^{n^2 - n}；对称关系数：2^{\frac{n^2+n}{2}}；自反且对称：2^{\frac{n^2-n}{2}}；反对称关系数：2^n \cdot 3^{\frac{n^2-n}{2}}。

集合论 6：关系的闭包运算

  • 6.1 闭包的公理化定义与构造
    • 自反闭包 r(R)、对称闭包 s(R)、传递闭包 t(R) 的极小性定义。
    • 闭包计算公式：r(R) = R \cup I_A，s(R) = R \cup R^{-1}，t(R) = \bigcup_{i=1}^\infty R^i。
  • 6.2 传递闭包的有限截断定理
    • 证明：若 |A|=n，则 t(R) = R \cup R^2 \cup \dots \cup R^n（利用鸽巢原理证明长路径去环）。
  • 6.3 闭包的性质保全定理
    • 闭包的单调性；自反/对称/传递性的继承与互锁性质（强调：传递关系的对称闭包不一定传递）。

集合论 7：等价关系与集合划分

  • 7.1 等价关系与等价类
    • 同时满足自反、对称、传递的关系；
    • 等价类 [a]_R 的定义、代表元概念；等价类的基本性质（非空、重合或完全不相交、覆盖全集）。
  • 7.2 商集与集合划分的一致性
    • 商集 A/R 的构造（分组概念）；集合划分 \pi 的定义（非空、互斥、不漏）；
    • 一一对应定理：等价关系与集合划分一一对应，彼此可自然诱导。

集合论 8：偏序关系、哈斯图与特殊元素

  • 8.1 偏序关系与偏序集 (Poset)
    • 自反、反对称、传递三位一体；偏序记号 \le 与严格偏序 <；全序（线序）关系概念。
  • 8.2 覆盖关系与哈斯图 (Hasse Diagram)
    • 覆盖与紧邻后继概念；哈斯图的标准化分层绘制方法（省略自环与传递跃迁边）。
  • 8.3 偏序子集的极值元与界
    • 最大/小元（若存在必唯一）vs 极大/小元（可有多个，端点性）；
    • 上/下界 vs 最小上界 (上确界 \sup) / 最大下界 (下确界 \inf) 的定义与判定。

第二部分：数理逻辑 (Mathematical Logic)

数理逻辑 1：命题逻辑基本概念与真值表

  • 1.1 命题与联结词
    • 命题定义（可判定真假的陈述句）、真值（0/1）、命题常元与变元；
    • 五大联结词及真值表：否定 \neg、合取 \wedge、析取 \vee（相容或）、条件 \to（前假则全真）、双条件 \leftrightarrow。
  • 1.2 命题公式及其分类
    • 命题公式构造与真值表求法（二进制递增列举赋值法）；
    • 公式三大类型：重言式（永真式）、矛盾式（永假式）、可满足式。

数理逻辑 2：逻辑等价、等值演算与主析取范式

  • 2.1 常用逻辑等价式与置换规则
    • 蕴涵化简律 P \to Q \Leftrightarrow \neg P \vee Q；逆否律；德·摩根律；分配律与广义分配律；吸收律；
    • 置换规则在逻辑化简中的理论依据与应用。
  • 2.2 主析取范式 (PCNF)
    • 极小项（小项）的概念及其成真赋值独特性；
    • 逻辑公式化为主析取范式的标准步骤（先化析取范式，再用同一律与互补律“补元”展开）。

数理逻辑 3：主合取范式与范式编码

  • 3.1 极大项与主合取范式 (PDNF)
    • 极大项（大项）的概念及其成假赋值唯一性；二进制/十进制下标编码规则（m_i 与 M_j）。
    • 主析取范式与主合取范式的对偶关系（下标集合关于 \{0,1,\dots,2^n-1\} 互为补集）。
  • 3.2 真值表求主范式法与逻辑应用题
    • 基于真值表成真赋值写小项、成假赋值写大项的快速求解法；
    • 实际逻辑推理建模题（人员外派选拔问题的主析取范式解法）。

数理逻辑 4：命题逻辑的推理理论

  • 4.1 推理定律与推理规则
    • 蕴涵式 A \Rightarrow B（对应 A \to B 为重言式）；
    • 常用基本定律：假言推理、拒取式、析取三段论、假言三段论（传递律）、化简律、附加律。
    • 形式证明系统规则：前提引入规则 P、结论引入规则 T、合取引入规则。
  • 4.2 间接证明法
    • 反证法：否定结论作为附加前提，推导产生矛盾式 A \wedge \neg A；
    • CP 规则（条件证明法）：结论为 A \to B 时，将前件 A 作为附加前提推导后件 B。
    • 逻辑推理实例：破案推演与应用题形式化验证。

数理逻辑 5：一阶谓词逻辑基础

  • 5.1 谓词、个体词与量词
    • 个体常元与个体变元；n 元谓词的性质与关系刻画；
    • 全总个体域与特性谓词的作用；
    • 量词与特性谓词标准组合模式：
      • 全称量词搭配条件句：“所有的 A 都是 B” \iff \forall x (A(x) \to B(x))；
      • 存在量词搭配合取句：“存在 A 是 B” \iff \exists x (A(x) \wedge B(x))。
  • 5.2 量词的作用与消除
    • 有限个体域下量词展开为合取/析取；多元量词顺序敏感性辨析（\forall x \exists y \ne \exists y \forall x）。

数理逻辑 6：谓词公式变元约束与前束范式

  • 6.1 约束变元、自由变元与改名规则
    • 指导变元与量词辖域；约束与自由出现的辨析；换名规则与代入规则（避免变元捕获与混淆）。
  • 6.2 谓词等价式与前束范式 (Prenex Normal Form)
    • 量词穿越/否定律；辖域收缩与扩张等价式；
    • 前束范式的标准定义（所有量词前置）；标准化求解流程（改名 \to 消蕴涵 \to 摩根律内移否定 \to 量词外提扩张）。

数理逻辑 7：一阶谓词逻辑的推理理论

  • 7.1 量词消去与引入的四大推理规则
    • 全称消去 (\forall -)、全称引入 (\forall +)、存在消去 (\exists -)、存在引入 (\exists +)；
    • 消去规则的严格次序约束：存在消去必须先于全称消去执行，且消去引入的特异个体常元 c 不得产生作用域冲突（分析证明易错反例）。
  • 7.2 综合推演与数论实例验证
    • 运用自然推理系统、反证法证明谓词推理有效性。

第三部分：图论 (Graph Theory)

图论 1：图的基本概念、同构与握手定理

  • 1.1 经典图论起源问题
    • 哥尼斯堡七桥问题（抽象为顶点度数奇偶分析）、聚会问题（Ramsey 理论初探）、四色定理。
  • 1.2 图的定义与结构概念
    • 无向图 G = \langle V, E \rangle；顶点的度 d(v)、孤立点、悬挂点、最大度 \Delta(G) 与最小度 \delta(G)；
    • 简单图、平凡图、多重图、子图、生成子图、点导出子图 G[V']。
  • 1.3 握手定理 (Handshaking Lemma)
    • 定理：\sum_{v \in V} d(v) = 2|E|；推论：任何图中度数为奇数的顶点个数必为偶数。
  • 1.4 图的同构与经典图形
    • 图同构的充要/必要条件；彼得森图 (Petersen Graph) 的几何构型与性质。

图论 2：完全图、正则图、补图与自补图

  • 2.1 特殊图类与度序列
    • 度的单调排列；n 阶完全图 K_n（边数 \binom{n}{2}）；k-正则图。
  • 2.2 补图与自补图
    • 补图 \overline{G} 的性质：d_G(v) + d_{\overline{G}}(v) = n-1；
    • 自补图充要必要条件定理：若 n 阶简单图为自补图，则其边数 |E| = \frac{1}{4}n(n-1)，且 n \equiv 0 或 1 \pmod 4。
  • 2.3 极值度数问题与 5 阶自补图构建
    • 证明简单图中必存在两顶点度数相同；
    • 联立度序列方程分类画出全部 5 阶自补图（共 2 种非同构形态）。

图论 3：通路、回路与连通性理论

  • 3.1 通路与回路的分层分类
    • （一般）通路/回路 \to 简单通路/回路（边不重复）\to 基本通路/圈（点不重复）。
    • 基础定理：存在通路必存在基本通路。
  • 3.2 连通图与测度距离
    • 连通图判定，连通分支数 p(G)；顶点测度距离 d(u,v) 的三公理性质。
  • 3.3 割点、割边与连通度
    • 割点与割边（桥）的概念；割边等价定理（边 e 是割边 \iff e 不在任何圈上）；
    • 点连通度 \kappa(G) 与边连通度 \lambda(G)；惠特尼不等式：\kappa(G) \le \lambda(G) \le \delta(G)。

图论 4：最短路径算法与连通性判定

  • 4.1 最短路径算法 (Dijkstra’s Algorithm)
    • 赋权图的距离定义；永久标号（P 标号）与临时标号（T 标号）的更新机制及逆向回溯路径法。
  • 4.2 连通性充分条件定理
    • 定理：若简单图中任意两点满足 d(u)+d(v) \ge n-1，则图连通；
    • 边数充分性定理：若边数 m > \frac{1}{2}(n-1)(n-2)，则 G 必连通；
    • 简单图及其补图的连通互补性：G 与 \overline{G} 中至少有一个是连通图。

图论 5：欧拉图与半欧拉图

  • 5.1 欧拉图的判定
    • 经过每条边恰好一次的闭回路；
    • 欧拉定理：连通图 G 是欧拉图 \iff G 中所有顶点的度数均为偶数（利用数学归纳法及圈分解严谨证明）。
  • 5.2 Fleury 算法与半欧拉图
    • Fleury 算法（“过河拆桥，尽量不走独木桥/割边”）；
    • 半欧拉图定理：连通图有欧拉通路 \iff 恰有 2 个奇度顶点；一笔画问题的统一判定。

图论 6：哈密顿图及其判别法则

  • 6.1 哈密顿图的必要条件
    • 经过每个顶点恰好一次的圈；
    • 必要条件定理：若 G 是哈密顿图，则对任意非空真子集 V_1 \subset V，连通分支数满足 p(G - V_1) \le |V_1|（用于否定哈密顿性）。
  • 6.2 哈密顿图的充分条件定理
    • Dirac 定理与 Ore 定理：任意两不相邻顶点度数和 d(u)+d(v) \ge n 则图为哈密顿图（给出极大非哈密顿图反证法证明）。
  • 6.3 哈密顿问题代数运算法与实例
    • 十二面体图的 Icosian 微积分运算法求解；实际“圆桌会议”与“语言交流排座”建模。

图论 7：树与最小生成树

  • 7.1 树的五大等价定义
    • 无圈连通图；任意两点间存在唯一基本通路；无圈且 m=n-1；连通且 m=n-1；连通且每条边均为割边。
  • 7.2 生成树与最小生成树 (MST)
    • 连通图必有生成树；求生成树的破圈法与避圈法；
    • 赋权图最小生成树的 Kruskal 避圈算法。
  • 7.3 树的度数与树叶性质计算
    • 握手定理在树上的代数推演；树叶数与最大度的关系：叶子数 t \ge \Delta(T)。

图论 8：二部图、平面图与欧拉公式

  • 8.1 二部图 (偶图)
    • 独立集与二部划分；二部图判定定理：图 G 是二部图 \iff G 中无奇数长度的回路（无奇圈）；推论：树必为二部图。
  • 8.2 平面图与欧拉示性数公式
    • 平面嵌入、面与面的度数、平面图握手定理 \sum d(f) = 2|E|；
    • 平面图欧拉公式：连通平面图满足 n - m + r = 2（归纳法证明）。
  • 8.3 平面图的边数边界与非平面图
    • 极大平面图与平面三角剖分；简单平面图边数极值不等式 m \le 3n - 6；
    • 经典非平面图：利用反证法证明 K_5（10 \le 9 矛盾）和 K_{3,3}（2 \le 1 矛盾）为非平面图。

图论 9：平面性判定与极值度数问题

  • 9.1 库拉托夫斯基定理 (Kuratowski’s Theorem)
    • 边的细分（剖分）与同胚概念；充要条件：不含与 K_5 或 K_{3,3} 同胚的子图；证明彼得森图非平面。
  • 9.2 简单平面图的极值度数定理
    • 运用欧拉公式与握手定理证明：连通简单平面图必存在度数不超过 5 的顶点 (\delta(G) \le 5)；
    • 边数 m < 30 时最小度 \delta(G) \le 4；无短圈（如无 3-圈、4-圈）平面图的极值不等式与构图。

第四部分：组合计数 (Combinatorics)

组合计数 1：容斥原理与鸽巢原理

  • 1.1 容斥原理 (Inclusion-Exclusion Principle)
    • 二集合与三集合容斥公式推导；n 个有限集合的广义交并展开定理；
    • 数论应用：求特定区间内不能被若干素数整除的整数个数；
    • 集合分类应用：球类团队兼项人数、课程选修多重交叠统计模型。
  • 1.2 鸽巢原理 (抽屉原理)
    • 基础形式与广义形式；数论余数同余差整除证明应用。

组合计数 2：常系数齐次线性递推关系

  • 2.1 递推关系概念与特征方程法
    • 斐波那契数列建模；k 阶常系数齐次线性递推方程 a_n + b_1 a_{n-1} + \dots + b_k a_{n-k} = 0 的代数结构；
    • 特征多项式与特征根定理；单特征根的通解线性叠加。
  • 2.2 重特征根的处理
    • 特征根为 r 重根时，基底解构造成形式 n^j q^n（j = 0, 1, \dots, r-1）；
    • 经典求解：斐波那契通项公式推导、含二重根/三重根高阶递推关系的初始条件定解。

组合计数 3：常系数非齐次线性递推关系及应用

  • 3.1 非齐次递推方程解的结构
    • 通解结构定理：\text{通解} = \text{对应齐次通解} + \text{非齐次特解}。
  • 3.2 待定系数法求特解
    • 多项式型自由项 f(n) = P_t(n)：若 1 是特征方程的 r 重根，设特解为 n^r Q_t(n)；
    • 指数型自由项 f(n) = a d^n：若 d 是特征方程的 r 重根，设特解为 A n^r d^n。
  • 3.3 递推关系的拓展应用
    • 利用非齐次差分递推关系求解自然数高阶幂和公式（如 \sum_{k=1}^n k^4）。

组合计数 4：普通生成函数及其应用

  • 4.1 生成函数 (母函数) 基础
    • 序列与幂级数的一一对应思想；常见数列生成函数（如 a_n=q^n, a_n=n 的封闭形式化简）；
    • 级数指标平移变换技巧；广义二项式系数与负指数幂展开公式 \binom{-n}{k} = (-1)^k \binom{n+k-1}{k}。
  • 4.2 用生成函数求解线性递推方程
    • 乘以 x^n 对 n 求和构建母函数方程；通过有理分式部分分式分解求逆级数展开得出数列通项。

组合计数 5：生成函数在重复组合与格路中的应用

  • 5.1 多重集的组合数
    • 构造形式多项式展开模型，将组合计数转化为多项式乘积中 x^k 系数提取；
    • 无限重复组合（可放回抽样）公式 \widetilde{C}_n^k = \binom{n+k-1}{k} 的生成函数代数证明。
  • 5.2 多重集的全排列与非降路径模型
    • 多重集全排列的多项式系数定理；
