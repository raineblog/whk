- 金属杆 ab 在水平向右的外力 F 作用下做初速度为 0、加速度 a = 5.0\\text{ m/s}^2 的**匀加速直线运动**。
- 运动切割磁感线产生感应电动势 E = BLv = BLat，电动势随时间均匀增大。
- 电阻 R 与电容器 C 并联在导轨两端，两端电压即为感应电动势 U = E。
- **电容器特性**：由于两端电压随时间均匀增加，电容器处于持续充电状态，回路中会产生**恒定的充电电流**。

**(2) 求 t = 2\\text{ s} 时外力 F 的大小**

### 【例 2 详解】分布参数（回路电阻随位移变化）电量积分模型

#### 1. 物理过程与情境剖析

- 导轨和导体棒单位长度的电阻均为 r_0，当导体棒在导轨上运动时，**回路的有效周长发生变化，导致回路总电阻随位移连续变化**。
- 传统的感应电量公式 q = \\frac{\\Delta \\Phi}{R} 仅适用于**回路总电阻 R 为定值**的情形。对于总电阻随位移变化的情形，必须采用**微元积分法**（\\mathrm{d}q = I\\mathrm{d}t = \\frac{\\mathrm{d}\\Phi}{R(x')}）求解。
- 设初始状态导体棒距离导轨左端闭合边的距离为 x_0。当导体棒移动 x 时，积分即可求得电荷量。

#### 2. 详细推导与求解

- 设闭合回路的宽度为 L。当导体棒向右运动至离左边闭合导轨距离为 x' 时：
  - 左端导轨长度为 L，阻值为 R_1 = L r_0；
  - 导体棒长度为 L，阻值为 R_2 = L r_0；
  - 上、下两根导轨接入回路的长度均为 x'，阻值各为 x' r_0。
- 此时回路的总电阻为： R(x') = R_1 + R_2 + 2 x' r_0 = 2L r_0 + 2x' r_0 = 2r_0(L + x')
- 在极短时间 \\mathrm{d}t 内，棒向右移动微元位移 \\mathrm{d}x'，回路磁通量的变化量为： \\mathrm{d}\\Phi = B \\mathrm{d}S = B L \\mathrm{d}x'
- 通过回路截面的微元电荷量为： \\mathrm{d}q = I \\mathrm{d}t = \\frac{E}{R(x')} \\mathrm{d}t = \\frac{1}{R(x')} \\frac{\\mathrm{d}\\Phi}{\\mathrm{d}t} \\mathrm{d}t = \\frac{\\mathrm{d}\\Phi}{R(x')}
- 将 R(x') 与 \\mathrm{d}\\Phi 代入： \\mathrm{d}q = \\frac{B L \\mathrm{d}x'}{2r_0(L + x')} = \\frac{BL}{2r_0} \\cdot \\frac{\\mathrm{d}x'}{L + x'}
- 对整个移动位移过程积分（设棒的初始位置为 x_0，移动后的末位置为 x_0 + x）： q = \\int\_{x_0}^{x_0 + x} \\frac{BL}{2r_0} \\frac{\\mathrm{d}x'}{L + x'} = \\frac{BL}{2r_0} \\left[ \\ln(L + x') \\right]\_{x_0}^{x_0 + x} = \\frac{BL}{2r_0} \\ln\\left( \\frac{L + x_0 + x}{L + x_0} \\right)

### 【例 3 详解】宏观电磁感应动量与微观载流子定向移动距离的映射

#### 1. 物理过程与情境剖析

- **匀速阶段**：金属棒以速度 v_0 匀速运动，棒内自由电子沿棒定向移动速率为 u_0。利用微观电流公式 I = neSu 与宏观欧姆定律 I = \\frac{BLv}{R}，可以建立金属棒宏观速度 v 与电子微观漂移速度 u 的**线性正比例约束关系**。
- **撤去外力阶段**：棒仅受安培阻力做减速运动，直到电子定向移动速率降为 \\frac{u_0}{2}。由线性关系可知，此时棒的宏观速度也降为 \\frac{v_0}{2}。
- **动量定理连接电量**：对金属棒运用动量定理，安培力的冲量等于动量的改变量，从而得出该阶段流过的**总电荷量 q**。
- **微观电量与移动距离**：总电荷量 q = neS \\cdot d，即可直接反解出电子沿棒定向移动的宏观平均距离 d。

#### 2. 详细推导与求解

**(1) 建立棒速 v 与电子定向移动速率 u 的瞬时关系**

- 设棒内单位体积的自由电子数为 n，棒的横截面积为 S，元电荷为 e。
- 根据电流的微观表达式，任一时刻棒中的电流为： I = neSu
- 另一方面，根据宏观法拉第电磁感应定律与闭合电路欧姆定律，忽略其余电阻，电流为： I = \\frac{E}{R} = \\frac{BLv}{R}
- 联立以上两式可得： neSu = \\frac{BLv}{R} \\implies v = \\left( \\frac{neSR}{BL} \\right) u
- 由于 n, e, S, R, B, L 均为恒定量，因此**棒的宏观速度 v 与自由电子沿棒定向移动的速率 u 始终成正比**： \\frac{v}{u} = \\frac{v_0}{u_0} = \\text{常数}
- 当自由电子沿棒定向移动速率变为 u_1 = \\frac{u_0}{2} 时，金属杆的运动速度也对应变为： v_1 = \\frac{v_0}{2}

**(2) 运用动量定理求通过棒的感应电量 q**

- 撤去外力后，金属棒在水平方向只受安培力 F_A = BIL（方向与速度相反）。
- 取向右为正方向，根据动量定理，在时间 \\Delta t 内： -\\sum F_A \\Delta t = m v_1 - m v_0 即： -BL \\sum I \\Delta t = m \\left( \\frac{v_0}{2} - v_0 \\right) \\implies -BLq = -\\frac{1}{2}mv_0
- 由此解得通过回路的电荷量为： q = \\frac{mv_0}{2BL}

**(3) 求自由电子沿杆定向移动的距离 d**

- 一直在金属杆内的自由电子，在时间段内沿杆定向移动的平均距离为 d = \\int u \\mathrm{d}t。
- 根据电量与微观量的关系： q = \\int I \\mathrm{d}t = \\int neSu \\mathrm{d}t = neS \\int u \\mathrm{d}t = neS \\cdot d
- 由初始匀速状态时的微观与宏观电流等式： I_0 = neSu_0 = \\frac{BLv_0}{R} \\implies neS = \\frac{BLv_0}{Ru_0}
- 将 neS 代入电量式： q = \\left( \\frac{BLv_0}{Ru_0} \\right) d
- 联立两式： \\frac{BLv_0}{Ru_0} d = \\frac{mv_0}{2BL}
- 解得自由电子沿杆定向移动的距离： d = \\frac{m R u_0}{2 B^2 L^2}

### 【例 4 详解】双棒追及模型与动量定理极值分析

#### 1. 物理过程与情境剖析

- **初始阶段**：M 在磁场外向右匀速运动，速度为 v_0；N 在磁场内静止，二者构成的回路磁通量不变（甚至回路尚未完全闭合导通），无感应电流，N 保持静止。
- **M 刚进入磁场时刻**：M 越过 ab 边界时，速度仍为 v_0。此时 M 与 N 之间的初始距离就是题中所求的 x。
- **双棒在磁场内运动**：
  - 相对速度 (v_M - v_N) > 0，回路产生逆时针方向感应电流。
  - M 受向左的安培力做减速运动，N 受向右等大的安培力做加速运动。
  - **系统动量守恒**：两棒质量相等，合外力（合安培力）为零，系统总动量保持为 mv_0。
- **追及与极值临界**：
  - 只要 v_M > v_N，M 的速度就始终大于 N，两棒之间的间距 \\Delta x(t) = x_N(t) - x_M(t) 就**单调减小**。
  - 题目要求“两棒在磁场内未相撞”，且“N 出磁场时的速度为 \\frac{v_0}{3}”。
  - 两棒间距的**最小值必定出现在 N 刚离开磁场的瞬间**。
  - 临界不相撞条件即为：**当 N 出磁场时，M 恰好追上 N（此时相对位移等于初始距离 x）**。

#### 2. 详细推导与求解

**(1) 确定两棒在磁场中运动时的末状态速度**

- 取向右为正方向。由于双棒所受安培力大小相等、方向相反，双棒系统在水平方向动量守恒： m v_M + m v_N = m v_0
- 当 N 杆离开磁场时，已知其速度为 v_N = \\frac{v_0}{3}，此时 M 杆的速度为： v_M = v_0 - v_N = v_0 - \\frac{v_0}{3} = \\frac{2}{3}v_0 *(注意：\\frac{2}{3}v_0 > \\frac{1}{3}v_0，说明在磁场运动全过程中，始终有 v_M > v_N，相对间距单调变小。)*

**(2) 利用微分与动量定理求相对位移 \\Delta s**

- 在任一时刻，回路的感应电动势： E = BL(v_M - v_N)
- 回路总电阻为 2R（双棒各为 R，导轨电阻不计），回路感应电流为： I = \\frac{E}{2R} = \\frac{BL(v_M - v_N)}{2R}
- 对 N 棒应用动量定理，在极短时间 \\mathrm{d}t 内： F_A \\mathrm{d}t = m \\mathrm{d}v_N 即： B I L \\mathrm{d}t = m \\mathrm{d}v_N \\implies \\frac{B^2 L^2}{2R} (v_M - v_N) \\mathrm{d}t = m \\mathrm{d}v_N
- 注意到 (v_M - v_N)\\mathrm{d}t = \\mathrm{d}s_M - \\mathrm{d}s_N = \\mathrm{d}(\\Delta s)，正是**两棒相对位移的微元**！
- 对整个在磁场中共存运动的过程积分： \\frac{B^2 L^2}{2R} \\int (v_M - v_N) \\mathrm{d}t = m \\int_0^{v_0/3} \\mathrm{d}v_N，\\frac{B^2 L^2}{2R} (s_M - s_N) = m \\left( \\frac{v_0}{3} - 0 \\right) = \\frac{1}{3}mv_0
- 解得在 N 杆出磁场前，两棒的相对位移量为： \\Delta s = s_M - s_N = \\frac{\\frac{1}{3}mv_0}{\\frac{B^2 L^2}{2R}} = \\frac{2m R v_0}{3B^2 L^2}

**(3) 求解最小初始距离 x**

- 初始时刻 M 位于边界 ab 处，N 位于距 ab 距离为 x 处，初始相对距离为 x。
- 运动过程中两棒距离为： d(t) = x + s_N(t) - s_M(t) = x - (s_M(t) - s_N(t))
- 为保证在磁场内不相撞，必须满足直至 N 离开磁场时，两棒间距始终 d(t) \\ge 0： x \\ge s_M - s_N
- 因此，初始时刻 N 杆到 ab 的最小距离为： x\_{\\min} = \\frac{2m R v_0}{3B^2 L^2}

#### 1. 微元法与状态积分思想（突破非恒定变量的利器）

- **适用场景**：电流 I 变动、电阻 R 变动、速度 v 变动的非平衡状态。

#### 2. “动量—电量”桥梁法（电磁动力学的黄金通道）

- **核心逻辑链条**： \\text{安培力} \\ F_A = BIL \\implies \\text{冲量} \\ I_A = \\int F_A \\mathrm{d}t = BL \\int I \\mathrm{d}t = BLq

#### 3. 宏微观互换与对称思维

- **宏微映射法**：在处理微观带电粒子问题时，牢记两条主线：

- 将难以测量的微观漂移距离 d 转化为宏观的动量改变量 \\Delta p 和外电路参数。

- 双棒运动中，“不相撞”、“恰好相撞”、“间距最小”的本质均为相对速度判据：
