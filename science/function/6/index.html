高中不等式进阶

柯西不等式

柯西不等式的引入

我们将讲解以向量为背景的不等式，这一部分的不等式需要建立一种思维，在二维（以及三维空间中），我们有欧式几何，从中可以推导出很多形式，将其代数化，这是有理有据的，比如向量经典三角不等式

|\bm u+\bm v|\le|\bm u|+|\bm v|

在二维空间中，我们完全可以用欧式几何来证明，三维空间同理，但是在高维空间中，我们需要用闵可夫斯基不等式来证明，因此这就是为什么闵可夫斯基不等式不能用上式来证明。

又如柯西不等式本身说的是

|\bm u\cdot\bm v|\le|\bm u|\cdot|\bm v|

其本身定义了高维空间下的向量夹角余弦值，而在二、三维空间中，我们可以用欧式几何来定义夹角余弦值，同样在高维空间中，我们不能用上式来证明柯西不等式。

我们可以做一个没有道理的推导，在二、三维空间中的以上结论，可以辅助我们理解和记忆，但是不能直接用来证明高维下的不等式，但是用向量来记忆和理解，确实非常有效的，因为其反映了我们对世界的基本数学认知。

柯西-施瓦茨不等式

柯西不等式表明，对于实数 a_1,a_2,b_1,b_2：

(a_1^2+a_2^2)(b_1^2+b_2^2)\ge(a_1b_1+a_2b_2)^2

在柯西不等式中，因为有平方，所以开方要小心绝对值、正负号等问题，比如上式右侧 a_1b_1,a_2b_2，系数均可以写作 \pm 1，但左侧必须是加而不能是减。

【经典例题】：填出所有使不等式成立的答案。

  1. (a_1^{\_\_}+a_2^{\_\_})(b_1^2+b_2^2)\ge(a_1^3b_1+a_2^3b_2)^2

    答案：6；6。

  2. (a_1^2+a_2^2)(b_1^2+b_2^2)\ge(\_\_ a_1b_1+a_2b_2)^2

    答案：\pm 1（1 或 -1）。

  3. (x^2+y^2)(9+\_\_)\ge(3x-2y)^2

    答案：4。

任何不等式的使用必须验证取等条件，上不等式取等条件为

a_1b_2=a_2b_1

【经典例题】：写出不等式的取等条件，并判断在相应条件下，是否可以取等。

  1. 5(a^2 + b^2) \ge (2a + b)^2

  2. 已知 a + b = 1，5(a^2 + b^2) \ge (2a + b)^2

  3. 5(a^2 + b^2) \ge (2a - b)^2

  4. 已知 a + b = 1，5(a^2 + b^2) \ge (2a - b)^2

  5. 14(a^2 + b^2 + c^2) \ge (a + 2b + 3c)^2

  6. 已知 a + b + c = 1，14(a^2 + b^2 + c^2) \ge (a + 2b + 3c)^2

  7. 已知 a + b + c = 1，a = 2c，14(a^2 + b^2 + c^2) \ge (a + 2b + 3c)^2

证明方法一：直接展开

要证明这个简单的不等式，最方便的做法就是直接展开：

a_1^2b_1^2+a_2^2b_2^2+a_1^2b_2^2+a_2^2b_1^2\ge a_1^2b_1^2+a_2^2b_2^2+2a_1b_1a_2b_2

约去相同的项，得到

a_1^2b_2^2+a_2^2b_1^2\ge 2a_1b_1a_2b_2

可以配方，也可以根据均值不等式，

a_1^2b_2^2+a_2^2b_1^2\ge2\sqrt{a_1^2a_2^2b_1^2b_2^2}\ge2a_1a_2b_1b_2

取等条件：

{a_1\over b_1}={a_2\over b_2}

证明方法二：换元法

还可以换元，不妨设

A=\sqrt{a_1^2+a_2^2},B=\sqrt{b_1^2+b_2^2}

则不等式可以表示为

\dfrac{(a_1b_1+a_2b_2)}{AB}\le1

不妨拆开，也就是

\dfrac{a_1b_1}{AB}+\dfrac{a_2b_2}{AB}\le\dfrac{1}{2}\left(\dfrac{a_1^2}{A^2}+\dfrac{b_1^2}{B^2}+\dfrac{a_2^2}{A^2}+\dfrac{b_2^2}{B^2}\right)=1

对于一般的实数序列 a_i,b_i：

\sum_{i=1}^na_i^2\sum_{i=1}^nb_i^2\ge\left(\sum_{i=1}^na_ib_i\right)^2

证明可以展开，用拉格朗日恒等式，但是较为复杂，取等条件为：

{a_1\over b_1}={a_2\over b_2}=\dots={a_n\over b_n}

若某个 b_i 为零，这个式子失效，但是仍然可以用 a_1b_2=a_2b_1=\dots=a_{n-1}b_n 来验证。

证明方法三：判别式法

可以用判别式证明，不妨令

A=\sum_{i=1}^na_i^2,B=\sum_{i=1}^na_ib_i,C=\sum_{i=1}^nb_i^2,

要证即 AC\ge B^2，不妨构造方程，注意到可以将 \sum 合并，配方为

f(x)=Ax^2+2Bx+C=\sum_{i=1}^n(a_ix+b_i)^2\ge0

因为二次函数恒非负，且二次项系数 A 非负，则一定有判别式非正：

\dfrac{\Delta}{4}=B^2-AC\le 0\implies AC\ge B^2

取等可以是存在 x 使得 a_ix+b_i 均为零。

柯西不等式有两个常见的变形，这两个变形无须记忆，重点应该记忆柯西不等式的标准形式

  1. 平方和形式：设 a_1, a_2, \dots, a_n 为任意实数，则

    \left(\sum_{i=1}^n a_i\right)^2 \leqslant n \sum_{i=1}^n a_i^2,

    等号当且仅当 a_1 = a_2 = \dots = a_n 时成立。

    在柯西不等式中取 b_i = 1（i = 1, 2, \dots, n），即得 \left(\sum_{i=1}^n a_i\right)^2 \leqslant \left(\sum_{i=1}^n a_i^2\right) \cdot n。等号条件为 a_i 与常数 1 成比例，即 a_i 全部相等。

  2. 倒数和形式：设 a_1, a_2, \dots, a_n 为正实数，则

    \left(\sum_{i=1}^n a_i\right) \left(\sum_{i=1}^n \dfrac{1}{a_i}\right) \geqslant n^2,

    等号当且仅当 a_1 = a_2 = \dots = a_n 时成立。

    在柯西不等式中取 b_i = 1/\sqrt{a_i}（i=1,2,\dots,n），则 a_i^2b_i^2=a_i，且 b_i^2=1/a_i，即得 \left(\sum_{i=1}^n a_i\right) \left(\sum_{i=1}^n \dfrac{1}{a_i}\right) \geqslant \left(\sum_{i=1}^n 1\right)^2=n^2。等号条件为 \sqrt{a_i} 与 1/\sqrt{a_i} 成比例，即 a_i 全部相等。

更常见的推论是分数和形式，我们在下面单独讲解。

证明方法四：物理法

光滑桌子（\mu=0）上面放着若干个质量不一的薄板，其中间的摩擦因数不为零（\mu\neq0）。

设其质量分别为 m_1,m_2,\dots,m_n，给它们一个互异的初速度 v_1,v_2,\dots,v_n。

根据能量守恒定律，经过有限的时间后，它们必定会趋于同一个速度，设为 v_f。

那么，根据动量守恒定律和功能关系：

\begin{aligned} m_1v_1+m_2v_2+\dots+m_nv_n&=m_1v_f+m_2v_f+\dots+m_nv_f\\ {1\over2}m_1v_1^2+{1\over2}m_2v_2^2+\dots+{1\over2}m_nv_n^2&\ge {1\over2}m_1v_f^2+{1\over2}m_2v_f^2+\dots+{1\over2}m_nv_f^2 \end{aligned}

化简、移项，得到：

\begin{aligned} v_f={\sum m_iv_i\over\sum m_i}\\ \sum(m_iv_i^2)\ge(\sum m_i)v_f^2 \end{aligned}

上式代入下式，得：

\sum(m_iv_i^2)\ge{(\sum m_iv_i)^2\over\sum m_i}

再移项，得：

\sum(m_iv_i^2)\sum m_i\ge(\sum m_iv_i)^2

我们取 m\to a^2，v\to b/a，即：

\sum{a_i^2}\sum{b_i^2}\ge(\sum{a_ib_i})^2

取等条件为初始就共速，即 v_1=v_2=\dots=v_n，则：

{b_1\over a_1}={b_2\over a_2}=\dots={b_n\over a_n}

即柯西不等式（当然这个结论比柯西不等式弱一些）。

在 n 维空间中，夹角余弦值的定义就是内积

\cos\theta=\dfrac{\bm a\cdot \bm b}{|\bm a|\cdot|\bm b|}

而要证明夹角余弦值的绝对值 \le 1，即证明

|\bm a\cdot\bm b|\le|\bm a|\cdot|\bm b|

不妨设两向量为

\bm a=(a_1,a_2,\dots,a_n),\bm b=(b_1,b_2,\dots,b_n)

展开即为柯西不等式，因此夹角余弦值可以用来记忆和理解柯西不等式，但是不能用来证明柯西不等式，因为 |\cos\theta|\le1 本身就是柯西不等式的一种形式。需要注意的是，在二维、三维中，从几何余弦定理可以推出柯西不等式，因为几何角度独立；但 n 维的“夹角”通常没有独立几何定义，是内积诱导的。即使可以嵌入二维平面，也需先建立内积与长度，可能仍依赖柯西不等式。

从向量的角度证明柯西不等式与判别式法类似，对任意实数 t，有

|\bm a+t\bm b|^2=|\bm a|^2+2t(\bm a\cdot\bm b)+t^2|\bm b|^2\ge 0

因此判别式 \Delta\le 0，即柯西不等式的向量形式。

柯西不等式的分式形式

柯西不等式的分式形式，也称为分数和形式、Engel 形式（虽然中文不常用，但是也可以叫作安多形式）、Titu 引理（或谐音为 T2 引理），更一般化的时候称为权方和不等式，因为权方和不等式的形式很复杂，且用起来也不方便，因此一般只用 Engel 形式。

最简单的二元形式可以写作

\dfrac{a_1^2}{b_1}+\dfrac{a_2^2}{b_2}\ge\dfrac{(a_1+a_2)^2}{b_1+b_2}

更一般的形式可以写作

\dfrac{a_1^2}{b_1}+\dfrac{a_2^2}{b_2}+\dots+\dfrac{a_n^2}{b_n}\ge\dfrac{(a_1+a_2+\dots+a_n)^2}{b_1+b_2+\dots+b_n}

其中必须有任意 b_i>0，而对 a_i 的要求是任意实数即可。

等号成立当且仅当

\dfrac{a_1}{b_1}=\dfrac{a_2}{b_2}=\dots=\dfrac{a_n}{b_n}

证明由柯西不等式形式

(a_1^2+a_2^2+\dots+a_n^2)(b_1^2+b_2^2+\dots+b_n^2)\ge(a_1b_1+a_2b_2+\dots+a_nb_n)^2

令 a_i=\dfrac{x_i}{\sqrt{y_i}},b_i=\sqrt{y_i}，那么

\left(\dfrac{x_1^2}{y_1}+\dfrac{x_2^2}{y_2}+\dots+\dfrac{x_n^2}{y_n}\right)(y_1+y_2+\dots+y_n)\ge(x_1+x_2+\dots+x_n)^2

除过去即为 Engel 形式。

权方和不等式

设 a_1,a_2,\dots,a_n>0,b_1,b_2,\dots,b_n>0,r\in\mathbb{R}，则

  • 当 r\ge0，或 r\le-1 时，有

    \dfrac{a_1^{r+1}}{b_1^{r}}+\dfrac{a_2^{r+1}}{b_2^{r}}+\dots+\dfrac{a_n^{r+1}}{b_n^{r}}\ge\dfrac{(a_1+a_2+\dots+a_n)^{r+1}}{(b_1+b_2+\dots+b_n)^{r}}。

  • 当 -1<r<0 时，有

    \dfrac{a_1^{r+1}}{b_1^{r}}+\dfrac{a_2^{r+1}}{b_2^{r}}+\dots+\dfrac{a_n^{r+1}}{b_n^{r}}\le\dfrac{(a_1+a_2+\dots+a_n)^{r+1}}{(b_1+b_2+\dots+b_n)^{r}}。

示例：已知实数 x,y>0 满足 \dfrac{1}{x}+\dfrac{4}{y}=1，求 x+y 的最小值。根据权方和不等式：

1=\dfrac{1^2}{x}+\dfrac{2^2}{y}=\dfrac{a^2}{x}+\dfrac{b^2}{y}\ge\dfrac{(a+b)^2}{x+y}=\dfrac{(1+2)^2}{x+y}=\dfrac{9}{x+y}

即：

1\ge\dfrac{9}{x+y}\Rightarrow x+y\ge 9

所以 x+y 的最小值为 9。

我们温故一下 Titu’s Lemma

\dfrac{a_1^2}{b_1}+\dfrac{a_2^2}{b_2}+\dots+\dfrac{a_n^2}{b_n}\ge\dfrac{(a_1+a_2+\dots+a_n)^2}{b_1+b_2+\dots+b_n}

对于任意 b_i>0 时成立，等号成立的条件是

\dfrac{a_1}{b_1}=\dfrac{a_2}{b_2}=\dots=\dfrac{a_n}{b_n}=\lambda

例题一：已知正实数 a,b,c 满足条件 a+b+c=1，求 \dfrac{1}{a}+\dfrac{4}{b}+\dfrac{9}{c} 的最小值。

这个题非常有意思的观察是 1,4,9 都是完全平方数，但是这不重要，我们构造 Titu 引理的形式，即分子都是平方，分母都是一次，有

\dfrac{1^2}{a}+\dfrac{2^2}{b}+\dfrac{3^2}{c}\ge\dfrac{(1+2+3)^2}{a+b+c}=36

例题三：对于正实数序列 a_1,a_2,\dots,a_n 与 b_1,b_2,\dots,b_n，且满足 a_1+a_2+\dots+a_n=b_1+b_2+\dots+b_n，证明

\dfrac{a_1^2}{a_1+b_1}+\dfrac{a_2^2}{a_2+b_2}+\dots+\dfrac{a_n^2}{a_n+b_n}\ge\dfrac{a_1+a_2+\dots+a_n}{2}

直接应用 TiTu 引理，

\begin{aligned} \sum_{k=1}^n\dfrac{a_k^2}{a_k+b_k}&\ge\dfrac{(a_1+a_2+\dots+a_n)^2}{a_1+a_2+\dots+a_n+b_1+b_2+\dots+b_n}\\ &=\dfrac{(a_1+a_2+\dots+a_n)^2}{2(a_1+a_2+\dots+a_n)}\\ &=\dfrac{a_1+a_2+\dots+a_n}{2} \end{aligned}

解析几何中的柯西不等式

考虑用柯西不等式的形式证明点到直线的距离公式：点 P(x_0,y_0) 到直线 \ell:Ax+By+C=0 的距离为

d=\dfrac{|Ax_0+By_0+C|}{\sqrt{A^2+B^2}}

我们不妨用经典的策略，将求点到直线的距离，转化为求点到直线上另一点的距离最小值，不妨设直线上的点 Q(x_1,y_1)，根据上面的公式，可以猜到构造形式

(A^2+B^2)[(x_0-x_1)^2+(y_0-y_1)^2]\ge[A(x_0-x_1)+B(y_0-y_1)]^2

注意到 Q 在直线上等价于 Ax_1+By_1+C=0，因此不等式右侧就是 Ax_0+By_0+C，而左侧第二个平方和就是点到直线的距离，开方即可

(x_0-x_1)^2+(y_0-y_1)^2\ge\dfrac{(Ax_0+By_0+C)^2}{A^2+B^2}

d=\{\sqrt{(x_0-x_1)^2+(y_0-y_1)^2}\}_{\min}=\dfrac{|Ax_0+By_0+C|}{\sqrt{A^2+B^2}}

已知点 P(x_0,y_0) 是椭圆 \dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}=1 上的点，求 Ax_0+By_0 的取值范围。

这道题所求的形式，看起来就和上一道题很类似，如果直接柯西的话，容易写出

(A^2+B^2)(x_0^2+y_0^2)\ge(Ax_0+By_0)^2

但是我们发现左侧形式不好，点 P 在椭圆上，我们只能转化为 \dfrac{x_0^2}{a^2}+\dfrac{y_0^2}{b^2}=1，所以我们不妨把左侧改造一下

\left(\dfrac{x_0^2}{a^2}+\dfrac{y_0^2}{b^2}\right)(a^2A^2+b^2B^2)\ge(Ax_0+By_0)^2

因此

-\sqrt{a^2A^2+b^2B^2}\le Ax_0+By_0\le\sqrt{a^2A^2+b^2B^2}

用柯西不等式理解椭圆的切线方程：假设椭圆是 \dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}=1 的形式，我们知道切线必然不过原点，也就是可以写作 \ell:Ax+By+C=0，当我们固定一个 \theta，也就是固定了切线的方向（法向量），结合图像我们容易发现，切线就是拿着这根斜率确定的直线去尝试交椭圆，而 C 反映这个直线的相对位置，那么随着直线的运动，假设直线与椭圆有一交点（不一定是唯一，我们只取一个）P(x_0,y_0)，那么有 C=-Ax_0-By_0，此时我们以点 P 为自变量，而 C 为因变量，我们发现 P 运动一周，两个恰好切点（交点唯一）的，就是 C 的极值点，因此我们考虑上一道题，用柯西不等式放缩，那么取等条件就恰好是切线。

上一道题我们已经做出来了类似的东西，我们发现取等条件是

\dfrac{x_0}{a^2A}=\dfrac{y_0}{b^2B}

我们知道 A,B,C 的确切值不重要，重要的是他们的比例关系，因此不妨假设 A=\sin\theta,B=\cos\theta，上式整理得

\tan\theta=\dfrac{x_0b^2}{y_0a^2}

因此

A=\sin\theta=\dfrac{x_0b^2}{\sqrt{x_0^2b^4+y_0^2a^4}}

B=\cos\theta=\dfrac{y_0a^2}{\sqrt{x_0^2b^4+y_0^2a^4}}

C=-\dfrac{x_0^2 b^2 + y_0^2 a^2}{\sqrt{x_0^2b^4+y_0^2a^4}}=-\dfrac{a^2b^2\left(\dfrac{x_0^2}{a^2}+\dfrac{y_0^2}{b^2}\right)}{\sqrt{x_0^2b^4+y_0^2a^4}}=-\dfrac{a^2b^2}{\sqrt{x_0^2b^4+y_0^2a^4}}

最后写出切线 Ax+By+C=0，两边同乘 -\dfrac{\sqrt{x_0^2b^4+y_0^2a^4}}{a^2b^2}：

-\dfrac{x_0}{a^2}x-\dfrac{y_0}{b^2}y+1=0 \quad\Longrightarrow\quad \boxed{\dfrac{x_0 x}{a^2}+\dfrac{y_0 y}{b^2}=1}

这个方法看起来不如直接背下来公式，但是也有一些有意思的地方，比如对偶切线模型方程，已知椭圆 \dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}=1(a,b>0) 的一条切线分别与 x 正半轴、y 轴正半轴交于 A,B 两点，则 |AB| 的最小值为？

我们发现 A,B 的形式，非常适合设为截距式，不妨设 A(m,0),B(0,n) 其中 m,n>0，则直线 \dfrac{x}{m}+\dfrac{y}{n}=1，我们不妨假设直线与椭圆交于点 P(x_0,y_0)，尝试对这个构造柯西不等式

\left(\dfrac{x_0^2}{a^2}+\dfrac{y_0^2}{b^2}\right)\left(\dfrac{a^2}{m^2}+\dfrac{b^2}{n^2}\right)\ge\left(\dfrac{x_0}{m}+\dfrac{y_0}{n}\right)^2=1

根据点 P 的意义，发现最左最右显然都是 1，因此就有：

\dfrac{a^2}{m^2}+\dfrac{b^2}{n^2}\ge1

我们前面提到过，切线，就是恰好取到极值的时候。这里比较迷惑，我们前面用一个 C 来刻画直线的相对位置，这里看起来没有了 C，但是仔细想这个式子的缘由。我们这个式子列出来的是直线与椭圆交点必然满足的条件，也就是在这之外就不满足了，也就是在椭圆外了，当我们取得等时，我们在写的就是一个边界条件，是类似判别式 \Delta=0 的条件，这一点我们可以将截距式化为一般式，直接用判别式等于零，能够看出来上式就反映的是判别式，而等于 1 就是切线。

切线必然满足

\dfrac{a^2}{m^2}+\dfrac{b^2}{n^2}=1

注意到所求 |AB|^2=m^2+n^2，再构造柯西不等式

(m^2+n^2)\left(\dfrac{a^2}{m^2}+\dfrac{b^2}{n^2}\right)\ge(a+b)^2

因此就有

|AB|=\sqrt{m^2+n^2}\ge a+b

概率中的柯西不等式

我们知道对于随机变量 X，设其分布列为 P(X=x_i)=p_i(i=1,2,\dots,n)，其方差 D(X)=E(X^2)-[E(X)]^2，我们知道方差是非负数，于是，我们考虑证明 E(X^2)\ge[E(X)]^2，不妨直接写出来，构造柯西不等式

\left(\sum_{i=1}^nx_i^2p_i\right)\left(\sum_{i=1}^np_i\right)\ge\left(\sum_{i=1}^nx_ip_i\right)^2

我们发现第二项就是 1，因此得证。考虑将这种形式拓展到两个随机变量，设随机变量 X,Y 的数学期望、方差均存在，证明 E(X^2)E(Y^2)\ge[E(XY)]^2。我们注意到这里如果再用设开的形式，就会很复杂，我们想到，数学期望和向量点积很像，因此不妨借鉴柯西不等式证明时的向量方法，不妨构造

f(t)=[E(X-tY)]^2=[E(Y^2)]t^2-2E(XY)t+E(X^2)

因为左式恒大于等于 0，因此右式必有判别式恒小于等于 0，即

\Delta=4[E(XY)]^2-4E(X^2)E(Y^2)\le0

不等式得证。

内斯比特不等式

内斯比特不等式（Nesbitt’s Inequality）是一个很有意思的不等式，不是说他多有用，多奇妙，而是说他的证明方法多到离谱。

内斯比特不等式指出，对于任意正实数 a,b,c 有

\dfrac{a}{b+c}+\dfrac{b}{a+c}+\dfrac{c}{a+b}\ge\dfrac{3}{2}

等号取等当且仅当 a=b=c。

证法一：Titu 引理。这个问题的经典策略是强行构造平方，使用 Titu 引理

\dfrac{a}{b+c}+\dfrac{b}{a+c}+\dfrac{c}{a+b}=\dfrac{a^2}{ab+ac}+\dfrac{b^2}{ab+bc}+\dfrac{c^2}{ac+bc}\ge\dfrac{(a+b+c)^2}{2(ab+ac+bc)}

要证明再次 \dfrac{3}{2}，只需证明

(a+b+c)^2\ge3ab+bc+ac

展开知道这就是 a^2+b^2+c^2\ge ab+bc+ac 的经典均值不等式形式，原不等式得证。

证法二：排序不等式。我们注意到左侧关于 a,b,c 完全对称，也就是随意交换任意一个完全相同，因此我们不妨假设 a\ge b\ge c，那么同时就有 a+b\ge a+c\ge b+c，因此 \dfrac{1}{b+c}\ge\dfrac{1}{a+c}+\ge\dfrac{1}{a+b}，我们应用排序不等式顺序和最大，即顺序和要大于等于某个乱序和，我们要用某些方法让右侧能凑出来原形式，多凑凑可以想出来

\dfrac{a}{b+c}+\dfrac{b}{a+c}+\dfrac{c}{a+b}\ge\dfrac{b}{b+c}+\dfrac{c}{a+c}+\dfrac{a}{a+b}

\dfrac{a}{b+c}+\dfrac{b}{a+c}+\dfrac{c}{a+b}\ge\dfrac{c}{b+c}+\dfrac{a}{a+c}+\dfrac{b}{a+b}

相加注意到右侧是 3，因此左侧是原不等式左侧的两倍，除过去就是原不等式成立。排序不等式证明快，但是验证取等就要稍微复杂一点，这里就不展开。

证法三：接下来我们去证明一个等价形式，形如

2(a+b+c)\left(\dfrac{1}{b+c}+\dfrac{1}{c+a}+\dfrac{1}{a+b}\right)\ge9

若这个不等式成立，我们把系数除到右边，把 a+b+c 乘进去，于是

\dfrac{a+b+c}{b+c}+\dfrac{a+b+c}{c+a}+\dfrac{a+b+c}{a+b}=3+\dfrac{a}{b+c}+\dfrac{b}{a+c}+\dfrac{c}{a+b}\ge\dfrac{9}{2}

再把 3 减过去，原不等式就成立了。

而要证明这个等价形式，不妨证明

[(b+c)+(c+a)+(a+b)]\left(\dfrac{1}{b+c}+\dfrac{1}{c+a}+\dfrac{1}{a+b}\right)\ge9

这个就有很多方法了。

方法一：均值不等式。我们直接用均值，

(b+c)+(c+a)+(a+b)\ge3\sqrt[3]{(b+c)(c+a)(a+b)}

\dfrac{1}{b+c}+\dfrac{1}{c+a}+\dfrac{1}{a+b}\ge3\sqrt[3]{\dfrac{1}{(b+c)(c+a)(a+b)}}

两个乘起来即得证。

方法二：柯西不等式。柯西不等式大于等于号左侧是平方和的积，右侧是点积的平方，不妨构造两遍都是根号，即

\left[\left(\sqrt{b+c}\right)^2+\left(\sqrt{c+a}\right)^2+\left(\sqrt{a+b}\right)^2\right]\left[\left(\sqrt{\dfrac{1}{b+c}}\right)+\left(\sqrt{\dfrac{1}{c+a}}\right)+\left(\sqrt{\dfrac{1}{a+b}}\right)\right]

\ge\left[\sqrt{b+c}\cdot\dfrac{1}{\sqrt{b+c}}+\sqrt{c+a}\cdot\dfrac{1}{\sqrt{c+a}}+\sqrt{a+b}\cdot\dfrac{1}{\sqrt{a+b}}\right]^2=9

得证。

方法三：一个朴素的方法是直接展开，但是这就比较麻烦，此时不妨设 x=a+b,y=b+c,c=a+c，则可以进一步转化为

(x+y+z)\left(\dfrac{1}{x}+\dfrac{1}{y}+\dfrac{1}{z}\right)=3+\dfrac{x}{y}+\dfrac{x}{z}+\dfrac{y}{x}+\dfrac{y}{z}+\dfrac{z}{x}+\dfrac{z}{y}\ge3+6=9

此时也可以用另一个不等式（AM-HM），即

\dfrac{x+y+z}{3}\ge\dfrac{3}{\dfrac{1}{x}+\dfrac{1}{y}+\dfrac{1}{z}}

证法四：不妨观察原式，注意到左侧分式的分子分母都是一次，也就是说左侧是零次的，这就提醒我们观察发现，其实重要的不是 a,b,c 的值本身，而是他们的比例关系。

一种思想是不妨直接假设 a+b+c=1，另一种更加暴力一点，不妨假设 a+b+c=k，也可以理解为不妨假设 a:b:c=x:y:z，而后者 x+y+z=1，总之都是一样的，问题转化为证明

\dfrac{1}{a+b}+\dfrac{1}{b+c}+\dfrac{1}{a+c}\ge\dfrac{9}{2}

这个可以直接根据 AM-HM 的

\dfrac{(a+b)+(b+c)+(c+a)}{3}=\dfrac{2}{3}\ge\dfrac{3}{\dfrac{1}{a+b}+\dfrac{1}{b+c}+\dfrac{1}{a+c}}

解决，或者类似前面去用更加高阶的不等式，但是我们发现这个证法的本质是简化运算，而不是提出一个高级的方法，再用高阶东西但是也属实大炮打蚊子了。

证法五：巧妙构造。不妨令

S=\frac{a}{b+c}+\frac{b}{c+a}+\frac{c}{a+b}

M=\frac{b}{b+c}+\frac{c}{c+a}+\frac{a}{a+b}

N=\frac{c}{b+c}+\frac{a}{c+a}+\frac{b}{a+b}

因此就有 M+N=3，同时根据均值不等式，M+S\ge 3 且 N+S\ge 3，因此就可以得出 M+N+2S\ge 6 进而 2S\ge 3 即 S\ge \dfrac{3}{2}。

如果观察仔细，可以发现这个和排序不等式有点类似。这个方法，很像排序不等式，都是有顺序和和乱序和，但是就是更加具象一点，没有排序不等式的抽象化，但是同时又少一些限制，多一些巧妙的构思，譬如对称的本质，避免了排序不等式的大小顺序的讨论。

卡尔松不等式

从柯西到多个括号。

先回顾非负形式的柯西不等式：

\left(\sum_{i=1}^{m}u_i^2\right) \left(\sum_{i=1}^{m}v_i^2\right) \ge \left(\sum_{i=1}^{m}u_iv_i\right)^2

这里，u_iv_i 是 u_i^2 与 v_i^2 的几何平均数。我们把两个非负序列推广为三个非负序列，记为 x_i,y_i,z_i。最自然的改法是：把逐项乘积换成同一行中三个数的几何平均数，并把外侧的平方换成三次方。于是，我们猜出：

(x_1+x_2)(y_1+y_2)(z_1+z_2) \ge \left( \sqrt[3]{x_1y_1z_1} + \sqrt[3]{x_2y_2z_2} \right)^3

这已经是卡尔松不等式在 m=2,n=3 时的样子。继续推广时，括号有几个，根指数就是几；每个括号里有几个数，就对应几列。这种从柯西不等式的括号个数出发构造新不等式的过程，就是卡尔松不等式最自然的推广路径。

卡尔松不等式的矩阵形式。

在中文资料中，我们通常把下面的有限非负矩阵形式称为卡尔松不等式（Carlson inequality）。设 A=(a_{ij}) 是一个 m\times n 的非负实数矩阵，其中 m,n\in\mathbb{N}^{*}，则有：

\sum_{i=1}^{m}\sqrt[n]{\prod_{j=1}^{n}a_{ij}} \le \sqrt[n]{ \prod_{j=1}^{n} \left(\sum_{i=1}^{m}a_{ij}\right) }

由于两边均非负，将上式两边同时取 n 次方，可以得到与柯西不等式更同型的形式：

\prod_{j=1}^{n} \left(\sum_{i=1}^{m}a_{ij}\right) \ge \left( \sum_{i=1}^{m}\sqrt[n]{\prod_{j=1}^{n}a_{ij}} \right)^n

当 n=2 时，这正是柯西不等式的标准形式；前一个式子只是对它整体取了 \sqrt[n]{}。因此，两种写法没有本质区别，只是观察角度不同。

换句话说，矩阵各行元素的几何平均数之和，不超过各列和的几何平均数。行数 m 决定左侧一共有多少个加数，列数 n 同时决定行内根指数与右侧乘积的因子个数。

证明：为什么按列归一化

记第 j 列的元素和为：

c_j=\sum_{i=1}^{m}a_{ij}

如果直接对每一行使用均值不等式，我们只能得到：

\sum_{i=1}^{m}\sqrt[n]{\prod_{j=1}^{n}a_{ij}} \le \dfrac{1}{n}\sum_{j=1}^{n}c_j

然而，均值不等式又告诉我们：

\dfrac{1}{n}\sum_{j=1}^{n}c_j \ge \sqrt[n]{\prod_{j=1}^{n}c_j}

所以这个上界反而大于我们需要的右侧，无法据此闭合证明。关键在于：不再把每个元素单独拿来做放缩，而是先把每一列整体归一化。

若存在 c_j=0，由于矩阵中的元素均非负，所以这一列全部为 0。此时每一行的乘积都为 0，原不等式两边也都等于 0。以下设所有 c_j>0，并令：

b_{ij}=\dfrac{a_{ij}}{c_j}

这样，每一列的元素和都被归一化为 1：

\sum_{i=1}^{m}b_{ij} =\dfrac{\sum_{i=1}^{m}a_{ij}}{c_j} =1

对于固定的一行 i，再由均值不等式：

\sqrt[n]{\prod_{j=1}^{n}b_{ij}} \le \dfrac{1}{n}\sum_{j=1}^{n}b_{ij}

再对所有 m 行求和，得到：

\dfrac{\displaystyle\sum_{i=1}^{m}\sqrt[n]{\prod_{j=1}^{n}a_{ij}}} {\displaystyle\sqrt[n]{\prod_{j=1}^{n}c_j}} = \sum_{i=1}^{m}\sqrt[n]{\prod_{j=1}^{n}b_{ij}} \le \dfrac{1}{n}\sum_{i=1}^{m}\sum_{j=1}^{n}b_{ij} = \dfrac{1}{n}\sum_{j=1}^{n}\dfrac{\sum_{i=1}^{m}a_{ij}}{c_j}=1

最后乘上 \sqrt[n]{\prod_{j=1}^{n}c_j}，即得卡尔松不等式。整个证明最关键的一步，就是把各个列和作为整体缩放，使每一列的和恰好变成 1。

取等条件。

取等条件仍然需要分情况讨论。

如果存在一个全零列，那么原不等式两边均为 0，等号成立。

如果所有列和均为正，那么均值不等式取等要求每一行归一化后的元素都相等，即：

\dfrac{a_{i1}}{c_1} = \dfrac{a_{i2}}{c_2} = \dots = \dfrac{a_{in}}{c_n}, \qquad i=1,2,\dots,m

等价地，存在 t_1,t_2,\dots,t_m\ge 0，使得：

a_{ij}=t_ic_j \quad (1\le i\le m,\ 1\le j\le n), \qquad \sum_{i=1}^{m}t_i=1

也就是说，除存在全零列的情形外，矩阵的每一行都是列和向量 (c_1,c_2,\dots,c_n) 的非负倍数。因此，所有非零行彼此成比例，零行也允许存在。例如：

A= \begin{pmatrix} 1&2&3\\ 2&4&6 \end{pmatrix}

的两行成比例，所以可以取等号。特别地，当 m=1 或 n=1 时，原不等式退化为恒等式。

当 n=2 时：回到柯西不等式。

令 x_i,y_i\ge 0，并定义：

a_{i1}=x_i^2, \qquad a_{i2}=y_i^2

卡尔松不等式的 n 次方同型形式便给出：

\left(\sum_{i=1}^{m}x_i^2\right) \left(\sum_{i=1}^{m}y_i^2\right) \ge \left(\sum_{i=1}^{m}x_iy_i\right)^2

这正是非负形式的柯西不等式，取等当且仅当 (x_i) 与 (y_i) 线性相关，允许其中一个为零向量。对实数形式，先取绝对值，再用三角不等式，就得到通常的柯西不等式。我们不必把柯西与卡尔松作为两个互不相关的结论记忆：先看到同一个结构中的柯西，再自然推广到多个括号。

当 m=2 时：得到马勒不等式（Mahler’s inequality）。

分别令两行为 x_k 与 y_k，即 x_k=a_{1k}、y_k=a_{2k}，则卡尔松不等式化为：

\sqrt[n]{\prod_{k=1}^{n}x_k} + \sqrt[n]{\prod_{k=1}^{n}y_k} \le \sqrt[n]{\prod_{k=1}^{n}(x_k+y_k)}

这正是马勒不等式：两个非负数列逐项相加后所得数列的几何平均数，不小于原来两个数列的几何平均数之和。对于正数列，等号成立当且仅当：

\dfrac{x_1}{y_1} = \dfrac{x_2}{y_2} = \dots = \dfrac{x_n}{y_n}

这也解释了马勒不等式的按列归一化证明：若存在 k 使 x_k+y_k=0，则等号成立；否则令 c_k=x_k+y_k>0，再分别对 \dfrac{x_k}{c_k} 与 \dfrac{y_k}{c_k} 使用均值不等式。

卡尔松与赫尔德不等式（Hölder’s inequality）。

首先，把 a_{ij} 写成 z_{ij}^{n}，卡尔松不等式就变成：

\sum_{i=1}^{m}\prod_{j=1}^{n}z_{ij} \le \prod_{j=1}^{n} \sqrt[n]{\sum_{i=1}^{m}z_{ij}^{n}}

这正是 n 个序列的等指数广义赫尔德不等式。反过来令 z_{ij}=\sqrt[n]{a_{ij}}，又能恢复卡尔松不等式，所以二者只是同一种结构的不同记号。

我们常用的两序列共轭指数赫尔德不等式为，对于 p,q>1 且 \dfrac{1}{p}+\dfrac{1}{q}=1 有：

\sum_{i=1}^{m}|x_iy_i| \le \sqrt[p]{\sum_{i=1}^{m}|x_i|^p} \sqrt[q]{\sum_{i=1}^{m}|y_i|^q}

若至少一组数列为零数列，则等号成立；否则取等要求存在 \lambda>0，使得 |x_i|^p=\lambda|y_i|^q 对所有 i 成立。

当 p,q 为有理数时，可以取共同分母，按相应次数重复两侧的因子，再应用卡尔松不等式。需要注意的是，这种有限重复的构造只直接给出有理共轭指数；一般的实指数还要借助有理数的逼近与极限，已经超出高中常规，这里不再展开。

当 p=q=2 时，赫尔德不等式回到柯西不等式；它也可以作为推导闵可夫斯基不等式的工具。对高中生而言，我们只需记住：卡尔松给出了等指数广义赫尔德的形式，而更一般的共轭指数赫尔德可以看作同一类均值型结构在不同指数下的推广。

高考 / 强基定位与识别

卡尔松通常不是高考或强基的直接考点；即使在强基中出现，也多以结构变形后的形式考察。直接套用定理的频率并不高。真正值得掌握的是卡尔松不等式对柯西不等式的自然推广，以及它对马勒、赫尔德等均值型不等式的统一作用。

做题时，优先观察能否整理成与柯西同型的 n 次方形式：右侧是 n 个列和相乘，左侧是各行几何平均数之和的 n 次方。如果两侧能够对应，就可以尝试使用卡尔松不等式。不过，如果均值不等式、柯西不等式或一元函数方法能够更短地解决问题，也不必强行套用。重要的不是每道题都用它，而是能够认出这种结构。

闵可夫斯基不等式

闵科夫斯基不等式（或闵可夫斯基不等式，作者的输入法抽风，本文可能混用，感谢您的理解）表明，对于任意实数 a_1,a_2,b_1,b_2 有

\sqrt{a_1^2+a_2^2}+\sqrt{b_1^2+b_2^2}\ge\sqrt{(a_1+b_1)^2+(a_2+b_2)^2}

如果我们令 \bm u=(a_1,a_2),\bm v=(b_1,b_2)，这个式子说的就是

|\bm u|+|\bm v|\ge|\bm u+\bm v|

由代数特征，不难发现实际上也有

\sqrt{a_1^2+a_2^2}+\sqrt{b_1^2+b_2^2}\ge\sqrt{(a_1\pm b_1)^2+(a_2\pm b_2)^2}

\sqrt{a_1^2+a_2^2}+\sqrt{b_1^2+b_2^2}\ge\sqrt{(a_1\pm b_2)^2+(a_2\pm b_1)^2}

等等，用各种方法都可以证明，上式取等条件为

\dfrac{a_1}{b_1}=\dfrac{a_2}{b_2}

或者

a_1b_2=a_2b_1

拓展到 n 维就是

\sqrt{a_1^2+a_2^2+\dots+a_n^2}+\sqrt{b_1^2+b_2^2+\dots+b_n^2}\ge\sqrt{(a_1+b_1)^2+(a_2+b_2)^2+\dots+(a_n+b_n)^2}

更一般的，设 p\ge 1，x_k,y_k\in\mathbb R，有

\sqrt[p]{\sum_{k=1}^n|x_k+y_k|^p}\le\sqrt[p]{\sum_{k=1}^n|x_k|^p}+\sqrt[p]{\sum_{k=1}^n|y_k|^p}

这两个取等条件为

\dfrac{a_1}{b_1}=\dfrac{a_2}{b_2}=\dots=\dfrac{a_n}{b_n}

注意如果有零，那么必然一个数列是全零，因此这样问题可以化简为只有一个数列没有零，把它当作 b 即可避免 0 作为除数的问题。

当 p=1 的平凡形式即为

\sum_{k=1}^n|x_k+y_k|\le\sum_{k=1}^n (|x_k|+|y_k|)

或

|x+y|\le|x|+|y|

的三角不等式形式。

因为有较强的几何意义，因此闵可夫斯基不等式在难度不大的题目中，应用比下面几个广泛得多，例如，已知 x+y=2，求 \sqrt{x^2+1}+\sqrt{y^2+4} 的最小值。

从闵可夫斯基不等式的角度，构造

\sqrt{x^2+1}+\sqrt{y^2+4}\ge\sqrt{(x+y)^2+(1+2)^2}=\sqrt{13}

柯西不等式例题

例一：已知实数 x,y 满足 x^2+y^2=3，求 5x+2y 的最大值。

87=(5^2+2^2)(x^2+y^2)\ge(5x+2y)^2

所以 5x+2y 的最大值为 \sqrt{87}。

我们知道这道题还可以用三角代换，所以我们不妨来延伸一下，考虑证明

-\sqrt{a^2+b^2}\le a\sin x+b\cos x\le\sqrt{a^2+b^2}

我们不妨构造

(a^2+b^2)(\sin^2x+\cos^2x)\ge(a\sin x+b\cos x)^2

展开讨论即可。

例二：（1）已知 x,y>0，且 \dfrac{1}{2x+y}+\dfrac{1}{y+1}=1，求 x+2y 的最小值。

观察到分母不好处理，不妨令 m=2x+y,n=y+1，则 y=n-1,x=\dfrac{m-n+1}{2}，条件即 \dfrac{1}{m}+\dfrac{1}{n}=1，所求即为

x+2y=\dfrac{m-n+1}{2}+2n-2=\dfrac{m+3n-3}{2}

我们只需要求 m+3n 的最小值，这里自然可以用均值不等式中“1”的代换思路，即

m+3n=(m+3n)\left(\dfrac{1}{m}+\dfrac{1}{n}\right)=4+\dfrac{3n}{m}+\dfrac{m}{n}\ge4+2\sqrt{3}

同时也可以用柯西不等式的思路，

m+3n=(m+3n)\left(\dfrac{1}{m}+\dfrac{1}{n}\right)\ge(1+\sqrt{3})^2=4+2\sqrt{3}

最终可以得到 x+2y\ge\sqrt{3}+\dfrac{1}{2}。

（2）已知 a,b>0 满足 a+b=1，求 \dfrac{1}{a+2b}+\dfrac{1}{6a+2b} 的最小值。

我们发现，这次给的是线性，要求的是分式，我们想到在曾经均值不等式中就用过的配凑常数的方法，容易想到一个做法就是

\dfrac{1}{a+2b}+\dfrac{1}{6a+2b}=\dfrac{1}{(a+b)+b}+\dfrac{1}{2(a+b)+4a}=\dfrac{1}{b+1}+\dfrac{1}{4a+2}

这可以省去像上一问那种设 x=a+2b,y=6a+2b 的复杂运算，接下来，我们可以换元，也可以不换，构造

\left(\dfrac{1}{b+1}+\dfrac{1}{4a+2}\right)[4(b+1)+(4a+2)]\ge(\sqrt{4}+1)^2

因此

\dfrac{1}{b+1}+\dfrac{1}{4a+2}\ge\dfrac{9}{4(a+b)+6}=\dfrac{9}{10}

例三：已知 x,y,z 均为正数，证明

\dfrac{x^2}{y}+\dfrac{y^2}{z}+\dfrac{z^2}{x}\ge x+y+z

可以直接对左侧用柯西不等式，即

(x+y+z)\left(\dfrac{x^2}{y}+\dfrac{y^2}{z}+\dfrac{z^2}{x}\right)\ge(x+y+z)^2

除过去即可，当然也可以用类似上道题的那种均值不等式的朴素做法，即两侧同加

\dfrac{x^2}{y}+y+\dfrac{y^2}{z}+z+\dfrac{z^2}{x}+x\ge2(x+y+z)

对左侧直接应用三个二元均值不等式即可得到右边。

例四：已知 a+b=1，求证 a^4+b^4\ge\dfrac{1}{8}。

常规做法是设 a=\dfrac{1}{2}+d,b=\dfrac{1}{2}-d，那么

a^4+b^4=\left(\dfrac{1}{2}+d\right)^4+\left(\dfrac{1}{2}-d\right)^4=\dfrac{1}{8}+3d^2+2d^4\ge\dfrac{1}{8}

但是中间的展开很折磨，不妨用柯西不等式，连用两次：

(a^4+b^4)(1+1)\ge(a^2+b^2)^2

(a^2+b^2)(1+1)\ge(a+b)^2

连着代进去，就可以得到

a^4+b^4\ge\dfrac{(a+b)^4}{8}=\dfrac{1}{8}

例五：已知正数 a,b 满足 a^3+b^3=2，求证 a+b\le2。

常规做法是消元求导或代数变形

2=a^3+b^3=(a+b)(a^2-ab+b^2)=\dfrac{1}{4}(a+b)[(a+b)^2+3(a-b)^2]\ge\dfrac{1}{4}(a+b)^3

但是这个做法代数变形较为复杂，当然也可以不妨设 a=x+y,b=x-y，所证即为 x\le 1。代入展开即

a^3+b^3=(x+y)^3+(x-y)^3=2x^3+6xy^2=2

利用 x>0,y\ge 0，直接写出

x^3\le x^3+3xy^2=1

但是用柯西不等式更加简单，我们注意到 3 次方是奇数，不妨配上

(a^3+b^3)(a+b)\ge(a^2+b^2)^2

(a^2+b^2)(1+1)\ge(a+b)^2

因此

(a^3+b^3)(a+b)\ge\dfrac{(a+b)^4}{4}

直接可以化简出来 a+b\le\sqrt[3]{4(a^3+b^3)}=2。

例六：已知 a,b,c 为正数，且满足 abc=1，证明 (a+b)^3+(b+c)^3+(c+a)^3\ge24。

这个题是上面两题的三元拓展，可以直接展开，更简单的是两次均值不等式去避免展开三次方，也就是

\begin{aligned} &\ (a+b)^3+(b+c)^3+(c+a)^3\\ \ge&\ 3\sqrt[3]{(a+b)^3(b+c)^3(c+a)^3}\\ =&\ 3(a+b)(b+c)(c+a)\\ \ge&\ 3\cdot2\sqrt{ab}\cdot2\sqrt{bc}\cdot2\sqrt{ca}\\ =&\ 24abc=24 \end{aligned}

从柯西不等式的角度，不妨将立方项改写为带有分母的形式，构造出安多形式的左端：

\begin{aligned} &\ (a+b)^3+(b+c)^3+(c+a)^3\\ =&\ \dfrac{[(a+b)^2]^2}{a+b}+\dfrac{[(b+c)^2]^2}{b+c}+\dfrac{[(c+a)^2]^2}{c+a}\\ \ge&\ \dfrac{[(a+b)^2+(b+c)^2+(c+a)^2]^2}{(a+b)+(b+c)+(c+a)} \end{aligned}

对分子再用柯西不等式，构造

[(a+b)^2+(b+c)^2+(c+a)^2](1+1+1)\ge[(a+b)+(b+c)+(c+a)]^2

即

(a+b)^2+(b+c)^2+(c+a)^2\ge\dfrac{4}{3}(a+b+c)^2

代入即

(a+b)^3+(b+c)^3+(c+a)^3\ge \dfrac{8(a+b+c)^3}{9}

根据三元均值不等式，

a+b+c\ge3\sqrt[3]{abc}=3

代入即可。

例七：（1）已知 x^2+xy+y^2=1，求 x^2-xy+y^2 的取值范围；（2）已知 4x^2-5xy+4y^2=5，求 x^2+y^2 的取值范围。

这类题目的特征是二次曲线有交叉项，从几何的角度可以旋转来消去交叉项，从代数上，就是和差或积商代换，我们在代换法中再说，从柯西不等式的角度理解，它们属于一个经典的不等式，不妨构造 \bm\alpha=(x,y),\bm\beta=(y,x)，由 |\bm\alpha\cdot\bm\beta|\le\|\bm\alpha\|\cdot\|\bm\beta\| 可得：

|xy+yx|\le\sqrt{x^2+y^2}\cdot\sqrt{y^2+x^2}\implies|2xy|\le x^2+y^2

也就是

-\dfrac{x^2+y^2}{2}\le xy\le\dfrac{x^2+y^2}{2}

以（1）问为例，我们有 x^2+y^2=1-xy，因此

xy-1\le2xy\le1-xy

化简得到

-1\le xy\le\dfrac{1}{3}

因此所求即为

x^2-xy+y^2=1-2xy\in\left[\dfrac{1}{3},3\right]

对于（2）类似，我们可以使用另一种角度，设所求为 S，直接对所求放缩

-\dfrac{S}{2}\le xy=\dfrac{4S}{5}-1\le\dfrac{S}{2}

两边分别解得

\dfrac{10}{13}\le S\le\dfrac{10}{3}

例八：设 a,b,c 均为正数，且 a+b+c=1，证明 ab+bc+ca\le\dfrac{1}{3}。

这道题无论是用均值不等式还是用柯西不等式，重点都在于与平方和建立联系。

在均值不等式上，可以对三个二元不等式相加，即

a^2+b^2\ge2ab,b^2+c^2\ge2bc,c^2+a^2\ge2ca

那么相加即

a^2+b^2+c^2\ge ab+bc+ca

展开放缩

1=(a+b+c)^2=a^2+b^2+c^2+2(ab+bc+ca)\ge3(ab+bc+ca)

因此

ab+bc+ca\le\dfrac{1}{3}

柯西不等式上，我们发现要使 ab+bc+ca 最大，只需令 a^2+b^2+c^2 最小，因此

(a^2+b^2+c^2)(1+1+1)\ge(a+b+c)^2=1

因此

a^2+b^2+c^2\ge\dfrac{1}{3}

再代入

ab+bc+ca=\dfrac{1-(a^2+b^2+c^2)}{2}\le\dfrac{1}{3}

例九：若方程组 \begin{cases}x^2+y^2=2\\ ax+y=2\end{cases} 有且仅有一组解，求实数 a 的值。

由这个形式，我们不妨构造柯西不等式将它们关联起来，即

(x^2+y^2)(a^2+1)\ge(ax+y)^2

代入条件得到

2(a^2+1)\ge 2^2=4\implies a^2+1\ge 2

从几何意义上看，方程组表示直线 ax+y-2=0 与圆 x^2+y^2=2 的交点。当 a^2+1>2 时直线与圆相交，有两组解；当 a^2+1<2 时直线与圆相离无解。因此方程组有且仅有一组解当且仅当直线与圆相切，即柯西不等式取等号：

a^2+1=2\implies a^2=1\implies a=\pm 1

此时柯西不等式取等条件为 \dfrac{x}{a}=y，代入一次方程即可解出唯一的切点解。

例十：（1）求 f(x)=\sqrt{5-3x}+\sqrt{1+x} 的最大值。

接下来我们要进入根式方面，这个是根式的简单题，我们可以对两个根式换元，但是为了更加直观，还是直接写出来，不妨构造

[(5-3x)+(3+3x)]\left(1+\dfrac{1}{3}\right)\ge(\sqrt{5-3x}+\sqrt{1+x})^2

因此原式 \le\sqrt{8\times\dfrac{4}{3}}=\sqrt{\dfrac{32}{3}}。

（2）求 f(x)=\dfrac{2+\sqrt{x^2-2}}{\sqrt{x^2+1}} 的最大值。

不妨将原式写作

S=\dfrac{2}{\sqrt{x^2+1}}+\dfrac{\sqrt{x^2-2}}{\sqrt{x^2+1}}

不妨构造

\left(3\cdot\dfrac{4}{x^2+1}+4\cdot\dfrac{x^2-2}{x^2+1}\right)\left(\dfrac{1}{3}+\dfrac{1}{4}\right)\ge S^2

因此

S^2\le4\cdot\dfrac{7}{12}=\dfrac{7}{3}\implies S\le\sqrt{\dfrac{7}{3}}

例十一：（1）已知 x^2+bx+c=0 在 [1,2] 上有实根，则 b^2+c^2 的最小值为？

这一组题是需要多次操作的，考查的是整体的逻辑构建，我们发现上式，不妨把 b,c 放到等式一边，考虑直接放缩出 b^2+c^2 验等，bx+c=-x^2 构造

(b^2+c^2)(x^2+1)\ge(bx+c)^2=x^4

因此

b^2+c^2\ge\dfrac{x^4}{x^2+1}:=g(x)

考虑到 g(x) 的特征是分子简单，分母复杂，不妨做倒数，先验证 g(x)=0 即 x=0 显然不成立，因此

\dfrac{1}{g(x)}=\dfrac{x^2+1}{x^4}\xlongequal{t=x^2}\dfrac{t+1}{t^2}=\dfrac{1}{t}+\dfrac{1}{t^2}=\dfrac{1}{t}\left(1+\dfrac{1}{t}\right)

因为 x\in[1,2]，所以 t\in[1,4]，那么 g(x) 要求最小值，则上式要取最大值，以 \dfrac{1}{t} 为主元的二次函数，显然在 t=1 时取到最大值，即

\dfrac{1}{g(x)}\le2\implies g(x)\ge\dfrac{1}{2}

因此

b^2+c^2\ge g(x)\ge\dfrac{1}{2}

验证是否能取等：柯西不等式取等要求 \dfrac{b}{x}=\dfrac{c}{1} 即 b=cx，二次函数取等要求 x=1，因此 b=c。代入 bx+c=-x^2=-1 得 2b=-1，解得 b=c=-\dfrac{1}{2}。此时 b^2+c^2=\left(-\dfrac{1}{2}\right)^2+\left(-\dfrac{1}{2}\right)^2=\dfrac{1}{2}，代回原方程检验 1^2-\dfrac{1}{2}(1)-\dfrac{1}{2}=0 显然成立，因此最小值确实为 \dfrac{1}{2}。

（2）已知 f(x)=e^x-a\sin x，g(x)=b\sqrt{x}，若曲线 y=f(x) 和 y=g(x) 有公共点，求证 a^2+b^2>e。

有了上一题的启发，我们知道，不妨把 a,b 仍然放到一边，不妨假设公共点为 x_0，即

e^{x_0}=a\sin x_0+b\sqrt{x_0}

构造柯西不等式，

(a^2+b^2)(\sin^2x_0+x_0)\ge(a\sin x_0+b\sqrt{x_0})^2

因此

a^2+b^2\ge\dfrac{e^{2x_0}}{\sin^2 x_0+x_0}>e

只需证

e^{2x_0-1}>\sin^2x_0+x_0

这个证明并不容易，但是还算常规，这里略过。

例十二：已知 a,b>0 满足 \dfrac{1}{a}+\dfrac{3}{b}=1，求 \dfrac{4a+b+\sqrt{a^2+b^2}}{ab} 的最小值。

注意到右侧的次数是 -1 次，不妨设 m=\dfrac{1}{a},n=\dfrac{1}{b}，条件即为 m+3n=1，所求即为

\dfrac{4}{b}+\dfrac{1}{a}+\sqrt{\dfrac{1}{a^2}+\dfrac{1}{b^2}}=m+4n+\sqrt{m^2+n^2}

我们知道柯西不等式如果直接用，可以得到

(m^2+n^2)(1+1)\ge(m+n)^2 \implies \sqrt{m^2+n^2}\ge\dfrac{m+n}{\sqrt{2}}

这个形式不好化简，所以不妨我们假设一个 \bm v=(\lambda,\mu)，对其再用柯西不等式

(m^2+n^2)(\lambda^2+\mu^2)\ge(\lambda m+\mu n)^2\implies\sqrt{m^2+n^2}\ge\dfrac{\lambda}{\sqrt{\lambda^2+\mu^2}}m+\dfrac{\mu}{\sqrt{\lambda^2+\mu^2}}n

我们发现这里 \lambda,\mu 惊人的符合三角函数，所以不妨设 |\bm v|=1 且 \lambda=\cos\theta,\mu=\sin\theta，那么就有了

\sqrt{m^2+n^2}\ge m\cos\theta+n\sin\theta

代入原式，我们试图凑出题设条件

m+4n+\sqrt{m^2+n^2}\ge(1+\cos\theta)m+(4+\sin\theta)n

柯西不等式的取等条件为 m\sin\theta=n\cos\theta。同时我们希望 m,n 系数与条件成比，即 3=\dfrac{4+\sin\theta}{1+\cos\theta}。不妨设

\begin{cases} 4+\sin\theta&=3\lambda\\ 1+\cos\theta&=\lambda \end{cases}

根据

\sin^2\theta+\cos^2\theta=(3\lambda-4)^2+(\lambda-1)^2=1

即

10\lambda^2-26\lambda+16=0\implies (5\lambda-8)(\lambda-1)=0

因为我们要使 \sin\theta,\cos\theta 相关的式子最大，且观察到都是正数，因此取 \lambda=\dfrac{8}{5}，解得 \sin\theta=\dfrac{4}{5},\cos\theta=\dfrac{3}{5}，我们就可以放缩了，我们不妨在答题卡上写：

(m^2+n^2)\left(\dfrac{9}{25}+\dfrac{16}{25}\right)\ge\left(\dfrac{3}{5}m+\dfrac{4}{5}n\right)^2

因此

\sqrt{m^2+n^2}\ge\dfrac{3}{5}m+\dfrac{4}{5}n

代入所求

m+4n+\sqrt{m^2+n^2}\ge\dfrac{8}{5}m+\dfrac{24}{5}n=\dfrac{8}{5}(m+3n)=\dfrac{8}{5}

当且仅当 \dfrac{m}{3/5}=\dfrac{n}{4/5} 且 m+3n=1，即 m=\dfrac{1}{5},n=\dfrac{4}{15}（对应 a=5,b=\dfrac{15}{4}）时取得最小值 \dfrac{8}{5}。

以上步骤给了我们一个有意思的不等式

\sqrt{a^2+b^2}\ge|a\cos\theta+b\sin\theta|

或者说，当 p^2+q^2=1 时，有

\sqrt{a^2+b^2}\ge|ap+bq|

成立。

卡尔松不等式例题

我们在上一节中把卡尔松不等式讲的很高大上，但实际上，在接下来的题目中，卡尔松不等式将以一种看起来很简单的形式出现，其实卡尔松不等式确实很复杂，但是考虑到大部分题目不会超过高考难度太大，因此接下来的选题和做法也会相对轻松一点。

卡尔松不等式相比柯西不等式，最简单的一类，可以理解为是，左侧多个括号，大于等于，右侧两根和，例如

(a+b)(c+d)(e+f)\ge(\sqrt[3]{acd}+\sqrt[3]{bdf})^3

例题一：已知 \theta\in\left(0,\dfrac{\pi}{2}\right)，

  1. 求 \dfrac{1}{\cos\theta}+\dfrac{1}{\sin\theta} 的最小值。

    这个题理论上可以直接求导做，或者我们先随便给一个简单做法，不妨设

    S=\dfrac{1}{\cos\theta}+\dfrac{1}{\sin\theta}=\dfrac{\sin\theta+\cos\theta}{\sin\theta\cos\theta}=\dfrac{2\sqrt{1+\sin2\theta}}{\sin2\theta}=\dfrac{2t}{t^2-1}

    其中令 t=\sqrt{1+\sin2\theta}\in(1,\sqrt{2}]，没有 \pm 是因为 \theta 取值范围的限定，因此

    \dfrac{2}{S}=\dfrac{t^2-1}{t}=t-\dfrac{1}{t}\in\left(0,\dfrac{\sqrt{2}}{2}\right]

    因此 S\ge2\sqrt{2}。这道题用卡尔松不等式的证法是构造

    \left(\dfrac{1}{\cos\theta}+\dfrac{1}{\sin\theta}\right)\left(\dfrac{1}{\cos\theta}+\dfrac{1}{\sin\theta}\right)(\sin^2\theta+\cos^2\theta)\ge(1+1)^3=8

    即 S^2\times1\ge8，则 S\ge2\sqrt{2}。

  2. 求 \dfrac{1}{\sqrt{\cos\theta}}+\dfrac{1}{\sqrt{\sin\theta}} 的最小值。这个题我们直接类比上面，令所求为 T，则构造 T^4(\sin^2\theta+\cos^2\theta)\ge(1+1)^5=32，因此 T\ge2\sqrt[4]{2}。

例题二：已知正数 x,y 满足 x+2y=1，求 \dfrac{1}{x^2}+\dfrac{1}{y^2} 的最小值。根据上一题的思路，我们不妨令所求为 S，则可以构造 (x+2y)^2S\ge(1+\sqrt[3]{4})^3，因此 S\ge(1+\sqrt[3]{4})^3。

例题三：已知 x,y,z 均为正实数，求 \dfrac{xyz}{(1+4x)(9x+y)(4y+z)(9z+1)} 的最大值。

注意到分母在字母上有点轮换的意思，分别 x,y,z 各有三次，因此我们不妨整理一下

(1+4x)(9x+y)(4y+z)(9z+1)\ge(\sqrt[4]{324xyz}+\sqrt[4]{4xyz})^4=1024xyz

除过去即可，但是这道题更重要的一点是验等，我们知道取等条件是

\dfrac{1}{4x}=\dfrac{9x}{y}=\dfrac{4y}{z}=\dfrac{9z}{1}

这个能解但是比较复杂，这里就略过了。

排序不等式

排序不等式及其证明

排序不等式的一个最简单的形式是均值不等式，假设 a\ge b,c\ge d，那么有

ac+bd\ge ad+bc

如果我们设 a=c=\max(m,n),b=d=\min(m,n)，那么就有

\max\nolimits^2(m,n)+\min\nolimits^2(m,n)\ge\max(m,n)\min(m,n)+\min(m,n)\max(m,n)

也就是 m^2+n^2\ge2mn。从这里我们可以体会到一个“指数集中”的思想，也就是指数越大，倾向于更大，因为交叉会让大小分散开，而集中能让优势放大，也就是上式中平方和大于交叉和的感觉。

对于非严格单调递增（或递减）的实数序列 x,y，另 \sigma_i 表示 1\sim n 的任意一个排列，有，

x_1y_1+x_2y_2+\dots+x_ny_n\ge x_{\sigma_1}y_1+x_{\sigma_2}y_2+\dots+x_{\sigma(n)}y_n\ge x_1y_n+x_2y_{n-1}+\dots+x_ny_1

顺序和大于等于（不小于）乱序和，乱序和不小于（大于等于）逆序和；取等条件：参与交换的两项中只要有一方取值相同，和就不变；特别地，若 x,y 都严格单调，则顺序和严格大于一切乱序和与逆序和。

排序不等式不限正负，证明可以归纳法。二维时直接看差：

ac+bd-(ad+bc)=a(c-d)-b(c-d)=(a-b)(c-d)

所以若 a>b，c>d，则 a-b>0，c-d>0，因此 (a-b)(c-d)>0，即 ac+bd>ad+bc。也就是说，排序不等式 ac+bd\ge ad+bc 取严格不等号的条件是两组对应的大小关系都严格。

严格版本是，两个序列都严格递增时，同序和严格最大；同理，逆序和严格最小。所以严格递增时，只要排列不是恒等，就一定有逆序对，交换后和严格变大，最终同序和严格最大。

注意：严格不等号要求两个序列都严格。若只有一个严格，另一个有相等项，可能仍然取等号。例如二维中 a>b 但 c=d，则 ac+bd=ad+bc。

对于 n 维的排序不等式，说复杂也复杂，说不复杂也不复杂，核心就一句话：任何乱序配对里，只要出现“大配小、小配大”，把这两对改成“大配大、小配小”，总和一定增加。反复这样做，最后就得到同序配对，所以同序和最大；反过来逆序和最小。

几种说法：

  1. 邻项交换法：随便看两对配对。如果一对是较大数配了较小数，另一对是较小数配了较大数，就把它们交换成同序。交换后总和增加的量，正好是两个数差距的乘积，是正数。所以只要还有逆序配对，就还能变大；没有逆序时就是同序，因而同序最大。

  2. 冒泡排序法：固定一组数不动，把另一组数通过相邻交换慢慢排成同序。每次相邻交换，如果原来是把逆序改成顺序，总和就会增加；如果改成逆序，总和就会减少。既然最终能通过只增不减的交换变成同序，那同序自然最大。

  3. 交叉连线法：把两组数的配对画成连线。乱序配对一定会出现交叉：大的连了小的，小的连了大的。把交叉的两条线改成不交叉，也就是大的连大的、小的连小的，总和会变大。不断消除交叉，最后没有交叉，就是同序配对。所以同序最大，逆序最小。

  4. 反证法：假设某个排列使总和最大，但它不是同序。那它里面一定存在两个位置是逆序配对：大的配了小的，小的配了大的。把这两对交换成同序，总和会严格增加，矛盾。所以最大排列必须同序。

  5. 部分和累积法：把两组数都从小到大看。同序时，较大的元素总是更早地配到另一组较大的累积量上；乱序会让较大的元素配到较小的累积量上。因此同序时每一步累积都不吃亏，总和最大。

这些方法本质都一样：逆序配对换成同序配对，总和会变大；一直换到没有逆序，就是同序。

或者说的简单一点，可以理解成从左边 x_1y_1+x_2y_2+\dots+x_ny_n 不断放缩，就能依次（或者多路）得到各种不等式，最后放到最右边 x_1y_n+x_2y_{n-1}+\dots+x_ny_1 了。

排序不等式解决轮换和对称不等式问题

在排序不等式初学中，最经典的就是二元对称不等式的证明，一下所有题均默认 a,b,c 等均为正数。首先考虑证明 a^2+b^2\ge2ab，前面已经提到均值不等式，但是这里给出一种更加符合排序不等式的解法，我们发现这个式子关于 a,b 是二元对称式，即交换 a,b，即 b,a，是完全不变的，对于这种对称式，我们就可以直接假定 a\ge b（或 b\ge a 均可），在这道题中，根据 a\ge b，列排序不等式重复 a\ge b，可以得到 a\times a+b\times b\ge a\times b+b\times a=2ab。

如果说上面的不等式可以有很多方法来证明，那么下面的不等式，用排序不等式就是非常方便的了，我们简要讲解，同样 a,b 均为正数，考虑证明 a^5+b^5\ge a^3b^2+a^2b^3：我们发现这个不等式，左右同样都是 5 次的，考虑排序不等式，我们发现 a,b 对称，即不妨令 a\ge b，对 a^3\ge b^3,a^2\ge b^2，应用排序不等式，也可以得到。

对于三元轮换，就要复杂的多了，我们先抛出一个题目，证明 a^3+b^3+c^3\ge a^2b+b^2c+c^2a\ge3abc。容易发现的是，左侧是顺序和的样子，右侧是逆序和样子，因此这个不等式左右是显然的，但中间不是对称式？我们从次数和项数上，能够看出，中间应该是乱序和，但是怎么去描述呢？

因为这道题保证了 a,b 都是正数，容易发现其实右侧用均值不等式也能解决；我们不妨回归轮换的本质，我们知道，其实就是 (a,b,c)\to(b,c,a)\to(c,a,b) 是一个环，因此我们能够不妨设 a 是 a,b,c 里的最大值，即 a\ge b,b\ge c，因为只要把最大值轮换到 a 的位置上来，就能满足我们的假设。当我们轮换过来，我们就可以简单的分类讨论 b,c 的大小关系了。

当我们用这个视角来看上一道题，证明 a^3+b^3+c^3\ge a^2b+b^2c+c^2a，我们知道 a\ge b,a\ge c，无论 b>c 还是 c>b，以 a\ge b\ge c 为例，对 a^2\ge b^2\ge c^2，a\ge b\ge c 用排序不等式，我们发现 a^2b+b^2c+c^2a 一定是乱序和；而若 c\ge b，a^2b+b^2c+c^2a 也一定是乱序和。也就是说，我们发现，无论 b,c 的大小关系如何，a^2b+b^2c+c^2a 的形式，一定是乱序和。

对于右侧，我们不妨把形式拆为 ab\cdot a+bc\cdot b+ca\cdot c\ge ab\cdot c+bc\cdot a+ca\cdot b。根据 a,b,c>0 因此 abc>0，所以 \dfrac{a}{c}+\dfrac{b}{a}+\dfrac{c}{b}\ge3=\dfrac{a}{a}+\dfrac{b}{b}+\dfrac{c}{c}，我们发现是一个经典的轮换式和对称式的比较，对于证明大于等于，要么是构造左侧是顺序和、右侧是乱序和，要么是构造左侧是乱序和，右侧是逆序和（顺序和大于等于逆序和也不是不可能，只是有点太普通了），考虑 a\ge b\ge c 的情况，\dfrac{1}{c}\ge\dfrac{1}{b}\ge\dfrac{1}{a}，应用排序不等式，注意到左侧是乱序和，右侧是逆序和（怎么发现的呢？注意到右侧是同字母相除，因此最大的一定除最大的，最小的一定除最小的，也就等同于最大的一定乘最小的，最小的一定乘最大的，那么这就是乱序和），即可得到；若 a\ge c\ge b 同理即可。

下面是两道分式型的题，分式型在构造上有独特的难点，可以结合对称、轮换的模式去构造。例如证明 \dfrac{b^2}{a}+\dfrac{c^2}{b}+\dfrac{a^2}{c}\ge a+b+c，注意到左侧是轮换的，右侧是对称的，我们在前面的几道题，都发现经常是顺序和是对称式，乱序和是轮换式，逆序和是对称式（这不是一般规律，但是也是一定的思路），这是一种指数集中的思想，只要是“自己配自己”，则一定大的配到自己，则是顺序和，而指数平均通常是逆序形式，通常是最小的，这在麦克劳林不等式和穆尔黑德不等式也会有感受。

回到上面的题，我们不妨构造 a\ge b\ge c，则 a^2\ge b^2\ge c^2，\dfrac{1}{c}\ge\dfrac{1}{b}\ge\dfrac{1}{a}，因此 \dfrac{a^2}{c}+\dfrac{b^2}{a}+\dfrac{c^2}{a}\ge a+b+c 成立，这是很自然的逆序和不大于乱序和。如果 a\ge c\ge b 同理可得。

接下来是一个非常精妙的不等式，证明 \dfrac{c^2}{a+b}+\dfrac{b^2}{a+c}+\dfrac{a^2}{b+c}\ge\dfrac{a^2}{a+b}+\dfrac{b^2}{b+c}+\dfrac{c^2}{c+a}。如果我们把分子看成一个 (a^2,b^2,c^2) 的序列，那么分母就分别是 (b+c,a+c,a+b) 和 (a+b,b+c,c+a)，我们发现左侧的形式整齐，而右侧的看起来很乱，注意到不等式是大于等于号，那么大胆猜测左侧是顺序和，那么怎么构造顺序和呢？我们不妨先构造 a\ge b\ge c，则 a^2\ge b^2\ge c^2，那么接下来很精妙，我们可以通过一些小学思想，也可以证明，总之很容易能得到，但是不容易想到的 a+b\ge a+c\ge b+c，那么则有 \dfrac{1}{b+c}\ge\dfrac{1}{a+c}\ge\dfrac{1}{a+b}，应用排序不等式，则可以得到上面的不等式；若 a\ge c\ge b 同理可得。

排序不等式有的时候还可以结合其他代数技巧来用，以一个最简单的为例，比如证明 a^ab^bc^c\ge a^bb^cc^a，容一发现左侧看起来很对称，右侧看起来很轮换，容易想到把指数消掉，方法可以是两遍取对数，得到 a\ln a+b\ln b+c\ln c\ge b\ln a+c\ln b+a\ln c，这个就是前面提到的很经典的自己配自己的想法，不妨假设 a\ge b\ge c\ge 0，则 \ln a\ge\ln b\ge\ln c，即可得到。

切比雪夫总和不等式与多元排序不等式

切比雪夫总和不等式声称，若 a_1\ge a_2\ge\dots\ge a_n 且 b_1\ge b_2\ge\dots\ge b_n，则：

n\sum_{k=1}^na_kb_k\ge\left(\sum_{k=1}^na_k\right)\left(\sum_{k=1}^nb_k\right)\ge n\sum_{k=1}^na_kb_{n+1-k}

或

\sum_{k=1}^na_kb_k\ge\dfrac{1}{n}\left(\sum_{k=1}^na_k\right)\left(\sum_{k=1}^nb_k\right)\ge\sum_{k=1}^na_kb_{n+1-k}

或

\dfrac{1}{n}\sum_{k=1}^na_kb_k\ge\left(\dfrac{1}{n}\sum_{k=1}^na_k\right)\left(\dfrac{1}{n}\sum_{k=1}^nb_k\right)\ge\dfrac{1}{n}\sum_{k=1}^na_kb_{n+1-k}

切比雪夫总和不等式可以由排序不等式而来，但是我们可以用更加形式化的方式，我们以第二个式子为例，我们发现左侧是顺序和，右侧是逆序和，容易想到其实左侧类似与一个乱序和，但是又不完全是，我们发现中间其实是 n^2 个成绩的 \dfrac{1}{n}，容易想到可以直接做和来解，因此我们考虑证明第一个不等式。

由排序不等式，我们可以列出

\begin{aligned} a_1b_1+\dots+a_nb_n&=a_1b_1+a_2b_2+\dots+a_nb_n\\ a_1b_1+\dots+a_nb_n&=a_1b_2+a_2b_3+\dots+a_nb_1\\ a_1b_1+\dots+a_nb_n&=a_1b_3+a_2b_4+\dots+a_nb_2\\ &\dots\\ a_1b_1+\dots+a_nb_n&=a_1b_n+a_2b_1+\dots+a_nb_{n-1}\\ \end{aligned}

将上面 n 个式子分边相加，同时对右边进行因式分解，便得到

n(a_1b_1+\dots+a_nb_n)\ge(a_1+\dots+a_n)(b_1+\dots+b_n)

原不等式右边同理可得。

我们知道排序不等式指定了对于两个单调性相同的序列 (x_1,x_2,\dots,x_n),(y_1,y_2,\dots,y_n) 满足

x_1y_1+x_2y_2+\dots+x_ny_n\ge x_{\sigma_1}y_1+x_{\sigma_2}y_2+\dots+x_{\sigma(n)}y_n\ge x_1y_n+x_2y_{n-1}+\dots+x_ny_1

我们考虑，能否再加一个同等单调性序列 (z_1,z_2,\dots,z_n) 呢？答案是不完全能。具体内容可以参考冯·诺伊曼迹迹不等式（Fan 迹不等式）的相关内容，这里简要说一下“广义排序不等式”的基本形式。

广义排序不等式指出，对于多个单调性相同且全非负的序列 x,y,z 有顺序和最大，但是不能得出逆序和最小，注意，一定是全非负的序列，也就是三个序列的任意一项都非负，才有，例如当是三个序列时，对于任意的置换（排列）\tau,\pi 有

\sum_{i=1}^na_ib_ic_i\ge\sum_{i=1}^na_ib_{\tau(i)}c_{\pi(i)}

这个多元排序不等式可以直接解决上面的一道例题，已知 a,b,c>0，证明 a^3+b^3+c^3\ge a^2b+b^2c+c^2a，构造三组同向序列 a\le b\le c，即可得到原不等式，易知其他顺序同理。

这个结论对任意 m 个序列都成立，如果有 m 个同阶的非负单调递增序列 A^{(1)}, A^{(2)}, \dots, A^{(m)}，那么它们的项相乘求和，在所有序列保持相同顺序排列时取得最大值

\sum_{i=1}^n \prod_{k=1}^m a^{(k)}_{\sigma_k(i)} \le \sum_{i=1}^n \prod_{k=1}^m a^{(k)}_i

对多元排序不等式求平均，也可以得到类似的切比雪夫总和不等式形式，例如当是三个序列是有

\dfrac{1}{n}\sum_{i=1}^nx_iy_iz_i\ge\left(\dfrac{1}{n}\sum_{i=1}^nx_i\right)\left(\dfrac{1}{n}\sum_{i=1}^ny_i\right)\left(\dfrac{1}{n}\sum_{i=1}^nz_i\right)

设 m 个序列都是非负的，且都具有相同的单调性（例如都单调递增），对每个 k \in \{1, 2, \dots, m\}，都有 0 \le x^{(k)}_1 \le x^{(k)}_2 \le \dots \le x^{(k)}_n。则有：

\frac{1}{n} \sum_{i=1}^n \left( \prod_{k=1}^m x^{(k)}_i \right) \ge \prod_{k=1}^m \left( \frac{1}{n} \sum_{i=1}^n x^{(k)}_i \right)

凹凸形的定义

函数的凹凸性（Convexity）是导数考察中用于寻找“界限”的核心工具。函数的凹凸性是导数压轴题中用于寻找“界限”的核心几何工具。国内教材对于凹凸的定义有歧义，英文中是基本确定的，但是中文中有不同，建议以个人选用教材为准，下面主要以下凸与上凸进行描述。

下凸函数（Convex）：若函数 f(x) 的图像呈现“向上开口”的 \cup 型形态，则称其为下凸函数。可以直观的理解为，凸起是向下的，因为这个函数图像是 \cup 形的，所以我一般更喜欢称之为凹函数，因为和中文里面中字形比较像。

  • 几何本质：割线始终在弧线上方，切线始终在弧线下方。
  • 判据：f''(x) > 0。
  • 举例：y = x^2, y = e^x, y = x^{-1}。

上凸函数（Concave）：若函数 f(x) 的图像呈现“向下开口”的 \cap 型形态，则称其为上凸函数。可以直观的理解为，凸起是向上的，因为这个函数图像是 \cap 形的，所以我一般更喜欢称之为凸函数，因为和中文里面中字形比较像。

  • 几何本质：割线始终在弧线下方，切线始终在弧线上方。
  • 判据：f''(x) < 0。
  • 举例：y = \ln x, y = \sqrt{x}, y = \sin x。

凹凸性的切线放缩

切线放缩的核心思想是：利用线性函数（一次函数）去局部逼近复杂的非线性函数。这种方法在证明“函数恒大于 \dots”或“存在性证明”中具有极高的实战价值。

设函数 f(x) 在点 x_0 处可导，其切线方程为 y = f(x_0) + f'(x_0)(x - x_0)。

  • 下凸平移性：若 f(x) 是下凸的（f(x)'' > 0），则曲线始终位于切线的上方：

    f(x) \ge f(x_0) + f'(x_0)(x - x_0)

  • 上凸限制性：若 f(x) 是上凸的（f(x)'' < 0），则曲线始终位于切线的下方：

    f(x) \le f(x_0) + f'(x_0)(x - x_0)

等号成立的充要条件通常为 x = x_0。上面的结论也比较好证明，以函数下凸为例，即 f''(x)>0，设切点为 (x_0,f(x_0))，令 g(x)=f(x)-f'(x_0)x+x_0f'(x_0)-f(x_0)，对其求导 g'(x)=f'(x)-f'(x_0)，所以 g''(x)=f''(x)>0，因为 g'(x_0)=0，所以 g(x)\ge g(x_0)=0 成立。

切线放缩的经典案例：

  1. 指数母函数 f(x)=e^x 是下凸函数，我们在 x=0,x=1 处分别取切线，能得到

    e^x\ge x+1

    e^x\ge ex

  2. 对数母函数 f(x)=\ln x 是上凸函数，我们在 x=1 处取切线，能得到

    \ln(x+1)\le x

    \ln x\le x-1

找点心法：取等做切。证明 f(x) \ge g(x) 时，若直接求导困难，可遵循以下路径，

  • 观察或猜测一个特殊的 x_0，使得 f(x_0) = g(x_0)。

  • 在 x_0 处做 f(x) 的切线 L(x)。

  • 若能证明 f(x) \ge L(x) \ge g(x)，则利用切线的传递性完成放缩证明。

琴生不等式

琴生不等式是凹凸性中最重要的一部分，高中情境下琴生不等式有多种说法，从最简单到一般，我们依次叙述。

以下以下凸的 \cup 型函数为例，例如 f(x)=x^2，满足 f''(x)>0，我们发现，我们随便在函数上取两点 A(x_1,f(x_1)),B(x_2,f(x_2))，那么这两点连线的中点，一定高于这两点中点的横坐标处的函数值，也就是

\dfrac{f(x_1)+f(x_2)}{2}\ge f\left(\dfrac{x_1+x_2}{2}\right)

这个证明比较简单，我们再来一个更一般的结论，我们发现线段 AB 中间任意一点的函数值都大于该点横坐标处的函数值，我们引入变量 t\in(0,1)，即

tf(x_1)+(1-t)f(x_2)\ge f(tx_1+(1-t)x_2),t\in(0,1)

证明

我们不妨设

g(t)=tf(x_1)+(1-t)f(x_2)-f(tx_1+(1-t)x_2)

则

g'(t)=f(x_1)-f(x_2)-(x_1-x_2)f'(tx_1+(1-t)x_2)

再求导

g''(t)=-(x_1-x_2)f''(tx_1+(1-t)x_2)<0

观察到

g'(0)=f(x_1)-f(x_2)-(x_1-x_2)f'(x_2)

g'(1)=f(x_1)-f(x_2)-(x_1-x_2)f'(x_1)

根据上一部分下凸函数的切线放缩，我们知道

f(x)-f(x_0)\ge(x-x_0)f'(x_0)

代入上面我们发现 g'(0)\ge0，g'(1)\le0，根据 g'(x) 单调递减，因此存在 t_0\in(0,1) 使得 g'(t_0)=0，在 t\in(0,t_0) 满足 g'(t)>0，在 t\in(t_0,1) 满足 g'(t)<0。因此 g(t) 在 (0,1) 是先单增后单减的，因此 g(t) 在 (0,1) 恒有

g(t)\ge\min\{g(0),g(1)\}=0

这就证完了（以上是作者梦游写的，开闭乱七八糟凑合看吧）。

在上不等式中，代入 t=\dfrac{1}{2} 即可得到最初的最简单的形式。

琴生不等式更一般的是 n 元形式，同样较简单的是对于下凸函数

\dfrac{f(x_1)+f(x_2)+\dots+f(x_n)}{n}\ge f\left(\dfrac{x_1+x_2+\dots+x_n}{n}\right)

更一般的是对于任意 \lambda_1+\lambda_2+\dots+\lambda_n=1 均有

\lambda_1f(x_1)+\lambda_2f(x_2)+\dots+\lambda_nf(x_n)\ge f(\lambda_1x_1+\lambda_2x_2+\dots+\lambda_nx_n)

以上所有结论都是下凸函数，如果是上凸函数全部反向即可。

琴生不等式一个最经典的应用是来轻松证明均值不等式，不妨令 f(x)=\ln x，因此 f''(x)=-\dfrac{1}{x^2}<0，是上凸函数，故有

\ln\left(\dfrac{x_1+x_2+\dots+x_n}{n}\right)\ge\dfrac{\ln x_1+\ln x_2+\dots+\ln x_n}{n}=\ln\left(\sqrt[n]{x_1x_2\dots x_n}\right)

故有

\dfrac{x_1+x_2+\dots+x_n}{n}\ge\sqrt[n]{x_1x_2\dots x_n}

例题一：已知正数 a,b,c 满足 a+b+c=3，求证 e^a+e^b+e^c\ge 3e。

我们发现 y=f(x)=e^x 是下凸函数，因此有 \dfrac{e^a+e^b+e^c}{3}\ge e^{\frac{a+b+c}{3}}=e 整理即可。

例题二：已知 A, B, C 是 \triangle ABC 的三个内角，则 \sin A + \sin B + \sin C 的最大值为？\sin\dfrac{A}{2}+\sin\dfrac{B}{2}+\sin\dfrac{C}{2} 的最大值为？

我们知道 y=f(x)=\sin(x) 在 (0,\pi) 是上凸函数，因此有

\sin\left(\dfrac{A+B+C}{3}\right)\ge\dfrac{\sin A+\sin B+\sin C}{3}

\sin\left(\dfrac{A+B+C}{6}\right)\ge\dfrac{\sin\dfrac{A}{2}+\sin\dfrac{B}{2}+\sin\dfrac{C}{2}}{3}

整理即可得到

\sin A+\sin B+\sin C\le\dfrac{3\sqrt{3}}{2}

\sin\dfrac{A}{2}+\sin\dfrac{B}{2}+\sin\dfrac{C}{2}\le\dfrac{1}{2}

Hermite-Hadamard 积分不等式

H-H 不等式是连接凹凸性与积分的桥梁，其本质是“面积三明治”。对于区间 [a, b]：

  • 下凸引擎 (\cup)：

    f\left( \dfrac{a + b}{2} \right) \le \dfrac{1}{b - a} \int_a^b f(x) \mathrm{d}x \le \dfrac{f(a) + f(b)}{2}

  • 上凸引擎 (\cap)：

    f\left( \dfrac{a + b}{2} \right) \ge \dfrac{1}{b - a} \int_a^b f(x) \mathrm{d}x \ge \dfrac{f(a) + f(b)}{2}

口诀：中点评估、积分平均、端点评估（梯形）。下凸则递增顺序，上凸则递减顺序。

全量代入与经典不等式

幂函数系列：

  • 二次函数 f(x) = x^2：

    \dfrac{(a + b)^2}{4} \le \dfrac{a^2 + ab + b^2}{3} \le \dfrac{a^2 + b^2}{2}

  • 反比例函数 f(x) = 1/x：

    \dfrac{2ab}{a + b} \le \dfrac{b - a}{\ln b - \ln a} \le \dfrac{a + b}{2} \implies \mathbf{H \le L \le A}

  • 根号函数 f(x) = \sqrt{x}：

    \sqrt{\dfrac{a + b}{2}} \ge \dfrac{2(b\sqrt{b} - a\sqrt{a})}{3(b - a)} \ge \dfrac{\sqrt{a} + \sqrt{b}}{2}

指对函数系列：

  • 指数函数 f(x) = e^x：

    e^{\dfrac{a+b}{2}} \le \dfrac{e^b - e^a}{b - a} \le \dfrac{e^a + e^b}{2}

    在对数坐标 [\ln a, \ln b] 下：\sqrt{ab} \le \dfrac{b - a}{\ln b - \ln a} \le \dfrac{a + b}{2} \implies \mathbf{G \le L \le A}。

  • 对数函数 f(x) = \ln x：

    \dfrac{a + b}{2} \ge \dfrac{1}{e} \left( \dfrac{b^b}{a^a} \right)^{\dfrac{1}{b-a}} \ge \sqrt{ab} \implies \mathbf{A \ge I \ge G}

三角函数系列 (x \in (0, \pi))：

  • 正弦函数 f(x) = \sin x：

    \sin\left( \dfrac{a + b}{2} \right) \ge \dfrac{\cos a - \cos b}{b - a} \ge \dfrac{\sin a + \sin b}{2}

深度整合之均值的几何生成与五均值链

  1. 五均值大一统链条 (H-G-L-I-A)

    \mathbf{H \le G \le L \le I \le A}

    各环节均可由不同坐标系下的 H-H 不等式精确生成。

  2. 坐标系换元与中点映射

    • 线性坐标下：中点 \to 算术均值 A。
    • 对数坐标下：中点 \to 几何均值 G。

    这解释了为什么 \sqrt{ab} 不直接对应上凸函数，它是对数变换后下凸函数 e^u 的中点。

认知复盘与解题模型

遇到差分商 \dfrac{g(b) - g(a)}{b - a}，第一反应应是：“这是谁的积分平均？”通过锁定母函数 f(x) = g'(x) 的凹凸性，配合 H-H 引擎，可实现对复杂结构的瞬间夹逼。

掌握 H-H 引擎，即掌握了不等式生成的元逻辑。这种从几何直观出发的洞察力，是提升数学任督二脉的关键。

  1. 切线放缩 (局部逼近)

    • e^x \ge x + 1 (于 x=0)
    • \ln x \le x - 1 (于 x=1)
    • e^x \ge ex (于 x=1)

  2. 双曲函数代换 (对称性秒杀)

    设 x_1 = ce^v, x_2 = ce^{-v}，将对数均值转换为：

    L = c \cdot \dfrac{\sinh v}{v}

    原不等式链简化为：1 < \dfrac{\sinh v}{v} < \cosh v。

  3. 积分本质直观 (曲边面积)：不涉及复杂求导，仅凭“下凸曲线真实面积小于梯形面积”即可洞穿不等式的底牌。
