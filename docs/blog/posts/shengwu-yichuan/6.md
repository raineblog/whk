# 2025青岛淄博高三二模遗传学不定项

题目描述：某昆虫（ZW 型）的翅型由两对基因控制。科研人员进行了如下实验。实验一：取一只纯合正常翅雌虫和一只纯合无翅雄虫杂交，发现 F₁ 雄虫全为正常翅，雌虫全为缺刻翅，F₁ 随机交配，F₂ 中正常翅:缺刻翅:无翅=3:3:2；实验二：科研人员偶然发现一个常染色体上基因 t，当 t 基因纯合时，雄虫转化为不育雌虫，但雌虫没有性反转。取一对有翅雌雄昆虫杂交，F₁ 雌:雄=3:1，F₁ 雄性均为正常翅，雌性既有正常翅又有缺刻翅，F₁ 自由交配得 F₂。不考虑 ZW 同源区段，下列说法错误的有（不定项）

- A. 控制翅型的基因均位于常染色体上
- B. 实验一 F₂ 中正常翅雌雄个体随机交配，F₃ 正常翅雄虫中纯合子占 1/2
- C. 实验二亲本为正常翅雄虫和正常翅雌虫
- D. 实验二 F₂ 的雌：雄之比为11:5

本题是一道非常经典的**伴性遗传、两对等位基因互作（上位效应）以及性别决定与性反转**相结合的综合遗传题。

题目要求选出**说法错误**的选项，正确答案是：**A、B、C**。

下面为您进行全面、详细的拆解与推导演算：

## 实验与选项分析

### 一、实验一分析：确定翅型的遗传方式及基因位置

#### 1. 基因位置的推导

- **亲本表型与子代表型：**
    - 纯合正常翅雌虫 $\times$ 纯合无翅雄虫 $\rightarrow \text{F}_1$ 雄虫全为正常翅，雌虫全为缺刻翅。
    - **关键突破口：** 亲本均为纯合子，若控制翅型的基因全部位于常染色体上，则 $\text{F}_1$ 雌雄个体的基因型应完全一致，表型也应一致。然而，$\text{F}_1$ 中雄虫全为正常翅、雌虫全为缺刻翅（表现出性别差异），说明**至少有一对控制翅型的基因位于 Z 染色体上**。
    - **结论：选项 A 错误。**

#### 2. 两对基因的作用机理及基因型推导

- 设常染色体上的基因为 $\text{A/a}$，Z 染色体上的基因为 $\text{B/b}$（昆虫为 ZW 型，雌性为 ZW，雄性为 ZZ）。
- $\text{F}_1$ 雌雄随机交配，$\text{F}_2$ 中 **正常翅 : 缺刻翅 : 无翅 = 3 : 3 : 2**（总份数为 $3+3+2=8$，即 $6:6:4/16$）。
    - 出现比例为 16 的变式，说明两对基因独立遗传，且：
        - 无翅占 $2/8 = 4/16$（即双隐性或某一隐性纯合表现为无翅，符合 $\text{aa\_\_}$ 占 $1/4$ 的特征，说明 $\text{aa}$ 具有隐性上位效应，只要存在 $\text{aa}$ 即表现为无翅）；
        - 正常翅占 $6/16 = 3/8$；
        - 缺刻翅占 $6/16 = 3/8$。
- **亲本与 $\text{F}_1$ 的基因型确定：**
    - 纯合正常翅雌虫：$\text{AA Z}^B\text{W}$
    - 纯合无翅雄虫：$\text{aa Z}^b\text{Z}^b$
    - $\text{F}_1$ 基因型：
        - 雄虫：$\text{Aa Z}^B\text{Z}^b$（表现为正常翅，说明 $\text{A\_ Z}^B\_$ 为正常翅，$\text{Z}^B$ 对 $\text{Z}^b$ 为显性）；
        - 雌虫：$\text{Aa Z}^b\text{W}$（表现为缺刻翅，说明 $\text{A\_ Z}^b\text{W}$、$\text{A\_ Z}^b\text{Z}^b$ 表现为缺刻翅）。
- **表型与基因型对应关系：**
    - **正常翅**：$\text{A\_ Z}^B\_$（即 $\text{A\_ Z}^B\text{Z}^B$、$\text{A\_ Z}^B\text{Z}^b$、$\text{A\_ Z}^B\text{W}$）
    - **缺刻翅**：$\text{A\_ Z}^b\text{Z}^b$、$\text{A\_ Z}^b\text{W}$
    - **无翅**：$\text{aa \_\_}$（与 B/b 基因无关）

### 二、选项 B 的详细计算（实验一 $\text{F}_3$ 纯合子概率）

1. **$\text{F}_2$ 中正常翅雌雄个体的基因型及比例：**
    - $\text{F}_1$（$\text{Aa Z}^B\text{Z}^b \times \text{Aa Z}^b\text{W}$）杂交：
        - 常染色体部分：$\text{Aa} \times \text{Aa} \rightarrow 1/4\text{AA} : 1/2\text{Aa} : 1/4\text{aa}$。
            - 正常翅个体必含有 $\text{A}$ 基因，因此在正常翅个体中：$\text{AA} : \text{Aa} = 1/3 : 2/3$（配子产生规律为 $\text{A} = 2/3, \text{a} = 1/3$）。
        - 性染色体部分：$\text{Z}^B\text{Z}^b \times \text{Z}^b\text{W}$
            - 雄性后代：$1/2\text{Z}^B\text{Z}^b$（正常翅）、$1/2\text{Z}^b\text{Z}^b$（缺刻翅）；
            - 雌性后代：$1/2\text{Z}^B\text{W}$（正常翅）、$1/2\text{Z}^b\text{W}$（缺刻翅）。
    - 因此，$\text{F}_2$ 中选出的正常翅个体基因型为：
        - **雄性：** $(1/3\text{AA}, 2/3\text{Aa})\text{Z}^B\text{Z}^b$
        - **雌性：** $(1/3\text{AA}, 2/3\text{Aa})\text{Z}^B\text{W}$

2. **$\text{F}_2$ 正常翅个体随机交配产生 $\text{F}_3$：**
    - **常染色体基因分析：**
        - 雄配子：$2/3\text{A}, 1/3\text{a}$；雌配子：$2/3\text{A}, 1/3\text{a}$。
        - 后代中：$\text{AA} = 4/9$，$\text{Aa} = 4/9$，$\text{aa} = 1/9$。
        - 在有翅（$\text{A\_}$）后代中：$\text{AA} : \text{Aa} = 1 : 1$（即 $\text{P(AA | A\_)} = 1/2$）。
    - **性染色体基因分析：**
        - 雄性亲本提供精子：$1/2\text{Z}^B, 1/2\text{Z}^b$；
        - 雌性亲本提供卵细胞：$1/2\text{Z}^B, 1/2\text{W}$；
        - 雄性后代（$\text{ZZ}$）：
            - 得到来自母亲的 $\text{Z}^B$ 和来自父亲的 $(1/2\text{Z}^B, 1/2\text{Z}^b)$，基因型为 **$1/2\text{Z}^B\text{Z}^B$** 和 **$1/2\text{Z}^B\text{Z}^b$**。
            - 可以看出：**所有雄性后代均含有 $\text{Z}^B$**！只要具备 $\text{A\_}$，就全为正常翅雄虫。
    - **求解 $\text{F}_3$ 正常翅雄虫中纯合子的比例：**
        - 纯合正常翅雄虫基因型为 $\text{AA Z}^B\text{Z}^B$。
        - 在全部正常翅雄虫（$\text{A\_ Z}^B\_$ 雄虫）中：
            - $\text{AA}$ 的概率为 $1/2$；
            - $\text{Z}^B\text{Z}^B$ 的概率为 $1/2$。
            - 纯合子（$\text{AA Z}^B\text{Z}^B$）所占比例为： $\frac{1}{2} \times \frac{1}{2} = \frac{1}{4}$
    - **结论：选项 B 错误（应占 $1/4$，而非 $1/2$）。**

### 三、实验二分析：性反转基因 $\text{t}$ 与表型判断

#### 1. 性反转机制与亲本 $\text{T/t}$ 基因型推导

- 题干信息：常染色体基因 $\text{t}$ 纯合时，**$\text{tt ZZ}$ 转化为不育雌虫**；$\text{tt ZW}$ 雌虫不反转且**可育**。
- 杂交后代 $\text{F}_1$ **雌 : 雄 = 3 : 1**：
    - 正常情况下染色体性别比例为 $\text{ZW} : \text{ZZ} = 1 : 1$（各占 $1/2$）。
    - 出现 $3:1$（即雌虫 $3/4$，雄虫 $1/4$），说明原本为雄性的 $\text{ZZ}$ 个体中有**一半发生了性反转**变成了雌虫（占总数的 $1/4$），剩下的 $1/4$ 仍为雄虫。
    - 这意味着：雄性受精卵中，$\text{tt}$ 占 $1/2$，$\text{Tt}$ 占 $1/2$。
    - 雄亲本必须是雄虫，所以基因型绝不能是 $\text{tt}$（因为 $\text{tt ZZ}$ 会性反转为雌虫），因此**雄亲本只能是 $\text{Tt}$**；
    - 为了让子代产生比例为 $1:1$ 的 $\text{Tt}$ 与 $\text{tt}$，**雌亲本必须是 $\text{tt}$**（$\text{tt ZW}$ 不反转，表型为雌虫且正常可育）。
    - $\text{F}_1$ 的性别和基因型组成如下：
        - $\text{Tt ZZ}$（占 $1/4$）：正常雄虫（可育）
        - $\text{tt ZZ}$（占 $1/4$）：**反转为雌虫（不育）**
        - $\text{Tt ZW}$（占 $1/4$）：正常雌虫（可育）
        - $\text{tt ZW}$（占 $1/4$）：正常雌虫（可育）
        - 雌 : 雄 = $(1/4 + 1/4 + 1/4) : 1/4 = 3 : 1$。

#### 2. 亲本翅型分析（选项 C 的真伪推导）

- 题干：一对有翅昆虫杂交，$\text{F}_1$ 雄性**全为正常翅**，雌性**既有正常翅又有缺刻翅**。
- **雌亲本分析：**
    - 雌亲本将 $\text{Z}$ 染色体传给所有雄性后代（$\text{ZZ}$）。由于 $\text{F}_1$ 雄性全为正常翅，说明它们都获得了显性基因 $\text{Z}^B$。
    - 因此，**雌亲本必定是 $\text{Z}^B\text{W}$（正常翅雌虫）**。
- **雄亲本分析：**
    - 雄亲本基因型是 $\text{Z}^B\text{Z}^b$（正常翅）还是 $\text{Z}^b\text{Z}^b$（缺刻翅）？
        - **假设一：雄亲本为 $\text{Z}^B\text{Z}^b$（正常翅）：**
            - $\text{ZZ}$ 个体获得母亲的 $\text{Z}^B$，父亲的 $\text{Z}^B$ 或 $\text{Z}^b$，均为 $\text{Z}^B\_$（正常翅，包括正常雄虫和反转雌虫）。
            - $\text{ZW}$ 个体获得母亲的 $\text{W}$，父亲的 $\text{Z}^B$（正常翅）或 $\text{Z}^b$（缺刻翅）。
            - 结果：雄性全为正常翅，雌性既有正常翅又有缺刻翅。**假设成立！**
        - **假设二：雄亲本为 $\text{Z}^b\text{Z}^b$（缺刻翅）：**
            - $\text{ZZ}$ 个体获得母亲的 $\text{Z}^B$，父亲的 $\text{Z}^b$，基因型全为 $\text{Z}^B\text{Z}^b$（表现为正常翅）。
                - 其中 $\text{Tt ZZ}$ 为正常翅雄虫（雄性全为正常翅）；
                - $\text{tt ZZ}$ 为**正常翅雌虫**（反转而来）。
            - $\text{ZW}$ 个体获得母亲的 $\text{W}$，父亲的 $\text{Z}^b$，基因型全为 $\text{Z}^b\text{W}$（表现为**缺刻翅雌虫**）。
            - 结果：$\text{F}_1$ 雄性全为正常翅，雌性中既有正常翅（性反转个体）又有缺刻翅（正常雌性）。**假设同样完全成立！**
- **结论：** 实验二的亲本雄虫既可以是**正常翅（$\text{Tt Z}^B\text{Z}^b$）**，也可以是**缺刻翅（$\text{Tt Z}^b\text{Z}^b$）**。选项 C 断定“亲本为正常翅雄虫和正常翅雌虫”是**错误的**。

### 四、选项 D 的详细计算（实验二 $\text{F}_2$ 雌雄比例）

此计算是本题极具技巧性的关键点，需要注意**不育雌虫不能参与自由交配**：

1. **分析 $\text{F}_1$ 中能够参与繁殖的个体：**
    - **雄性个体：**
        - 只有 $\text{Tt ZZ}$（全部雄性都是该基因型）。
        - 产生精子的种类及比例：
            - $\text{T Z} = 1/2$
            - $\text{t Z} = 1/2$
            - （精子必然携带 $\text{Z}$ 染色体）
    - **雌性个体：**
        - 注意：$\text{F}_1$ 中的 **$\text{tt ZZ}$ 雌虫是不育的**，不参与交配！
        - 真正能够参与交配的雌虫只有 $\text{ZW}$ 个体：
            - $1/2 \text{Tt ZW}$
            - $1/2 \text{tt ZW}$
        - 这些可育雌虫产生的配子种类及比例：
            - 常染色体基因：$\text{Tt}$ 产生 $1/4\text{T} + 1/4\text{t}$；$\text{tt}$ 产生 $1/2\text{t}$。
                - 雌配子中：$\text{T} = 1/4$；$\text{t} = 3/4$。
            - 性染色体：$\text{Z} = 1/2$；$\text{W} = 1/2$。
            - 综合卵细胞的种类及概率：
                - $1/8 \text{T Z}$
                - $1/8 \text{T W}$
                - $3/8 \text{t Z}$
                - $3/8 \text{t W}$

2. **精卵随机结合计算 $\text{F}_2$ 的性别比例：**
    - **$\text{ZW}$ 个体（全部发育为雌性，无性反转）：**
        - 比例为卵细胞中 $\text{W}$ 的比例，即占总后代的 **$1/2 = 8/16$**。
    - **$\text{ZZ}$ 个体（原本为雄性，总共占 $1/2 = 8/16$）：**
        - 产生 $\text{tt}$ 基因型的概率（性反转为雌性）： $\text{P(tt ZZ)} = \text{精子}(\text{t}) \times \text{卵细胞}(\text{t Z}) = \frac{1}{2} \times \frac{3}{8} = \frac{3}{16} \quad (\text{性反转为雌性})$
        - 产生 $\text{T\_}$ 基因型的概率（保持雄性）： $\text{P(T\_ ZZ)} = \frac{8}{16} (\text{全部 ZZ}) - \frac{3}{16} (\text{tt ZZ}) = \frac{5}{16} \quad (\text{雄性})$
    - **统计 $\text{F}_2$ 的雌雄总数：**
        - **雌性总数** = 正常 $\text{ZW}$ 雌性 + 反转 $\text{tt ZZ}$ 雌性 = $\frac{8}{16} + \frac{3}{16} = \frac{11}{16}$
        - **雄性总数** = 正常 $\text{T\_ ZZ}$ 雄性 = $\frac{5}{16}$
    - **雌 : 雄 = 11 : 5。**
    - **结论：选项 D 正确。**

## 总结与反思

- **A 选项错误**：翅型有一对基因位于 Z 染色体上。
- **B 选项错误**：$\text{F}_3$ 正常翅雄虫中纯合子占 $1/4$。
- **C 选项错误**：亲本雄虫既可以是正常翅，也可以是缺刻翅。
- **D 选项正确**：$\text{F}_2$ 雌 : 雄 = 11 : 5。

### 一、题型模型归纳（四大核心模型）

#### 模型 1：隐性上位与伴性遗传复合模型（$3:3:2$ 比例模型）

- **特征数字：** $\text{F}_2$ 出现表型比为 $3 : 3 : 2$（总份数为 $8$）。
- **本质剖析：**
    - 总数为 8 或 16 的变式，说明是两对等位基因自由组合，且涉及伴性遗传。
    - 展开为 16 分数：$3:3:2 = 6:6:4$。其中 $4/16$ 即 $1/4$，必定是某一基因座的隐性纯合（$\text{aa}$）导致了**隐性上位（无翅）**。
    - 剩下 $12/16$（即 $\text{A\_}$）中，按 $1:1$ 分裂为正常翅（$6/16$）和缺刻翅（$6/16$），由位于 Z 染色体上的显隐性基因（$\text{Z}^B$ 与 $\text{Z}^b$）控制。

#### 模型 2：性反转与育性修饰模型

- **机制拆解：** 表型性别 $\neq$ 染色体性别。
    - 染色体性别：$\text{ZZ}$（遗传雄性）、$\text{ZW}$（遗传雌性）。
    - 修饰基因：$\text{tt}$ 纯合导致 $\text{ZZ} \rightarrow$ **不育雌虫**；$\text{ZW}$ 雌虫不变且可育。
- **性比变异指征：**
    - 正常性比应为 $1 : 1$。
    - 若产生 $\text{tt}$ 纯合子，会导致原本属于雄性的 $\text{ZZ}$ 被“夺走”并计入雌性。
    - 本题 $\text{F}_1$ 出现 **雌 : 雄 = 3 : 1**，说明原本 $1/2$ 的 $\text{ZZ}$ 中，恰好有一半发生性反转（$1/4$ 反转为雌，剩下 $1/4$ 保持为雄），由此瞬时锁定亲本基因型为 $\text{tt} \times \text{Tt}$。

#### 模型 3：不育/致死约束下的群体自由交配模型

- **机制拆解：** $\text{F}_1$ 自由交配产生 $\text{F}_2$ 时，存在**“无效繁殖个体”**。
- **核心规律：** 发生性反转的 $\text{tt ZZ}$ 虽然表型是雌虫，但**“不育”**，无法提供卵细胞。因此，在统计母本基因库时，**必须剔除 $\text{tt ZZ}$ 个体**，只保留真正可育的 $\text{ZW}$ 雌虫！

### 二、核心思想方法（解题的底层逻辑）

#### 1. 拆分与重组思想（乘法原理与独立事件）

- **化繁为简：** 面对“常染色体翅型基因（A/a）”、“伴性翅型基因（B/b）”、“性反转基因（T/t）”三对基因交织的问题，切忌写 64 格棋盘法。
- **解剖方法：**
    - 分析翅型：将 $\text{A/a}$ 与 $\text{Z}^B/\text{Z}^b$ 拆开，各自推导配子比例后再相乘。
    - 分析性别比例：翅型完全不影响性别，直接把翅型基因抛开，**单独抽离出 $\text{T/t}$ 和 $\text{Z/W}$ 染色体进行二元分析**。

#### 2. 配子概率法（处理自由交配的最强工具）

- 面对多基因、比例不对称的自由交配问题，**“基因型逐个杂交法”极易漏项出错，配子概率法是唯一最高效且零容错的方法**。
- **操作三步走：**
    1. **定群体：** 确定有效可育雄性群体的精子库；确定有效可育雌性群体的卵子库。
    2. **算频率：** 算出雄配子（$\text{T Z}$、$\text{t Z}$）和雌配子（$\text{T Z}$、$\text{T W}$、$\text{t Z}$、$\text{t W}$）的概率。
    3. **配组合：** 通过精卵随机结合的乘积，一步到位算出后代基因型与表型比（如选项 D 中轻松得出 $11:5$）。

#### 3. 严格的条件概率思维

- 计算“某表型中某基因型占多少”属于典型的条件概率： $P(\text{纯合子} \mid \text{正常翅雄虫}) = \frac{P(\text{纯合正常翅雄虫})}{P(\text{正常翅雄虫})}$
- **必须兼顾所有基因座：** 不仅常染色体上必须纯合（$\text{AA}$），性染色体上也必须纯合（$\text{Z}^B\text{Z}^B$），漏掉任何一个座位的纯合限制就会误算成 $1/2$。

#### 4. 假说—演绎与非唯一性（发散与穷举思维）

- **反推亲本时警惕“唯一性陷阱”：**
    - 传统思维：看到子代雌性既有显性又有隐性，就武断认为“父本必携带显性基因和隐性基因”。
    - 辩证思维：子代显性雌性**既可能来自正常发育的 ZW 雌性，也可能来自性反转的 ZZ 雌性**！
    - 只要性反转机制能提供显性雌性，父本即使全为隐性（$\text{Z}^b\text{Z}^b$）也完全说得通。这就打破了常规的定向逻辑，体现了科学思维的严谨性。

### 三、高考经典易错陷阱与破局点

| 常见失分陷阱               | 命题人意图（“杀招”）                                                                                          | 破局思维（解题心法）                                                                  |
| :------------------------- | :------------------------------------------------------------------------------------------------------------ | :------------------------------------------------------------------------------------ |
| **染色体系统套错**         | 习惯了 XY 型，误将雄性当成异配（ZW），导致传递规律彻底颠倒。                                                  | 审题第一步圈出 **ZW 型**：母传 Z 给儿、传 W 给女；父传 Z 给儿女。                     |
| **纯合子判定片面**         | 算 Option B 时，只看了常染色体 $\text{AA}$（占 $1/2$），忘记了雄虫在 Z 上也能杂合（$\text{Z}^B\text{Z}^b$）。 | 纯合子是指**全部控制该性状的基因位点均纯合**（$\text{AA Z}^B\text{Z}^B$）。           |
| **忽略性反转个体的“不育”** | 算 Option D 的自由交配时，把反转生成的 $\text{tt ZZ}$ 雌虫也拉去产卵。                                        | 抓题眼**“转化为不育雌虫”**，凡不育个体一律从自由交配的“种群基因库”中剔除！            |
| **思维僵化认为亲本唯一**   | 算 Option C 时，漏掉了性反转雌虫对子代表型的贡献，误以为父本必须是正常翅。                                    | 考虑表型来源的多样性：**该表型是否可能由性反转个体提供？** 从而发现父本的双重可能性。 |

### 四、应对此类综合遗传压轴题的标准解题流程（SOP）

- **第 1 步：明机制，画骨架**
    - 确定性别系统（ZW 还是 XY）。
    - 依据 $\text{F}_1$ 性别差异或 $\text{F}_2$ 特殊比例，拆解基因位置（常染色体 / 性染色体 / 两者兼有）。
- **第 2 步：写对应，建映射**
    - 将表型与基因型列出对应字典（例：$\text{A\_ Z}^B\_$ 为正常，$\text{A\_ Z}^b\_$ 为缺刻，$\text{aa\_\_}$ 为无翅）。
- **第 3 步：拆性反转，算亲本**
    - 找异常性别比（如 $3:1$），对应反转条件，锁定亲本的性反转调节基因（如锁定母本必为 $\text{tt}$，父本必为 $\text{Tt}$）。
- **第 4 步：过滤群体，求配子**
    - 若涉及后代自由交配：
        1. 挑出**真正具有生育能力**的雌雄个体；
        2. 计算雄性群体产生的精子库比例；
        3. 归一化计算雌性群体产生的卵子库比例。
- **第 5 步：棋盘拼合，分步统计**
    - 用配子概率相乘，分别统计纯合概率、性比及表型分布。
