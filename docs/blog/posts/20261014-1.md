# 2023青岛高三二模23题遗传大题简析

题目描述：以野生型果蝇表现为刚毛、直翅和灰体，已知控制刚毛、截毛和灰体、黑檀体的基因位于两对同源染色体上。研究人员通过诱变获得了某些突变体果蝇，每个突变体只涉及一对等位基因的改变。研究人员进行了相关杂交实验，结果见下表。$F_2$ 为 $F_1$ 全部个体随机交配的后代，假定每只果蝇的生殖力相同。

| 杂交组合 | $P$                                      | $F_1$                        | $F_2$                |
| :------: | :--------------------------------------- | :--------------------------- | :------------------- |
|    甲    | 刚毛黑檀体雌果蝇 $\times$ 截毛灰体雄果蝇 | 刚毛灰体                     | 截毛全部为雄性       |
|    乙    | 截毛灰体雌果蝇 $\times$ 刚毛黑檀体雄果蝇 | 刚毛灰体 $:$ 截毛灰体 $=1:1$ | 截毛全部为雌性       |
|    丙    | 卷翅突变体 $\times$ 卷翅突变体           | 卷翅 $:$ 直翅 $=2:1$         | 卷翅 $:$ 直翅 $=1:1$ |
|    丁    | 卷翅突变体 $\times$ 野生型               | 卷翅 $:$ 直翅 $=1:1$         | $?$                  |

1. 果蝇的黑檀体突变属于**\_\_\_\_**（填“显性”或“隐性”）突变，控制该体色的基因位于**\_\_\_\_**（填“常”“X”或“Y”）染色体上。

2. 若果蝇的刚毛、截毛和灰体、黑檀体基因分别用 $D/d$ 和 $H/h$ 表示，则组合乙中亲本的基因型分别是**\_\_\_\_**。随机选取甲乙组合 $F_2$ 中截毛雄性和截毛雌性果蝇杂交，得到黑檀体果蝇的概率为**\_\_\_\_**。

3. 组合丁 $F_2$ 的表型及比例为**\_\_\_\_**，该比例不符合正常分离比的原因是**\_\_\_\_**。

4. 研究人员欲判断翅形和体色基因是否位于一对同源染色体上，请利用诱变获得的突变体果蝇为材料，设计杂交实验，写出实验思路并预测结果及结论（不考虑交叉互换）**\_\_\_\_**。

本题考查**基因的分离定律、自由组合定律、伴性遗传（X、Y染色体同源区段）以及致死效应**等遗传学核心内容。以下是各小题的标准答案及详细解析。

**（1）** 隐性 ； 常  
**（2）** $HHX^dX^d$（雌）、$hhX^dY^D$（雄）*［或：$HHX^dX^d$ 和 $hhX^dY^D$］* ； $\frac{1}{4}$  
**（3）** 卷翅 : 直翅 = 2 : 3 ； 卷翅基因显性纯合致死（或：显性纯合子致死 / AA致死）  
**（4）**

- **实验思路**（提供以下两种方案之一即可）：
    - **方案一（测交法）**：让卷翅突变体果蝇与黑檀体突变体果蝇杂交获得 $\text{F}_1$，选取 $\text{F}_1$ 中的卷翅灰体果蝇与黑檀体突变体果蝇测交，统计并记录子代的表型及比例。
    - **方案二（自交/相互交配法）**：让卷翅突变体果蝇与黑檀体突变体果蝇杂交获得 $\text{F}_1$，选取 $\text{F}_1$ 中的卷翅灰体雌雄果蝇相互交配，统计并记录子代表型及比例。
- **预测结果及结论**：
    - 若按**方案一（测交法）**：
        - 若子代表型及比例为**卷翅灰体 : 卷翅黑檀体 : 直翅灰体 : 直翅黑檀体 = 1 : 1 : 1 : 1**，则翅形和体色基因**不位于**一对同源染色体上（位于两对同源染色体上）；
        - 若子代表型及比例为**卷翅灰体 : 直翅黑檀体 = 1 : 1**，则翅形和体色基因**位于**一对同源染色体上。
    - 若按**方案二（相互交配法）**：
        - 若子代表型及比例为**卷翅灰体 : 卷翅黑檀体 : 直翅灰体 : 直翅黑檀体 = 6 : 2 : 3 : 1**，则翅形和体色基因**不位于**一对同源染色体上；
        - 若子代表型及比例为**卷翅灰体 : 直翅黑檀体 = 2 : 1**，则翅形和体色基因**位于**一对同源染色体上。

### 一、详细解析

#### 第一小问（体色基因显隐性及位置的判断）

1. **显隐性判断**：
    - 题干说明“野生型果蝇表现为刚毛、直翅和灰体”，黑檀体是诱变获得的突变型。
    - 在组合甲中，亲本为“黑檀体 ♀ × 灰体 ♂”，后代 $\text{F}_1$ 全部表现为**灰体**，表明野生型灰体对突变型黑檀体为显性，因此黑檀体突变属于**隐性突变**。
2. **染色体位置判断**：
    - 在组合甲（正交：黑檀体♀ × 灰体♂）中，$\text{F}_1$ 雌雄全为灰体；在组合乙（反交：灰体♀ × 黑檀体♂）中，$\text{F}_1$ 雌雄也都表现为灰体。正反交结果一致，且性状表现与性别无关，说明控制体色的基因位于**常染色体**上。
    - 题干同时说明“控制刚毛、截毛和灰体、黑檀体的基因位于两对同源染色体上”，后续推导出刚毛/截毛基因位于性染色体上，因此体色基因必然位于**常染色体**上。

#### 第二小问（刚毛/截毛伴性遗传分析及杂交概率计算）

1. **推导刚毛/截毛基因的染色体位置及组合乙亲本基因型**：
    - 由题意，野生型为刚毛（$D$ 为显性），突变型为截毛（$d$ 为隐性）。
    - **分析组合甲**：
        - P：刚毛黑檀体♀（$hh X^D X^-$）× 截毛灰体♂（$HH X^d Y^-$）。
        - $\text{F}_1$ 全为刚毛灰体，说明亲本均为纯合子：母本为 $hh X^D X^D$。
        - 若基因仅在X染色体上，则父本为 $X^d Y$，$\text{F}_1$ 为 $X^D X^d$ 和 $X^D Y$，$\text{F}_1$ 随机交配，$\text{F}_2$ 为 $X^D X^D$（刚♀）、$X^D X^d$（刚♀）、$X^D Y$（刚♂）、$X^d Y$（截♂），截毛确实全为雄性。
        - 但必须结合**组合乙**验证：
            - P：截毛灰体♀（$X^d X^d$）× 刚毛黑檀体♂（含 $X^D$ 或 $Y^D$）。
            - 若基因仅在X染色体上（父本为 $X^D Y$），则 $\text{F}_1$ 为 $X^D X^d$（刚♀）和 $X^d Y$（截♂）。$\text{F}_1$ 随机交配产生的 $\text{F}_2$ 中，雌雄都会出现截毛（$X^d X^d$ 雌性和 $X^d Y$ 雄性），这与组合乙表格中“$\text{F}_2$ **截毛全部为雌性**”相矛盾！
            - 因此，该等位基因必然位于 **X、Y 染色体的同源区段**：
                - 组合乙母本为截毛灰体：$HH X^d X^d$。
                - 若父本为 $hh X^d Y^D$（显性基因在Y上）：
                    - $\text{F}_1$ 产生：$Hh X^d X^d$（截毛灰体♀）和 $Hh X^d Y^D$（刚毛灰体♂），比例为 $1:1$，完全符合表格中 $\text{F}_1$“刚毛灰体 : 截毛灰体 = 1 : 1”。
                    - $\text{F}_1$ 雌雄随机交配（$X^d X^d \times X^d Y^D$），后代 $\text{F}_2$ 为：$X^d X^d$（截毛♀）和 $X^d Y^D$（刚毛♂）。
                    - 可以看到，$\text{F}_2$ 中**截毛全部为雌性**，刚毛全部为雄性，与表格完全吻合！
            - 由此确定，组合乙亲本基因型为：**雌果蝇 $HHX^dX^d$、雄果蝇 $hhX^dY^D$**。
            - 此时再反观组合甲：父本截毛雄果蝇基因型为 $HH X^d Y^d$，$\text{F}_1$ 为 $X^D X^d \times X^D Y^d \to \text{F}_2$ 中截毛果蝇为 $X^d Y^d$（全为雄性），完全成立。

2. **计算黑檀体概率**：
    - 题干：“随机选取甲乙组合 $\text{F}_2$ 中截毛雄性和截毛雌性果蝇杂交”：
        - **截毛雄性**只能来自组合甲的 $\text{F}_2$（因为乙组合 $\text{F}_2$ 的截毛全为雌性）；
        - **截毛雌性**只能来自组合乙的 $\text{F}_2$（因为甲组合 $\text{F}_2$ 的截毛全为雄性）。
    - 由于体色基因位于常染色体，与性染色体上的毛型基因**自由组合**：
        - 甲组合中：亲本关于体色为 $hh \times HH \to \text{F}_1$ 全为 $Hh$。$\text{F}_1$ 随机交配得到的 $\text{F}_2$ 中，关于体色的基因型及比例为 $\frac{1}{4}HH$、$\frac{1}{2}Hh$、$\frac{1}{4}hh$。
            - 因此，甲组合 $\text{F}_2$ 的截毛雄果蝇产生配子中，配子 $h$ 的概率为 $\frac{1}{2}$。
        - 乙组合中：亲本关于体色为 $HH \times hh \to \text{F}_1$ 全为 $Hh$。$\text{F}_1$ 随机交配得到的 $\text{F}_2$ 中，体色基因型及比例同样为 $\frac{1}{4}HH$、$\frac{1}{2}Hh$、$\frac{1}{4}hh$。
            - 因此，乙组合 $\text{F}_2$ 的截毛雌果蝇产生配子中，配子 $h$ 的概率也为 $\frac{1}{2}$。
    - 二者杂交，后代得到黑檀体（$hh$）果蝇的概率为： $$P(hh) = \frac{1}{2} \times \frac{1}{2} = \frac{1}{4}$$

#### 第三小问（致死效应与群体随机交配计算）

1. **分析组合丙（致死类型的判断）**：
    - 卷翅突变体 × 卷翅突变体 $\to \text{F}_1$ 卷翅 : 直翅 = 2 : 1。
    - 出现 $2:1$ 的分离比，说明卷翅对直翅为显性（设翅形基因为 $A/a$，卷翅为 $A$，直翅为 $a$），且**显性纯合致死（$AA$ 致死）**。
    - 故亲本卷翅均为杂合子 $Aa$，后代存活个体为 $\frac{2}{3}Aa$（卷翅）、$\frac{1}{3}aa$（直翅）。

2. **分析组合丁 $\text{F}_2$ 的表型及比例**：
    - 亲本 P：卷翅突变体（$Aa$）× 野生型直翅（$aa$）。
    - 产生的 $\text{F}_1$ 为：$\frac{1}{2}Aa$（卷翅）、$\frac{1}{2}aa$（直翅）。
    - **$\text{F}_2$ 为 $\text{F}_1$ 全部个体随机交配的后代**：
        - 先计算 $\text{F}_1$ 群体产生的配子频率： $$A \text{ 基因频率} = \frac{1}{2} \times \frac{1}{2} = \frac{1}{4}$$ $$a \text{ 基因频率} = 1 - \frac{1}{4} = \frac{3}{4}$$
        - 随机交配产生的受精卵基因型频率（根据哈代-温伯格平衡）： $$AA = \left(\frac{1}{4}\right)^2 = \frac{1}{16} \quad (\text{显性纯合致死})$$ $$Aa = 2 \times \frac{1}{4} \times \frac{3}{4} = \frac{6}{16} \quad (\text{卷翅})$$ $$aa = \left(\frac{3}{4}\right)^2 = \frac{9}{16} \quad (\text{直翅})$$
        - 由于 $AA$ 个体死亡，存活个体表现型及比例为： $$\text{卷翅}(Aa) : \text{直翅}(aa) = \frac{6}{16} : \frac{9}{16} = 6 : 9 = 2 : 3$$
3. **原因**：由于**卷翅基因显性纯合致死**（或 $AA$ 致死），导致纯合子无法存活，从而改变了正常的孟德尔分离比。

#### 第四小问（遗传学实验设计：判断是否位于一对同源染色体）

1. **材料的基因型明确**：
    - 题干给出关键信息：“每个突变体只涉及一对等位基因的改变”。
    - **卷翅突变体**：翅形改变（$Aa$），体色未突变为野生型纯合灰体（$HH$），基因型为 $AaHH$。
    - **黑檀体突变体**：体色改变（$hh$），翅形未突变为野生型纯合直翅（$aa$），基因型为 $aahh$。

2. **实验设计思路**：
    - 要探究翅形基因（$A/a$）与体色基因（$H/h$）是否位于一对同源染色体上（即是否连锁），需通过产生双杂合个体（$AaHh$）进行**测交**或**自交（雌雄相互交配）**来检验配子比例。
    - **第一步**：将卷翅突变体（$AaHH$）与黑檀体突变体（$aahh$）杂交，获取 $\text{F}_1$ 中表现型为**卷翅灰体**（$AaHh$）的果蝇。
    - **第二步**：
        - *（选择测交）* 将 $\text{F}_1$ 卷翅灰体果蝇与黑檀体突变体果蝇（$aahh$）测交。
        - *（或选择自交）* 将 $\text{F}_1$ 卷翅灰体雌雄果蝇相互交配。
    - **第三步**：统计子代表现型及比例。

3. **结果与结论推导**：
    - **若两对基因不位于同一对同源染色体上（自由组合）**：
        - $AaHh$ 产生 $AH : Ah : aH : ah = 1 : 1 : 1 : 1$ 四种配子。
        - **测交后代**：卷翅灰体 : 卷翅黑檀体 : 直翅灰体 : 直翅黑檀体 = $1 : 1 : 1 : 1$。
        - **相互交配后代**：由于 $AA$ 纯合致死，翅形存活为 $2 Aa : 1 aa$，体色存活为 $3 H\_ : 1 hh$，两者相乘得：卷翅灰体（$2\times 3=6$）: 卷翅黑檀体（$2\times 1=2$）: 直翅灰体（$1\times 3=3$）: 直翅黑檀体（$1\times 1=1$） = $6 : 2 : 3 : 1$。
    - **若两对基因位于同一对同源染色体上（完全连锁，不考虑互换）**：
        - 亲本为 $A-H$ 与 $a-h$ 结合产生 $\text{F}_1$ $AaHh$，因此基因连锁排布为 $AH$ 连锁在一条染色体上，$ah$ 连锁在另一条染色体上。
        - $AaHh$ 仅产生两种配子：$AH : ah = 1 : 1$。
        - **测交后代**（配子与 $ah$ 结合）：卷翅灰体（$AaHh$）: 直翅黑檀体（$aahh$） = $1 : 1$。
        - **相互交配后代**：配子随机结合产生 $1 AA HH$（致死）: $2 Aa Hh$（卷翅灰体）: $1 aa hh$（直翅黑檀体），存活个体表现为：卷翅灰体 : 直翅黑檀体 = $2 : 1$。

这道2023年青岛二模的遗传大题是一道极其经典的**“高综合度、强逻辑链”**的高考压轴题型。它将**伴性遗传（XY同源区段）、致死效应、群体遗传平衡（自由交配）、基因连锁判定**等多个高频难点融合在一起。

为了帮助你举一反三，下面对本题蕴含的**四大题型模型**和**四大解题思想方法**进行系统性梳理与总结：

### 二、四大核心题型模型

#### 模型 1：X、Y 染色体同源区段的伴性遗传模型

- **模型特征**：基因位于 X、Y 的同源区段，雌雄个体均有该基因的双份拷贝，雄果蝇基因型写为 $X^-Y^-$。
- **解题题眼（核心突破口）**：
    - **常规伴X隐性**：隐性雌 $\times$ 显性雄（$X^d X^d \times X^D Y$）$\to \text{F}_1$ 雌显雄隐；$\text{F}_1$ 互交后 $\text{F}_2$ **雌雄均有显隐性**。
    - **XY同源区段特有现象（本题乙组）**：当亲本雄果蝇的显性基因位于 Y 染色体上时（$X^d X^d \times X^d Y^D$）：
        - $\text{F}_1$：$X^d X^d$（隐性雌）、$X^d Y^D$（显性雄）
        - $\text{F}_1$ 自由交配产生 $\text{F}_2$：仍然是 $X^d X^d$（雌性全为隐性）和 $X^d Y^D$（雄性全为显性）。
        - **结论**：若后代中**某一性状始终“限雄性”或“限雌性”代代相传**，往往是基因位于 **XY同源区段**（如父本 $X^d Y^D$）的典型标志。

#### 模型 2：显性纯合致死模型（$2:1$ 及其衍生比）

- **模型特征**：
    - 显性性状自交（杂合子自交 $Aa \times Aa$），后代表型比由传统的 $3:1$ 变为 **$2:1$**（$2 Aa : 1 aa$），必为 **显性纯合致死（$AA$ 致死）**。
- **延伸规律**：
    - 遇到 $2:1$ 比例，立即锁定：**存活的显性个体基因型全为杂合子（$Aa$）**，不存在纯合显性存活个体。

#### 模型 3：群体“全部个体随机交配”模型（配子法/基因频率法）

- **模型特征**：题干出现“$\text{F}_2$ 为 $\text{F}_1$ **全部个体随机交配**的后代”。
- **致命误区**：很多同学误以为是各个表型各自自交或分别杂交，用组合拆分极易漏算或算错。
- **最优解题模板（配子概率法）**：
    1. 确定上一代（如 $\text{F}_1$）的基因型种类及比例。
    2. 直接计算该群体产生的**雌、雄配子比例（基因频率）**。
    3. 配子随机结合：$(pA + qa)^2 = p^2 AA + 2pq Aa + q^2 aa$。
    4. **扣除致死个体**，对剩余存活个体**重新归一化**求比例。
    - *本题丁组*：$\text{F}_1$ 为 $\frac{1}{2}Aa、\frac{1}{2}aa \to A = \frac{1}{4}, a = \frac{3}{4} \to AA = \frac{1}{16}(\text{死}), Aa = \frac{6}{16}, aa = \frac{9}{16} \to$ 存活比为 $6:9 = \mathbf{2:3}$。

#### 模型 4：判断基因位置关系的实验设计模型（连锁 vs 自由组合）

- **核心任务**：判断两对等位基因是否位于同一对同源染色体上（是否连锁）。
- **材料挖掘题眼**：“*每个突变体只涉及一对等位基因的改变*”
    - $\implies$ 卷翅突变体为：卷翅灰体（$AaHH$）；
    - $\implies$ 黑檀体突变体为：直翅黑檀体（$aahh$）。
- **经典设计通路**： $$\text{双纯/单杂亲本杂交} \to \text{获取双杂合子 } F_1 (AaHh) \to \begin{cases} \textbf{方案A：测交法} (AaHh \times aahh) \\ \textbf{方案B：互交法} (AaHh \times AaHh) \end{cases}$$
- **结果预测规律（无交叉互换）**：| 实验方法 | 不位于同源染色体（自由组合，含AA致死） | 位于同一对同源染色体（连锁 $AH / ah$） | | :--- | :--- | :--- | | **测交法** | 4种表型，比例为 **$1 : 1 : 1 : 1$** | 仅2种亲本表型，比例为 **$1 : 1$** | | **互交法** | 4种表型，比例为 **$6 : 2 : 3 : 1$** $(2:1) \times (3:1)$ | 仅2种表型（$AA$致死），比例为 **$2 : 1$** |

### 三、四大核心思想方法

#### 1. 拆分与重组思想（化繁为简）

- **方法内涵**：遇到两对及以上性状时，**绝不要混在一起看**。
- **实战应用**：
    - 看**体色**：正交全灰、反交全灰 $\to$ 常染色体隐性；
    - 看**毛型**：正交截毛全雄、反交截毛全雌 $\to$ XY同源区段伴性；
    - 看**翅形**：$2:1 \to$ 常染色体显性纯合致死；
    - 独立拆开分析完后，求多对基因杂交概率时（如第2小问），再利用乘法原理**重新组合**：$P(hh) = P(h_{\text{雄}}) \times P(h_{\text{雌}}) = \frac{1}{2} \times \frac{1}{2} = \frac{1}{4}$。

#### 2. 逆向倒推与假设排除法（穷举与验证）

- **方法内涵**：当某现象有多种可能时，先提出假说，通过反向推导推演后代，不符者立即排除。
- **实战应用**：在推导毛型染色体位置时，只看甲组 $\text{F}_2$ 截毛全为雄性，会有“仅在X上”或“在XY同源区段”两种可能。
    - *假设1*：仅在X染色体上 $\to$ 乙组父本只能是 $X^D Y \to \text{F}_2$ 会出现截毛雄果蝇 $\to$ **与题干矛盾，排除！**
    - *假设2*：在XY同源区段 $\to$ 乙组父本为 $X^d Y^D \to \text{F}_2$ 截毛必定且只能是雌性 $\to$ **完全吻合！**

#### 3. 群体基因库与“配子棋盘”思维

- **方法内涵**：高中生解遗传题常有“个体思维”，即习惯画遗传图解推一个个基因型组合；但面对**“群体随机交配”**，必须切换为**“群体配子池思维”**。
- **实战应用**：把所有参与交配个体的配子混合到一个“配子池”中，雄配子含各基因的概率是多少，雌配子是多少，两两碰撞受精。配子法不仅运算量只有传统展开法的 $\frac{1}{5}$，而且极不易漏项。

#### 4. “假说—演绎”与对照实验设计思想

- **方法内涵**：探究性实验设计的底层逻辑即是“假说—演绎法”：
    - 明确两个假说（假说1：自由组合；假说2：连锁）；
    - 演绎推理两个假说在相同实验步骤下的不同理论产物；
    - 以“若……则……；若……则……”的书面逻辑严谨表述。
- **实战规范**：实验设计题必须踩准三步得分点：**①选材与杂交步骤 $\to$ ②观察统计的具体指标（表型及比例） $\to$ ③分情况预测结果并对应得出相反结论**。
