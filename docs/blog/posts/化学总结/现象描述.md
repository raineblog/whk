# 高中化学现象描述

在高考化学中，**“实验现象描述”是主观题扣分的重灾区**。化学现象的描述必须严格遵循**“只描述看到的、听到的、摸到的感觉，绝不能用产物名称代替现象”**的原则（例如：不能写“生成了二氧化碳”，必须写“产生无色无味的气体，该气体能使澄清石灰水变浑浊”）。

以下为你全景梳理高中化学**无机**与**有机**中最核心、考查频率最高的实验反应现象。

## 第一部分：无机化学反应现象

### 一、燃烧与火焰现象（烟、雾、光、焰的区别）

**“烟”是固体微粒，“雾”是小液滴，“气”是无形气体。**

1. **钠在空气中加热**：熔化成银白色小球，**剧烈燃烧，发出黄色火焰**，生成**淡黄色固体**（$\text{Na}_2\text{O}_2$）。
2. **钠与水反应：**
    - **浮**：钠浮在水面上；
    - **熔**：熔化成闪亮的小球；
    - **游**：四处游动；
    - **响**：发出“嘶嘶”的响声；
    - **红**：滴有酚酞的溶液变红。
3. **镁条在空气/二氧化碳中燃烧：**
    - 空气中：发出**耀眼的白光**，放出大量热，生成**白色粉末**。
    - $\text{CO}_2$ 中：剧烈燃烧，发出白光，瓶壁有**黑色颗粒**（炭黑）和**白色粉末**（$\text{MgO}$）生成。
4. **铁丝在氧气中燃烧**：**剧烈燃烧，火星四射**，放出大量热，生成**黑色固体**。
5. **铁与水蒸气高温反应**：黑色粉末变为黑褐色，产生可燃性气体。
6. **硫燃烧：**
    - 在空气中：微弱的**淡蓝色火焰**；
    - 在纯氧中：明亮的**蓝紫色火焰**；
    - 共同现象：放出热量，生成**有刺激性气味的气体**。
7. **磷在氯气中燃烧**：产生**黄色火焰**，伴有**大量的白雾和白烟**（形成“白色烟雾”，$\text{PCl}_3$ 液滴为雾，$\text{PCl}_5$ 固体为烟）。
8. **氢气在氯气中燃烧**：安静地燃烧，发出**苍白色火焰**，集气瓶口有**白雾**（$\text{HCl}$ 遇水蒸气）。
9. **氢化氢（$\text{H}_2\text{S}$）燃烧：**
    - 完全燃烧产生**淡蓝色火焰**，生成刺激性气味气体；
    - 不完全燃烧火焰呈淡蓝色，器壁上有**黄色固体**（$\text{S}$）附着。

### 二、特征沉淀生成与转化（颜色突变与两性现象）

1. **亚铁离子与碱反应（极高频）：**
    - 向 $\text{FeSO}_4$ 溶液中滴入 $\text{NaOH}$：**先生成白色絮状沉淀，迅速变为灰绿色，最终转变为红褐色沉淀**。
2. **铝盐与碱反应（两性）：**
    - 向 $\text{AlCl}_3$ 滴加 $\text{NaOH}$：**先产生白色胶状沉淀，随后沉淀逐渐溶解，最终变为澄清溶液**。
    - 向 $\text{NaAlO}_2$ 中滴加盐酸：**先产生白色胶状沉淀，酸过量后沉淀溶解**。
3. **铜离子与氨水反应：**
    - 向 $\text{CuSO}_4$ 滴加氨水：**先生成浅蓝色沉淀，继续滴加氨水，沉淀溶解，得到深蓝色透明溶液**（形成铜氨络离子）。
4. **银氨溶液的配制：**
    - 向 $\text{AgNO}_3$ 溶液中逐滴滴加稀氨水：**先产生白色沉淀（迅速变棕黑），继续滴加氨水，沉淀恰好完全溶解，得到无色透明溶液**。
5. **常见特征颜色沉淀归纳：**
    - **红褐色沉淀**：$\text{Fe(OH)}_3$
    - **蓝色沉淀**：$\text{Cu(OH)}_2$
    - **淡黄色沉淀：**
        - $\text{AgBr}$（难溶于稀硝酸）；
        - 硫单质（如 $\text{Na}_2\text{S}_2\text{O}_3 + \text{H}_2\text{SO}_4 \rightarrow$ **溶液变浑浊，产生淡黄色沉淀，同时生成有刺激性气味的气体**）。
    - **黄色沉淀**：$\text{AgI}$（难溶于稀硝酸）。
    - **黑色沉淀**：$\text{FeS}、\text{CuS}、\text{PbS}、\text{Ag}_2\text{S}$（多数不溶于非氧化性稀酸）。

### 三、氧化还原与溶液颜色变化（离子检验核心）

1. **铁离子的检验与转化：**
    - $\text{Fe}^{3+}$ 遇 $\text{KSCN}$ 溶液：**溶液立即变为血红色**。
    - $\text{Fe}^{2+}$ 遇铁氰化钾 $\text{K}_3[\text{Fe(CN)}_6]$：**生成特征深蓝色沉淀（滕氏蓝）**。
    - 向含 $\text{Fe}^{3+}$ 的棕黄色溶液中加过量铁粉/铜粉：**溶液由棕黄色逐渐变为浅绿色**。
2. **酸性高锰酸钾褪色反应：**
    - 通入 $\text{SO}_2$、滴入 $\text{H}_2\text{O}_2$、$\text{FeSO}_4$、草酸（$\text{H}_2\text{C}_2\text{O}_4$）：**溶液由紫红色/紫色褪为无色**（若为 $\text{Fe}^{2+}$，溶液褪色后最终呈现浅黄色）。
3. **氯气、溴、碘的置换现象：**
    - 氯气通入无色 $\text{KI}$-淀粉溶液：**溶液由无色变为蓝色**。
    - 溴水加入苯/$\text{CCl}_4$ 萃取：
        - 加入 $\text{CCl}_4$：**液体分层，下层呈橙红色，上层几乎无色**。
        - 加入苯：**液体分层，上层呈橙红色，下层几乎无色**。
4. **二氧化硫的漂白性（与氯水对比）：**
    - 通入品红溶液：**红色溶液褪色（或变无色），加热后又恢复红色**。
    - *（对比：若通入氯水，品红褪色，加热不复原；氯水通入紫色石蕊，**先变红后褪色**；$\text{SO}_2$ 通入紫色石蕊，**只变红不褪色**）*。
5. **铜与浓/稀硝酸反应（经典对比）：**
    - **铜与浓硝酸**：**反应剧烈，铜片溶解，产生大量红棕色气体，溶液变为绿色**（高浓度二氧化氮溶于水显绿）。
    - **铜与稀硝酸**：**反应较缓，铜片溶解，产生无色气体，在试管口/瓶口遇到空气后变为红棕色，溶液变为蓝色**。
6. **铜与浓硫酸共热**：铜片逐渐溶解，有刺激性气味气体逸出；反应混合液冷却后**注入水中**，溶液变蓝，试管底部有灰黑色固体残渣。

## 第二部分：有机化学反应现象

### 一、有机物燃烧现象（含碳量规律）

有机物含碳量越高，燃烧时火焰越明亮，黑烟越浓。

1. **甲烷、天然气**：产生明亮的**淡蓝色火焰**。
2. **乙烯**：火焰明亮，**伴有黑烟**。
3. **乙炔**：**火焰极其明亮，伴有浓烈的黑烟**。
4. **苯**：剧烈燃烧，**火焰明亮，产生大量浓黑的浓烟**。
5. **乙醇**：产生淡蓝色火焰，放出大量的热。

## 第三部分：高考答题“防扣分”核心规范

在描述实验现象时，考官阅卷通常执行以下“踩分点”规则，多写了臆想词会直接判零分：

1. **不可“直呼其名”：**
    - ❌ 错误：生成了二氧化碳 / 生成了银。
    - ✔️ 正确：产生无色气体，该气体能使澄清石灰水变浑浊 / 试管壁附着一层光亮的金属单质。
2. **“烟”与“雾”严禁混淆：**
    - $\text{NH}_3 + \text{HCl} \rightarrow \text{NH}_4\text{Cl}$：**产生大量白烟**（固体），绝不能写“白雾”；
    - 打开浓盐酸瓶盖：瓶口出现**白雾**（小液滴），绝不能写“白烟”。
3. **“褪色”与“变无色”的严密性：**
    - 紫色高锰酸钾加入过量硫酸亚铁：应描述为**“高锰酸钾溶液紫色褪去，最终呈黄色/浅黄色”**（因为生成的 $\text{Fe}^{3+}$ 是黄色的），若写“变为无色”直接判错。
4. **液-液分层的上下位置（必须点明层位）：**
    - 萃取实验不能仅写“液体分层，颜色变化”。必须明确指出：**“液体分层，上层呈无色，下层呈紫红色”**（如用 $\text{CCl}_4$ 萃取碘水中的碘）。
