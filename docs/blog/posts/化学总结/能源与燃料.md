# 高中化学能源与燃料

在中学化学（初中到高中）的课程体系中，**“能源、燃料与化石资源的综合利用”**是横跨“物质构成的奥秘”、“化学反应与能量”、“有机化学基础”以及“化学与可持续发展”的核心主线。

为了确保全面且系统，我们将这部分知识划分为六大核心模块进行全景式展开讲解：

## 模块一：能源与燃料的基础分类及燃烧理论（初高中衔接）

### 1. 能源的多维度分类（选择题高频考点）

- **按来源属性划分：**
    - **一次能源（天然存在）**：化石能源（煤、石油、天然气）、太阳能、风能、水能、地热能、生物质能、核燃料。
    - **二次能源（人工转化）**：电能、氢能、水煤气、焦炭、煤气、汽油/柴油、酒精。
- **按可再生性划分：**
    - **不可再生能源**：煤、石油、天然气、核能（核燃料越用越少）。
    - **可再生能源**：太阳能、风能、水能、生物质能、潮汐能。
- **按环境影响划分：**
    - **清洁能源**：太阳能、风能、氢能、地热能（利用过程基本不排放污染物）。
    - **传统化石能源**：燃烧会产生 $\text{CO}_2$、$\text{SO}_2$、氮氧化物（$\text{NO}_x$）及粉尘。

### 2. 燃烧的条件与灭火原理（初中核心，高中安全规范）

- **燃烧的本质**：一种发光、放热的剧烈的氧化反应。
- **燃烧的三要素（火三角）**：① 可燃物；② 充足的氧气（或助燃剂）；③ 温度达到着火点（着火点是物质的固有属性，**不可改变**）。
- **灭火的原理（打破三要素之一）：**
    - 清除或隔离可燃物（如森林火灾砍伐隔离带）；
    - 隔绝氧气/空气（如用沙土盖灭、油锅着火盖锅盖、$\text{CO}_2$ 灭火器）；
    - 降温至着火点以下（如用水灭火，**切记不可说成“降低着火点”**）。
- **完全燃烧与不完全燃烧：**
    - 氧气充足：生成 $\text{CO}_2$ 和 $\text{H}_2\text{O}$，释放热量多，节能环保；
    - 氧气不足：生成有毒的 $\text{CO}$ 和炭黑颗粒，浪费燃料且污染空气。

## 模块二：煤的组成及综合利用（有机工业基础）

### 1. 煤的组成

- **误区警示**：**煤不是单质碳，也不是纯净物！**
- **组成特征**：煤是由**有机物和无机物组成的复杂混合物**。
- **元素组成**：主要含碳（C）元素，还含有少量的氢（H）、氧（O）、氮（N）、硫（S）等元素以及矿物杂质（燃烧后形成灰分）。

### 2. 煤的综合利用“三部曲”（本质辨析是核心考点）

| 加工方式             | 核心定义与条件                                                 | 变化类型     | 主要产物及用途                                                                                                                                                                                                                                                                          |
| :------------------- | :------------------------------------------------------------- | :----------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **煤的干馏（焦化）** | **隔绝空气加强热**，使煤分解的过程。                           | **化学变化** | ① **焦炭（固）**：治金炼铁还原剂；② **煤焦油（液）**：含苯、甲苯、二甲苯、苯酚、萘、蒽等芳香族化合物（通过分馏分离）；③ **粗氨水（液）**：制化肥；④ **焦炉气（气）**：主要成分为 $\text{H}_2$、$\text{CH}_4$、$\text{CO}$、$\text{C}_2\text{H}_4$，用作气体燃料或化工原料。 |
| **煤的气化**         | 把煤转化为**可燃性气体**的过程。主要反应为碳与水蒸气反应。 | **化学变化** | 核心反应：$\text{C} + \text{H}_2\text{O(g)} \xrightarrow{\text{高温}} \text{CO} + \text{H}_2$（水煤气）。用途：制造合成气，合成甲醇、液体烃等。                                                                                                                                     |
| **煤的液化**         | 把煤转化为**液体燃料**（人造石油等）。                         | **化学变化** | ① **直接液化**：煤在高温高压和催化剂作用下加氢裂化裂解（加氢液化）；② **间接液化**：先将煤气化为 $\text{CO}$ 和 $\text{H}_2$，再催化合成甲醇或液体烃：；$\text{CO} + 2\text{H}_2 \xrightarrow{\text{催化剂}} \text{CH}_3\text{OH}$。                                              |

## 模块三：石油的组成及综合利用（现代石化工业支柱）

### 1. 石油的组成

- **特征**：是一种黑色或深褐色黏稠液体，比水轻，不溶于水。
- **物质类别**：是烷烃、环烷烃和芳香烃的**极复杂液态烃类混合物**。
- **元素组成**：主要元素是 **C 和 H**（占 97%~98%），含有极少量 O、N、S 等。

### 2. 石油的加工方法（四大工艺辨析）

#### ① 石油的分馏（物理变化）

- **原理**：利用原油中各组分**沸点不同**，通过加热蒸发、冷凝，将沸点相近的烃分离成不同**馏分**的过程。
- **设备与分类：**
    - **常压分馏**：产物按沸点由低到高依次为：石油气（$\text{C}_1 \sim \text{C}_4$）、汽油（$\text{C}_5 \sim \text{C}_{11}$）、航空煤油、柴油、重油（残留物）。
    - **减压分馏**：重油沸点极高，在常压高温下易炭化分解。利用**“气压降低，沸点降低”**的原理进行减压分馏，产物为：轻质润滑油、重质润滑油、石蜡、凡士林，残留物为沥青。
- **注意**：**每个馏分依然是混合物！**

#### ② 石油的裂化（化学变化）

- **目的**：工业上轻质油（汽油）需求量大，而重油过剩。裂化是为了**提高轻质液体燃料（特别是汽油）的产量和质量**。
- **原理**：在一定条件下（加热、加压、催化剂），将**相对分子质量大、沸点高的长链烃断裂为相对分子质量小、沸点低的短链烃**。
- **反应示例**：$\text{C}_{16}\text{H}_{34} \xrightarrow[\text{催化剂}]{\text{加热、加压}} \text{C}_8\text{H}_{18} (\text{辛烷}) + \text{C}_8\text{H}_{16} (\text{辛烯})$
- **裂化汽油 vs 直馏汽油的区别（实验题必考）：**
    - **直馏汽油**：分馏产物，成分全为饱和烷烃，**不能使溴水褪色**。
    - **裂化汽油**：裂化产物，**含有不饱和烯烃，能与溴水发生加成反应使之褪色**，故**裂化汽油不可用作溴水萃取的萃取剂**！

#### ③ 石油的裂解（化学变化）

- **目的**：裂解又称“深度裂化”。其核心目标**不是获取燃料，而是获取基本有机化工原料——“三烯”（乙烯、丙烯、丁二烯）和“三苯”**。
- **原理**：采用比裂化**更高的温度**（$700 \sim 800^\circ\text{C}$，甚至上千度），使长链烃彻底断裂为小分子气态不饱和烃。
- **行业地位**：**乙烯（$\text{C}_2\text{H}_4$）的产量是衡量一个国家石油化工发展水平的重要标志。**

#### ④ 催化重整（化学变化）

- **目的**：① 提高汽油的抗爆性能（提高**辛烷值**）；② 制取芳香烃（苯、甲苯、二甲苯等）。
- **原理**：在催化剂作用下，使直链烃发生链异构化、环化或脱氢反应，转变为**支链烷烃、环烷烃或芳香烃**。

## 模块四：天然气、“可燃冰”与生物质能源

### 1. 天然气（Natural Gas）

- **主要成分**：**甲烷（$\text{CH}_4$）**（含量通常 $>80\% \sim 99\%$）。
- **性质**：无色、无味（民用天然气中添加臭味剂硫醇以警示泄露）、难溶于水、密度比空气小。
- **燃烧反应**：$\text{CH}_4 + 2\text{O}_2 \xrightarrow{\text{点燃}} \text{CO}_2 + 2\text{H}_2\text{O} \quad \Delta H < 0$
    - 燃烧热值高、干净清洁（相比煤和石油，生成的粉尘与硫化物极少）。
- **化工利用**：制造合成气（$\text{CH}_4 + \text{H}_2\text{O} \rightleftharpoons \text{CO} + 3\text{H}_2$）、生产炭黑、制氯仿、氢氰酸等。

### 2. “可燃冰”（天然气水合物，Methane Hydrate）

- **组成与结构**：主要是**甲烷分子被水分子包裹在笼状晶格中**形成的笼形冰状水合物，化学式可表示为 $\text{CH}_4\cdot n\text{H}_2\text{O}$。
- **赋存条件**：**高压、低温**（深海沉积物、陆地永久冻土带）。
- **优势**：储量巨大、能量密度高（$1\text{ m}^3$ 可燃冰释放约 $164\text{ m}^3$ 甲烷气体）。
- **开采难点与生态风险**：若开采过程中发生泄露，甲烷造成的温室效应是 $\text{CO}_2$ 的数十倍，并可能诱发海底滑坡、海啸等灾害。

### 3. 生物质能（Biomass Energy）

- **沼气（生物天然气）**：秸秆、人畜粪便在厌氧微生物发酵下生成，主要成分同样是 **$\text{CH}_4$**。
- **乙醇汽油：**
    - 生产：通过发酵玉米、高粱等含淀粉植物生成燃料乙醇。
    - 汽油标号中的“E10”表示：含 90% 普通汽油 + 10% 变性燃料乙醇。
    - 优点：节约石油资源、乙醇含氧促进燃烧、有效降低尾气中 $\text{CO}$ 和碳氢化合物排放。

## 模块五：面向未来的清洁绿色能源与“双碳”目标

### 1. 氢能（最理想的清洁燃料）

- **三大优势**：① **来源广**（以水为原料）；② **热值极高**（同质量产热是汽油的 3 倍）；③ **产物极其清洁**（燃烧产物仅为 $\text{H}_2\text{O}$，零碳排放）。
- **工业制备：**
    - 传统制氢（灰氢/蓝氢）：化石燃料转化（天然气重整、煤炭气化）。
    - 绿氢：利用太阳能、风电进行**电解水制氢**（$2\text{H}_2\text{O} \xrightarrow{\text{通电}} 2\text{H}_2\uparrow + \text{O}_2\uparrow$）或光催化分解水。
- **发展瓶颈**：制氢成本较高、氢气密度小极难储运（需高压储氢瓶、金属合金吸氢材料或深冷液化）、易燃易爆安全性要求极高。

### 2. 化学电源（新能源汽车动力核心）

- 高中电化学主要考点：**锂离子电池**、**氢氧燃料电池**。
    - 氢氧燃料电池（酸性介质）：
        - 负极（通 $\text{H}_2$）：$\text{H}_2 - 2\text{e}^- = 2\text{H}^+$
        - 正极（通 $\text{O}_2$）：$\text{O}_2 + 4\text{e}^- + 4\text{H}^+ = 2\text{H}_2\text{O}$
        - 优点：直接将化学能转化为电能，能量转换效率高（不受卡诺循环限制），环境友好。

### 3. 环境治理与“双碳”目标

- **三大全球环境公害与化石能源的关系：**
    - **酸雨（$\text{pH} < 5.6$）**：主要是煤燃烧排放的 $\text{SO}_2$ 和汽车尾气排放的 $\text{NO}_x$。
        - *治理：钙基固硫法（生石灰脱硫）：$\text{SO}_2 + \text{CaO} \xrightarrow{\Delta} \text{CaSO}_3$，$2\text{CaSO}_3 + \text{O}_2 = 2\text{CaSO}_4$。*
    - **温室效应**：$\text{CO}_2$、$\text{CH}_4$ 大量排放。
    - **光化学烟雾**：汽车尾气（碳氢化合物与氮氧化物）在强紫外线照射下发生光化学反应生成醛、酮、PAN 等二次污染物。
- **双碳战略：**
    - **碳达峰（Carbon Peak）**：$\text{CO}_2$ 排放总量达到历史最高峰，此后不再增长，逐步回落。
    - **碳中和（Carbon Neutrality）**：人为活动排放的 $\text{CO}_2$ 通过植树造林、工业利用（CCUS 技术）等方式全额抵消，实现净零排放。

## 模块六：核心考点“避坑黄金对照表”

在高考和各类化学竞赛中，命题老师最喜欢在名词相似、原理交织的地方设置陷阱。

| 概念对辨                       |        物理变化 / 化学变化         | 常见混淆点与真理                                                                                                                                                                                           |
| :----------------------------- | :--------------------------------: | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **石油的分馏 vs 煤的干馏**     |  分馏：**物理**；干馏：**化学**  | 凡是带“馏”字不代表全一样！石油分馏根据沸点分离；煤的干馏是隔绝空气高温热解，生成了新物质。                                                                                                                 |
| **石油的裂化 vs 石油的裂解**   |            均为**化学**            | 目的不同！裂化是为了**多出汽油（燃料）**；裂解是超高温深度裂化，为了**出乙烯、丙烯（化工原料）**。                                                                                                         |
| **直馏汽油 vs 裂化汽油**       | 直馏：不反应；裂化：**加成褪色** | 用溴水鉴别！直馏汽油全是烷烃（不褪色，可萃取）；裂化汽油含烯烃（发生化学反应褪色，不可做萃取剂）。                                                                                                         |
| **水煤气 vs 天然气 vs 焦炉气** |             均为混合物             | **水煤气**：$\text{CO} + \text{H}_2$；**天然气**：主要成分 $\text{CH}_4$；**焦炉气**：主要成分 $\text{H}_2 + \text{CH}_4$；**高炉煤气**：主要成分 $\text{CO} + \text{CO}_2 + \text{N}_2$。 |
| **着火点的说法陷阱**           |                 —                  | ❌ 错误表述：用水浇灭火焰是因为降低了可燃物的着火点。✔️ 正确表述：用水浇灭降低的是**环境温度，使其低于着火点**。                                                                                       |
