# 高中化学与STSE

本文系统梳理高考化学“化学与传统文化、STSE及生活常识”相关知识点，涵盖古籍诗词中的化学反应、古代文物材料本质、大国重器与前沿科技材料、生态环境治理、食品与日化安全、药物常识及材料归类速查，帮助考生全面掌握客观题高频考点。

<!-- more -->

在高考化学（全国卷及各新高考省份自主命题卷）中，**“化学与传统文化、STSE（科学·技术·社会·环境）及生活常识”**通常稳居**客观选择题的第 1 题（如全国卷第 7 题）**。该题分值 6 分，特点是**“覆盖面极广、时代感极强、非计算性、易混淆丢分”**。

为了确保全面且无遗漏，以下将这部分内容拆解为四大核心知识版块，进行地毯式系统梳理。

## 模块一：化学与中华优秀传统文化（古籍、诗词、文物）

高考命题常以**古诗文、古代典籍（《天工开物》《本草纲目》《汉书》等）、出土文物**为载体，考查背后的物理变化、化学变化、物质组成及反应原理。

### 1. 经典古文典籍中的化学反应与工艺

| 古文记载 / 诗句出处 | 原文内容                                           | 蕴含的化学原理 / 反应本质                                                                   | 考点提炼                               |
| :------------------ | :------------------------------------------------- | :------------------------------------------------------------------------------------------ | :------------------------------------- |
| **《天工开物》**    | “凡石灰，经火焚炼为用”                             | $\text{CaCO}_3 \xrightarrow{\text{高温}} \text{CaO} + \text{CO}_2\uparrow$                  | 分解反应、吸热反应、化学变化           |
| **《天工开物》**    | “水胆矾转化造铜”                                   | $\text{Fe} + \text{CuSO}_4 = \text{FeSO}_4 + \text{Cu}$                                     | 湿法炼铜、置换反应、氧化还原反应       |
| **《天工开物》**    | “凡铁分生、熟，炒铁即成”                           | 鼓入空气使生铁中的碳氧化降低：$\text{C} + \text{O}_2 \xrightarrow{\text{高温}} \text{CO}_2$ | 降低生铁含碳量制钢（氧化还原）         |
| **《天工开物》**    | “凡打银，以铅为母……铅沉银浮”                       | 利用铅和银的熔点、密度不同及亲和力分离金银                                                  | 冶金提纯（物理与化学综合）             |

| **《本草经集注》**  | “以火烧之，紫青烟起，云是真硝石（$\text{KNO}_3$）” | 钾元素的**焰色试验**（透过蓝色钴玻璃显紫色）                                                | 物理变化（原子核外电子跃迁释放光能）   |

### 2. 经典诗词与成语中的化学内涵

- **“千锤万凿出深山，烈火焚烧若等闲。粉骨碎身浑不怕，要留清白在人间。”**
    - 涉及化学链：$\text{CaCO}_3 \xrightarrow{\text{高温}} \text{CaO} \xrightarrow{+\text{H}_2\text{O}} \text{Ca(OH)}_2 \xrightarrow{+\text{CO}_2} \text{CaCO}_3$
- **“爆竹声中一岁除，春风送暖入屠苏。”**
    - 黑火药爆炸反应：$\text{S} + 2\text{KNO}_3 + 3\text{C} \xrightarrow{\text{点燃}} \text{K}_2\text{S} + \text{N}_2\uparrow + 3\text{CO}_2\uparrow$（**$\text{S}、\text{KNO}_3$ 是氧化剂，$\text{C}$ 是还原剂**）。
- **“美人首饰侯王印，尽是沙中浪底来。”**
    - 淘金利用金化学性质极稳定且密度大，通过流水冲洗分离：**物理变化**。
- **“日照香炉生紫烟，遥看瀑布挂前川。”**
    - 水雾在阳光散射下产生的**丁达尔效应**（胶体性质）或光的色散：**物理变化**。
- **“野火烧不尽，春风吹又生。”**
    - 植物燃烧使有机物转化为无机矿物盐（富含草木灰 $\text{K}_2\text{CO}_3$），作为植物生长的天然钾肥。
- **“春蚕到死丝方尽，蜡烛成灰泪始干。”**
    - 蚕丝成分是**蛋白质**；蜡烛燃烧属于**烃类的氧化反应**（伴随石蜡受热熔化的物理变化）。

### 3. 古代文物与文化遗产的材料本质（分类必考点）

- **陶瓷、砖瓦、唐三彩、兵马俑、琉璃**：均属于**传统无机非金属材料（硅酸盐产品）**，主要成分为硅酸盐，原料是粘土/高岭土，高温烧结发生复杂的物理化学变化。
- **青铜器（司母戊鼎、越王勾践剑、三星堆青铜面具）**：属于**合金（金属材料）**，主要含铜、锡、铅。表面铜绿成分为**碱式碳酸铜 $\text{Cu}_2(\text{OH})_2\text{CO}_3$**，生成原理是铜在空气中与 $\text{O}_2、\text{H}_2\text{O}、\text{CO}_2$ 共同作用（吸氧腐蚀）。
- **四大发明中的材料：**
    - **造纸术**：原料为树皮、麻头、破布，主要成分是**纤维素（天然有机高分子）**。
    - **古代墨汁（徽墨）**：采用松木或油脂不完全燃烧生成的炭黑加胶制成，主要成分为**碳单质**（室温下碳的化学性质稳定，故字画能长久保存）。
    - **丝绸、毛织品**：主要成分是**蛋白质**；**棉、麻**：主要成分是**纤维素**。
        - *鉴别方法*：灼烧闻气味。产生烧焦羽毛气味且灰烬易碎为蚕丝/毛；产生烧纸气味为棉麻。
- **中国传统玉石、翡翠、玛瑙：**
    - 翡翠、软玉：**硅酸盐类矿物**；
    - 玛瑙、水晶：**二氧化硅（$\text{SiO}_2$）**。

### 2. 生态环境问题与化学治理策略（生态文明建设）

- **温室效应（Greenhouse Effect）：**
    - 主要温室气体：$\text{CO}_2$、$\text{CH}_4$、$\text{N}_2\text{O}$、氟氯烃（$\text{CFCs}$）。
    - **双碳战略**：“碳达峰”与“碳中和”。
    - **CCUS 技术（碳捕集、利用与封存）：**
        - 工业吸收法：用弱碱性有机胺类（如乙醇胺 $\text{HO-CH}_2\text{CH}_2\text{NH}_2$）吸收烟气中的 $\text{CO}_2$；
        - 资源化转化：$\text{CO}_2 + 3\text{H}_2 \xrightarrow{\text{催化剂}} \text{CH}_3\text{OH} + \text{H}_2\text{O}$（人工制甲醇）；我国科学家在国际上首次实现**二氧化碳全人工合成淀粉**。
- **酸雨（Acid Rain）：**
    - 定义：$\text{pH} < \mathbf{5.6}$ 的降水（*注意：正常雨水因溶有 $\text{CO}_2$ 饱和后 $\text{pH} \approx 5.6$*）。
    - 硫酸型酸雨（主因：燃煤排放 $\text{SO}_2$）：$\text{SO}_2 \xrightarrow{} \text{H}_2\text{SO}_3 \xrightarrow[\text{催化}]{\text{O}_2} \text{H}_2\text{SO}_4$。
    - 硝酸型酸雨（主因：汽车尾气排放 $\text{NO}_x$）：$3\text{NO}_2 + \text{H}_2\text{O} = 2\text{HNO}_3 + \text{NO}$。
    - *治理*：钙基脱硫（燃煤中加入生石灰 $\text{CaO}$ 或石灰石 $\text{CaCO}_3$）；汽车安装三元催化转化器：$2\text{NO} + 2\text{CO} \xrightarrow{\text{催化剂}} \text{N}_2 + 2\text{CO}_2$。
- **光化学烟雾（Photochemical Smog）：**
    - 成因：汽车尾气中的**碳氢化合物（未燃烧烃类）**和**氮氧化物（$\text{NO}_x$）**，在强烈阳光紫外线照射下发生光化学反应，生成臭氧（$\text{O}_3$）、过氧乙酰硝酸酯（PAN）等二次污染物。
- **臭氧空洞（Ozone Depletion）：**
    - 元凶：氟氯代烷（商品名氟利昂）和 $\text{NO}_x$。紫外线下分解产生的氯自由基（$\cdot\text{Cl}$）对臭氧分解起**催化剂**作用。
- **水体富营养化（赤潮、水华）：**
    - 成因：含氮（$\text{NH}_4^+、\text{NO}_3^-$）、含磷（主要是三聚磷酸钠等洗涤助剂）生活污水与工业废水排入水体，促使藻类疯长，消耗水中溶解氧导致鱼类窒息死亡。
    - *治理*：推广使用“无磷洗涤剂”。
- **雾霾与 PM2.5：**
    - **PM2.5**：直径小于或等于 $2.5\text{ }\mu\text{m}$ 的细颗粒物。
    - 化学本质：分散质粒子直径在 $1 \sim 100\text{ nm}$ 之间的细颗粒物分散在空气中**属于气溶胶，能产生丁达尔效应**。

## 模块三：化学与健康生活（饮食、日化、医药）

### 1. 食品化学与营养素

- **六大基本营养素**：糖类、油脂、蛋白质、维生素、无机盐、水。
- **食品添加剂的化学归类（合法使用范围内）：**
    - **抗氧化剂**：维生素C（抗坏血酸）、维生素E、异抗坏血酸钠；葡萄酒中添加极少量的**二氧化硫（$\text{SO}_2$）**（杀菌、抗氧化）。
    - **防腐剂**：苯甲酸及其钠盐、山梨酸及其钾盐、亚硝酸钠（肉制品发色防腐，但过量致癌）。
    - **膨松剂**：碳酸氢钠（小苏打 $\text{NaHCO}_3$）、碳酸氢铵（$\text{NH}_4\text{HCO}_3$）。
    - **凝固剂**：盐卤（$\text{MgCl}_2、\text{CaCl}_2$）、石膏（$\text{CaSO}_4$）、葡萄糖酸-$\delta$-内酯（使豆浆中的蛋白质发生**胶体聚沉**制成豆腐）。
- **加碘食盐与强化食品：**
    - 加碘食盐添加的是**碘酸钾（$\text{KIO}_3$）**，不是单质碘（$\text{I}_2$），也不是碘化钾（$\text{KI}$，易被氧化失效）。
    - 补铁剂：通常含**硫酸亚铁（$\text{FeSO}_4$）**或富马酸亚铁，服药时常配合服用维生素C（还原剂，防止 $\text{Fe}^{2+}$ 被氧化为不易吸收的 $\text{Fe}^{3+}$）。

### 2. 常见消毒剂的分类与安全禁忌（极高频）

- **氧化型消毒杀菌剂（通过强氧化性使蛋白质变性）：**
    - **“84”消毒液**：有效成分为**次氯酸钠（$\text{NaClO}$）**。
    - **漂白粉/漂粉精**：有效成分为**次氯酸钙 $\text{Ca(ClO)}_2$**。
    - **双氧水（$\text{H}_2\text{O}_2$）、过氧乙酸（$\text{CH}_3\text{COOOH}$）、臭氧（$\text{O}_3$）、二氧化氯（$\text{ClO}_2$）**：高效绿色杀菌剂，还原产物无害。
- **非氧化型消毒剂：**
    - **医用酒精（体积分数约为 75%）**：过高（如 95%）会导致细菌表面蛋白快速凝固形成保护硬膜阻止渗透；过低杀菌力不足。75% 渗透性最好，使蛋白质变性。
- **居家日化安全致命禁忌（考试必考）：**
    - **“84”消毒液不能与洁厕灵（主要成分为盐酸 $\text{HCl}$）混用！**
    - 混用会发生剧烈的氧化还原反应（归中反应），产生有毒的氯气导致中毒窒息：
        $$
        \text{ClO}^- + \text{Cl}^- + 2\text{H}^+ = \text{Cl}_2\uparrow + \text{H}_2\text{O}
        $$

### 3. 常见药物化学常识

- **抗酸药（胃酸中和剂）：**
    - 常用成分：$\text{Al(OH)}_3$、$\text{Mg(OH)}_2$、$\text{NaHCO}_3$、$\text{CaCO}_3$。
    - *禁忌*：**胃溃疡患者慎用或禁用 $\text{NaHCO}_3$ 和 $\text{CaCO}_3$**，因为与胃酸反应产生大量 $\text{CO}_2$ 气体，增加胃内压可能导致胃穿孔。
- **钡餐（X射线消化道造影剂）：**
    - 必须使用**医用硫酸钡（$\text{BaSO}_4$）**，既不溶于水，也不溶于胃酸（盐酸）。
    - **严禁误用碳酸钡（$\text{BaCO}_3$）！** 碳酸钡溶于胃酸释放可溶性重金属离子引发严重中毒：
        $$
        \text{BaCO}_3 + 2\text{HCl} = \text{BaCl}_2 + \text{CO}_2\uparrow + \text{H}_2\text{O}
        $$
    - *可溶性钡盐中毒解毒法*：口服大量硫酸钠（$\text{Na}_2\text{SO}_4$）溶液转化为不溶的 $\text{BaSO}_4$，或口服富含蛋白质的牛奶、生蛋清保护黏膜。

### 4. 常见干燥剂与脱氧剂（包装袋中的小包）

- **物理干燥剂**：**硅胶（无毒，吸水后可加热脱水再生）**、分子筛。
- **化学酸性/中性干燥剂**：无水 $\text{CaCl}_2$（不可干燥氨气）、$\text{P}_2\text{O}_5$、浓硫酸。
- **化学碱性干燥剂**：生石灰（$\text{CaO}$）、碱石灰（$\text{NaOH} + \text{CaO}$）。
- **双吸剂 / 脱氧剂（常见于月饼、坚果包装）**：主要成分是**还原铁粉**，同时吸收水分和氧气发生吸氧腐蚀，延长保质期。

| 材料大类               | 具体实例（重点牢记）                                                                                                                                                                  | 混淆/避坑关键点                                                                   |
| :--------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | :-------------------------------------------------------------------------------- |
| **传统无机非金属材料** | 普通玻璃、普通陶瓷、水泥、砖瓦                                                                                                                                                        | 统称为**硅酸盐材料**。                                                            |
| **新型无机非金属材料** | **单晶硅（$\text{Si}$）**、**二氧化硅光纤（$\text{SiO}_2$）**、碳化硅陶瓷（$\text{SiC}$）、氮化硅（$\text{Si}_3\text{N}_4$）、石墨烯、**碳纤维**、碳纳米管、富勒烯（$\text{C}_{60}$） | **特别注意**：碳纤维、石墨烯是**无机非金属材料**，不是有机材料，也不是金属材料！ |
| **金属材料**           | 纯金属（金、银、铜、铁）及各种**合金**（储氢合金、形状记忆合金、钛合金、不锈钢、硬铝）                                                                                                | 合金的熔点通常**低于**其组分金属，硬度通常**高于**组分金属。                      |
| **天然有机高分子材料** | **淀粉、纤维素、棉花、麻、天然橡胶（聚异戊二烯）、蚕丝、羊毛、皮毛、核酸**                                                                                                            | 蛋白质、纤维素、淀粉均是混合物，无固定相对分子质量。                              |
| **合成有机高分子材料** | **三大合成材料：塑料、合成纤维、合成橡胶**（如聚乙烯、聚丙烯、涤纶、尼龙、酚醛树脂）                                                                                                  | 人造丝是粘胶纤维（改性纤维素，属天然材料衍生）；合成纤维是石化原料聚合而来。      |
| **复合材料**           | 玻璃钢（树脂+玻璃纤维）、碳纤维复合材料、钢筋混凝土、轮胎                                                                                                                             | 由**基体材料**和**分散在其中的增强材料**组合而成。                                |
